# 프록시 선택 기준

프록시는 필수 구매 항목이 아닙니다. 직접 컨트랙트 민팅은 대체로 프록시 없이 경로가 더 짧습니다. 서명/voucher API를 많은 지갑이 동시에 호출하거나 사용자가 특정 egress 경로를 요구할 때만 검토하세요.

## 고를 때 확인

* 목표 체인 RPC와 필요한 API 도메인에 실제로 연결되는지
* 앱의 **전체 테스트**에서 지연과 실패율이 안정적인지
* 지역, 동시 연결 수, 트래픽 한도와 인증 방식
* 장애 시 직접 연결로 몰래 전환하지 않는 작업 정책과 맞는지

형식:

```text
host:port:username:password
```

제공사·가격·약관은 자주 바뀝니다. 구매 전 현재 평판과 환불 조건을 직접 확인하고, 먼저 소량으로 테스트하세요.
