# 프록시 선택 시 확인할 것
프록시는 모든 사용자에게 필요한 구매 항목이 아닙니다. 먼저 [앱 프록시 설정](../app-guide/proxies.md)이 실제 작업에 필요한지 확인하세요.

- 사용할 RPC·민팅 데이터 API에 연결되는지
- 지연과 실패율이 안정적인지
- 동시 연결·트래픽 한도와 인증 형식
- 요청한 경로와 지역이 유지되는지
- 제공사의 현재 이용·요금·환불 조건

Residential·ISP 같은 종류 이름만으로 속도나 안정성을 보장할 수 없습니다. 실제 경로에서 테스트한 결과가 중요합니다. 인증정보가 포함된 프록시 주소는 공개하지 마세요.
