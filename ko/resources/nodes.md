# RPC 제공사

경쟁하는 민팅이라면 제공사의 RPC를 쓰세요. 대개 무료 요금제가 있고, 유료도 저렴하며 한도에 잘 걸리지 않습니다.

| 제공사 | 방식 |
| --- | --- |
| [Alchemy](https://www.alchemy.com) | 무료 요금제, 사용량 과금 |
| [DRPC](https://drpc.org) | 무료 요금제, 크레딧 충전 |
| [Ankr](https://www.ankr.com) | 무료 요금제, 크레딧 충전 |
| [QuickNode](https://www.quicknode.com) | 무료 요금제, 월 구독 |

공개 RPC 주소는 [Chainlist](https://chainlist.org)에서 찾을 수 있습니다.

- 체인마다 잘 되는 제공사가 다릅니다. 여럿을 준비하고 **RPC** 메뉴의 테스트로 비교하세요.
- 손익 계산에는 Alchemy 주소가 필요합니다. [손익](../tools/pnl.md)
- 요금과 조건은 자주 바뀝니다. 제공사 사이트에서 확인하세요.

넣는 법은 [RPC](../setup/rpc.md)를 보세요.
