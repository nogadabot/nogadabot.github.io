# 유용한 외부 도구

- [Etherscan Gas Tracker](https://etherscan.io/gastracker): 이더리움 실시간 가스입니다. 앱 아래 상태줄에도 가스가 나옵니다.
- [Etherscan](https://etherscan.io): 컨트랙트의 민팅 함수와 다른 사람의 민팅 거래 데이터를 봅니다. [작업 만들기](../tasks/onchain.md)의 함수와 Hex에 씁니다.
- [Chainlist](https://chainlist.org): 체인별 공개 RPC 주소입니다.

외부 링크는 바뀔 수 있습니다. 열리지 않으면 이름으로 찾아보세요.
