# Telegram 봇 시작하기
공식 [@NOGADA_Mint_Bot](https://t.me/NOGADA_Mint_Bot)은 앱 없이 서버에서 실행됩니다. 앱의 지갑·작업·RPC·프록시를 보거나 제어하지 않습니다.

## 1. 로그인과 지갑 준비
[구매 이메일 인증](../getting-started/license.md)을 마친 뒤 **지갑**에서 봇 전용 지갑을 준비합니다. 봇 키는 서버에서 암호화 보관되며 앱의 DPAPI 지갑과 별개입니다. [지갑·입금](wallets.md)을 참고하세요.

## 2. Smart Mint로 작업 만들기
1. **Smart Mint** 또는 `/mint`를 엽니다.
2. 사용할 봇 지갑을 선택하고 링크나 컨트랙트를 보냅니다.
3. 체인을 직접 고르고 프로젝트의 정확한 페이즈를 선택합니다.
4. 지갑당 수량·총 목표·발사 방식·가스·예약을 확인합니다.
5. 작업 생성 후 작업 목록의 Start를 누릅니다.

서명 페이즈의 일반 사용자는 voucher를 수동으로 준비할 필요가 없습니다. 지원 경로에서 지갑별 데이터를 자동 조회합니다. [서명 민팅](../minting/whitelist.md)을 참고하세요.

## 3. 작업과 결과
목록은 간결한 보기와 자세한 보기를 전환할 수 있습니다. 작업 번호와 Start/Stop·상세·삭제 버튼의 대상을 확인하세요. 다시 실행하면 새 거래가 나가 중복 민팅될 수 있습니다.

**다음 업데이트:** 목록의 **결과 조회**는 내 작업을 페이지별 최대 25개씩, 각 작업의 최근 실행 기준으로 모아 봅니다. 작업×지갑 결과 수와 고유 지갑 수를 구분하고, 기록이 없는 작업은 결과를 추측하지 않습니다. 각 작업 상세에서 ms/s 발사 기록을 확인할 수 있습니다.

## 4. 개인 설정
- [시간대](timezone.md): 개인 채팅별 서버 저장. UTC·현지 시각·분초를 함께 확인합니다.
- [알림](notifications.md): 앱 알림과 별도로 선택합니다.
- [공급량 감시](supply-watch.md): 관측 알림이며 자동 민팅이 아닙니다.
- RPC·프록시·OpenSea 키: 봇의 **설정**에 별도로 등록합니다.

## 고급 ABI/Hex
일반 작업은 버튼으로 설정하세요. 직접 calldata가 필요할 때만 작업 메뉴의 **고급 ABI/Hex** 도움말을 사용합니다.

| 입력 | 의미 |
|---|---|
| `sig=`, `args=` | 실제 함수 시그니처와 인자 |
| `fire=spam`, `fire=safe` | 사용자가 선택한 발사 방식 |
| `gas=`, `fee=`, `tip=` | 가스 한도, 최대 수수료, 우선순위 수수료 |
| `max=`, `delay=` | 지갑별 거래 수 상한과 시도 간격(ms) |
| `at=`, `until=` | 안내된 UTC 기준 시작·종료 |
| `nft=` | 영수증에서 확인할 NFT 컨트랙트 |
| `sweep=` | 민팅 후 이동할 주소 |

예시 주소·시간을 그대로 실행하지 말고 현재 도움말의 형식과 범위를 확인하세요. ABI/Hex의 영수증 검증 수량은 calldata를 자동 수정하지 않습니다. 일반 민팅의 수령인은 서명 지갑입니다.

앱과 봇을 같은 지갑으로 동시에 쓰면 nonce가 충돌할 수 있습니다. 두 제품은 서로의 실행 상태를 공유하지 않습니다.
