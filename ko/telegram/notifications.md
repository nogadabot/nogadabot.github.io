# 알림 설정

앱 알림과 Telegram 알림은 **서로 독립적인 개인 설정**입니다. 봇에서는 **설정 → 알림 설정**을 여세요. Telegram 설정을 바꿔도 앱의 Windows 알림 설정은 바뀌지 않습니다.

## 공개 v0.9.43

**작업 결과**와 **Supply Watch** 알림을 각각 켜거나 끌 수 있습니다. 알림을 끄는 것은 메시지 수신 설정이며 작업을 중지하거나 실행 기록을 지우는 기능이 아닙니다.

## 다음 업데이트: 결과·단계별 선택

- 민트 성공, 실패, 부분 완료, 민팅 미확인, 확인 대기·중지
- 첫 제출 시도, RPC/빌더 접수, 온체인 영수증 관측
- Supply Watch

**작업 결과**는 모든 작업 알림의 전체 스위치입니다. 전체 스위치를 끄면 개별 항목이 켜져 있어도 작업 알림은 오지 않습니다. Supply Watch는 별도입니다.

새로운 제출·접수·영수증 단계 알림은 기본적으로 꺼져 있습니다. 필요한 항목만 켜세요. RPC 접수나 영수증 관측만으로 NFT 민트 성공이라고 판단하지 않습니다.

이미 전달된 메시지는 뒤늦은 기록으로 고쳐 쓰지 않습니다. 최신 결과는 [작업의 결과 조회](telegram-bot.md)에서 확인하세요.
