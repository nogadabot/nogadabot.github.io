# 시간대와 예약

**설정 → 시간대 설정**에서 Seoul, New York 등 원하는 시간대를 고르거나 `Asia/Seoul` 같은 IANA 이름을 입력하세요.

- 설정은 **각 Telegram 개인 채팅 ID**에 귀속되어 서버 DB에 저장됩니다.
- 봇이나 서버를 다시 시작해도 저장값을 사용합니다. 다른 사용자의 설정에는 영향이 없습니다.
- 언어를 바꿔도 시간대 설정은 유지됩니다.
- 앱은 Windows 시간대를 사용합니다. 봇의 시간대를 바꿔도 앱이나 PC 시간대는 바뀌지 않습니다.

예약 시각은 UTC 기준으로 저장하고, 화면에는 `UTC · 현지시간 · 5분 20초 후`처럼 표시합니다. 남은 시간은 메시지를 만들거나 새로고칠 때 계산됩니다. 이전 메시지가 매초 자동으로 바뀌는 것은 아닙니다.

`at=16:59` 등 고급 예약 입력은 안내에 적힌 UTC 기준을 따릅니다. 현지시간 표시는 입력의 기준을 몰래 바꾸지 않습니다. 서머타임도 선택한 지역의 시간대 규칙을 따릅니다.

예약 시각을 저장한 것만으로 작업이 실행되지는 않습니다. 작업의 **Start**를 미리 눌러 준비를 시작하세요.
