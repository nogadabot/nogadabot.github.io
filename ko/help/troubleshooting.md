# 문제 해결
## 목록이 비었거나 계속 로딩됩니다
조회 실패·마지막 확인값·실제로 빈 목록을 구분하세요. 재시도로 다시 불러오되, 이를 이유로 지갑이나 작업 데이터를 초기화하지 마세요. 조회 재시도는 민팅 Start와 다릅니다.

## 작업이 시작되지 않습니다
예약 시각, 선택 지갑, 체인·RPC, 실제 페이즈와 결과의 오류를 확인합니다. gas limit·max fee·tip 오류는 서로 다른 설정입니다. 실패 이유를 읽고 해당 값만 바로잡으세요. 준비 중이라고 Start를 연속해서 누르지 않습니다.

## 거래가 대기 중입니다
기존 해시와 영수증을 먼저 확인하세요. RPC 접수만으로 블록 포함을 단정할 수 없습니다. 새 Start는 새 거래일 수 있습니다. 앱의 [Boost](../minting/boost.md)를 쓰려면 정확한 미확정 대상과 가스를 확인합니다.

## 영수증은 성공인데 민팅 미확인입니다
성공 상태의 거래라도 기대한 NFT 컨트랙트·수령 지갑·수량을 확인하지 못할 수 있습니다. 탐색기와 [결과 요약](../app-guide/results.md)을 확인하세요. 자동으로 재민팅하지 않습니다.

## 설치·인증 오류입니다
공식 다운로드 출처와 Windows 경고를 확인하세요. 라이선스 오류는 구매 이메일·코드 유효시간·기기 제한을 확인합니다. 백신 끄기나 데이터 삭제를 기본 해결책으로 삼지 마세요.

## 문의할 때
앱 버전, 체인, 작업 번호, 발생 시각, 사용자에게 보이는 오류와 필요한 부분의 스크린샷을 보내세요. 개인키·인증코드·라이선스 키·전체 RPC 자격증명은 가립니다.
