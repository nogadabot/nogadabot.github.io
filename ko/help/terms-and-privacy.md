# 이용 조건과 개인정보

Nogada를 사고 쓸 때의 규칙과, 앱이 우리 서버로 보내는 것을 짧게 정리했습니다. 궁금한 점은 [문의하기](when-stuck.md#문의하기)를 보세요.

## 라이선스 구매

- [판매 페이지](https://nogada.app/buy)에서 코인으로 냅니다. Ethereum과 Base 네트워크의 ETH, USDC, USDT입니다. 자동 결제는 없습니다.
- 디지털 상품이라 환불은 되지 않습니다. 주문 금액보다 많이 보낸 금액도 돌려드리지 않습니다.
- 민팅의 성공은 가스, 경쟁, 프로젝트 사정에 달려 있어 앱이 보장하지 않습니다.
- 판매 서버는 Telegram ID, 사용자 이름, 이름, 주문, 입금마다 거래 해시와 보낸 주소를 보관합니다.

## 키 하나에 PC 한 대

- 키는 한 번에 PC 한 대에서만 돕니다. PC는 기기 ID로 구별합니다. 기기 ID는 Windows 기기 ID의 해시입니다.
- 같은 기기 ID로 키를 다시 켜면(복사하거나 복제한 Windows, 같은 PC의 다른 Windows 사용자) 그때까지 쓰던 쪽은 다음 라이선스 확인 때 멈춥니다.
- 기기 ID가 다른 PC는 [내 라이선스](https://nogada.app/dashboard)에서 **기기 초기화**(24시간에 한 번)를 한 뒤에 키를 쓸 수 있습니다. [라이선스](../getting-started/license.md#키-하나에-pc-한-대)를 보세요.

## PC에만 남는 것

- **개인키**는 이 PC에만 Windows 계정으로 암호화해 저장하고, 거래 서명도 이 PC에서 합니다. 앱은 개인키를 우리 서버로 보내지 않습니다. 민팅 기록, 라이선스 확인, 로그 묶음 어디에도 들어가지 않습니다.
- 앱은 복구 문구(시드 문구)를 묻지도 쓰지도 않습니다. 지갑은 개인키로 들여옵니다.
- 백업과 데이터 내보내기는 이 PC에 저장하는 파일입니다. 백업은 직접 정한 비밀번호로 암호화됩니다. **데이터 내보내기**는 개인키를 그대로 글자로 적으니 그 파일을 잘 보관하세요.

## 앱이 우리 서버로 보내는 것

| 언제 | 보내는 것 |
|---|---|
| 라이선스 확인(켤 때, 그 뒤 15분마다) | 라이선스 키, 기기 ID(Windows 기기 ID의 SHA-256 해시, 기기 ID 자체가 아님), 앱 버전 |
| 다른 서버 기능(업데이트, 마켓, 내장 RPC, Telegram 알림) | 같은 키와 기기 ID, 그리고 그 요청에 필요한 내용 |
| 민팅 기록(작업이 시작, 성공, 실패할 때와 부스트할 때) | 체인, 컨트랙트 주소, 민팅 함수 이름, 가스 설정, 작업의 지갑 주소, 거래 해시, NFT 컨트랙트, 오류 메시지(200자까지), 작업에 있으면 OpenSea 드롭 정보, 시각, 앱 버전, 이 PC에서 만든 무작위 설치 ID, 라이선스 키의 해시. 라이선스 키 자체와 기기 ID는 보내지 않습니다. |
| 로그 묶음(**로그 보내기**를 누를 때, 또는 운영자가 요청할 때) | `logs` 폴더의 앱 로그 파일과 충돌 로그, **사유**에 적은 글, 앱 버전, 설치 ID, 라이선스 키 해시, 연결한 Discord ID(있으면), 시스템 종류. 올리기 전에 줄마다 웹 주소의 물음표 뒷부분, 주소 안의 사용자 이름과 비밀번호, 주소 안의 키처럼 긴 부분, 프록시 사용자 이름과 비밀번호를 `<redacted>`로 바꿉니다. |
| 충돌 | 무슨 일이 있었는지 `logs` 폴더의 `crash.log`에 적습니다. 로그 묶음 안에서만 보내집니다. |

운영자가 로그 묶음을 요청하면 앱은 다음 라이선스 확인 때 묻지 않고 알아서 보냅니다.
