# 자주 묻는 질문
## 앱을 꺼도 봇이 작동하나요?
네. 봇 작업은 서버에서 독립 실행됩니다. 앱 작업은 PC와 앱이 실행 중이어야 합니다.

## 봇 시간대가 다른 사용자에게도 적용되나요?
아니요. 개인 채팅 ID별 서버 설정입니다. 앱은 사용자 PC의 Windows 시간대를 따릅니다. [시간대 설명](../telegram/timezone.md)

## Smart Mint로 작업을 만들면 바로 발사되나요?
아니요. 작업을 만든 뒤 Start를 누릅니다. 예약 작업은 미리 Start를 눌러 준비합니다.

## 서명 voucher를 직접 넣어야 하나요?
지원되는 일반 OpenSea 서명 민팅은 자동 조회합니다. 프로젝트 자체의 미지원 경로는 정확한 실행 데이터가 필요합니다. [서명 민팅](../minting/whitelist.md)

## 무료 민팅에 비용이 없나요?
민팅 가격이 0이어도 가스가 필요할 수 있습니다. ERC-20 대금과 네이티브 가스는 구분해서 확인하세요.

## 결과가 미확인이면 실패인가요?
확인하지 못했다는 뜻입니다. 0개·실패·성공 중 하나로 임의 해석하지 말고 기존 거래와 결과를 확인하세요.

## 원하는 EVM 체인은 모두 쓸 수 있나요?
실제 체인 목록과 해당 기능의 지원 범위를 확인하세요. 체인이 보여도 모든 마켓·NFT 데이터 경로가 지원되는 것은 아닙니다.

## 안내된 새 버튼이 없어요
[적용 버전](../README.md)을 확인하세요. 다음 업데이트 표시 기능은 아직 공개되지 않았습니다. 라이선스·기기·구매 조건은 [활성화 안내](../getting-started/license.md)를 참고하세요.
