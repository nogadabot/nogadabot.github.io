# 막혔을 때

증상을 단계별로 모았습니다. 여기서 풀리지 않으면 맨 아래 "문의하기"를 보세요.

## 켜기와 라이선스

**앱이 켜지지 않아요**

| 보이는 것 | 할 일 |
|---|---|
| 두 번 눌러도 아무 일이 없음 | 이미 켜져 있을 수 있습니다. 두 번째 실행은 아무것도 띄우지 않습니다. 열린 창을 찾거나, 작업 관리자에서 `nogada.exe`를 끝낸 뒤 다시 켭니다. |
| 파일이 없어졌거나 Windows가 위협이 있다고 함 | 백신이 가져간 것입니다. 백신의 기록에서 되살리고 앱 폴더를 검사 예외에 넣습니다. |
| 동기화 폴더(OneDrive 등)나 네트워크 드라이브에 설치함 | 앱을 지우고 기본 폴더 같은 로컬 폴더에 다시 설치합니다. 지갑과 작업은 설치 폴더 밖에 있어 남습니다. |

**"라이선스 확인을 잠시 할 수 없습니다"가 나와요**
여러 번 시도했지만 라이선스 서버에 닿지 못했다는 뜻입니다. 대개 잠깐의 연결 문제입니다. 인터넷을 확인하고 **지금 다시 시도**를 누릅니다. 저장된 키와 PC 묶임, 남은 기간은 바뀌지 않습니다.

**키를 넣어도 활성화되지 않아요**
- 키를 앞뒤 빈칸 없이 그대로 붙여넣었는지 봅니다.
- 만료되었거나 정지된 키인지 [내 라이선스](https://nogada.app/dashboard)에서 확인합니다.
- 다른 PC에 묶인 키라면 내 라이선스에서 **기기 초기화**를 합니다(24시간에 한 번).
- "이 PC의 시계가 1시간 넘게 틀립니다"가 나오면 아래를 봅니다.

**"이 PC의 시계가 1시간 넘게 틀립니다"가 나와요**
라이선스 서버의 답에는 서버 시각이 들어 있고, 이 PC의 시계가 그 시각과 1시간 넘게 차이 나면 앱이 답을 받지 않습니다. Windows에서 시간 자동 설정을 켠 뒤 다시 시도합니다. 저장된 키는 그대로 남습니다. 앱을 켤 때는 같은 이유가 "라이선스 확인을 잠시 할 수 없습니다" 화면의 **기술 정보** 안에 나올 수 있습니다.

**"이 PC에서 쓰려면 키를 다시 넣으세요"가 나와요**
이 PC에 키는 저장되어 있지만, 이 PC가 열 수 있는 사용 기록이 없다는 뜻입니다. 다른 PC나 다른 Windows 계정의 앱 데이터를 이곳으로 복사했을 때 나옵니다. 키를 다시 넣습니다. 지금까지 쓰던 PC는 다음 라이선스 확인 때 멈춥니다.

**"다른 PC에서 이 키를 켜서 이 PC의 사용이 끝났습니다"가 나와요**
같은 기기 ID를 가진 다른 곳에서 같은 키를 켰다는 뜻입니다. 복사하거나 복제한 Windows, 또는 이 PC의 다른 Windows 사용자입니다. 키는 한 번에 한 곳에서만 돌기 때문에 이쪽이 멈췄고, 돌던 작업도 함께 멈췄습니다. 여기서 다시 쓰려면 키를 넣습니다. 그러면 다른 쪽이 멈춥니다.

**쓰다가 라이선스 화면으로 돌아갔어요**
앱은 15분마다 라이선스를 확인하고, 서버가 키를 받아 주지 않으면(만료, 정지, 다른 PC에 묶임, 같은 기기 ID의 다른 곳에서 켬) 라이선스 화면으로 돌아갑니다. 인터넷이 잠깐 끊긴 것만으로는 돌아가지 않습니다.

## 라이선스 구매

| 판매 페이지의 메시지 | 할 일 |
|---|---|
| 금액이 다르거나 자동으로 안 잡히나요? | 주문 화면 아래에 보낸 거래의 해시를 넣고 **확인**을 누릅니다. 운영자가 확인합니다. |
| 주문 시간이 지났습니다 | 이미 보냈다면 잠시 기다리거나 거래 해시로 확인합니다. 아직이라면 새 주문을 만듭니다. |
| 열린 주문이 많습니다 | 열린 주문은 3개까지입니다. 내 라이선스에서 하나를 취소합니다. |
| 오늘 주문을 너무 많이 만들었습니다 | 하루에 만들 수 있는 주문 수를 넘었습니다. 내일 다시 합니다. |
| 시세를 읽지 못했습니다 | 잠시 뒤 다시 하거나 USDC, USDT로 냅니다. |

## 스마트 민트 조회

| 코드 | 뜻과 할 일 |
|---|---|
| R-NO-CODE | 그 체인의 그 주소에 컨트랙트가 없습니다. 체인을 확인하거나 민팅 컨트랙트 주소를 넣습니다. |
| R-CHAIN-MISMATCH | 링크의 체인과 고른 체인이 다릅니다. 체인을 바꿔 다시 조회합니다. |
| R-FN-NONE, R-FN-UNNAMED | 민팅 함수를 찾지 못했습니다. 민터 컨트랙트나 프로젝트 민팅 페이지 링크를 넣거나 ABI / Hex를 씁니다. |
| R-FN-AMBIGUOUS | 민팅 함수가 여러 개입니다. 목록에서 고릅니다. |
| R-VALUE-UNKNOWN | 가격을 읽지 못했습니다. 민팅 가격을 넣습니다. |
| R-TOKEN-ID | ERC-1155 컬렉션이라 토큰 ID가 필요합니다. |
| R-PROOF-UNVERIFIED | 화이트리스트 증명이 필요한데, 고른 지갑의 증명을 찾지 못했습니다. 화이트리스트 파일을 넣어 보세요. |
| R-AUTH-REQUIRED | 프로젝트 사이트가 지갑마다 발급하는 서명이 필요한 민팅입니다. |
| R-LINK-BLOCKED, R-LINK-FETCH | 프로젝트 페이지를 읽지 못했습니다. 민팅 컨트랙트 주소를 직접 넣습니다. |
| R-RATE-LIMITED | 익스플로러, 프로젝트 서버, 또는 RPC가 요청 한도를 걸었습니다. 잠시 뒤 다시 하거나 RPC를 바꿉니다. |
| R-TX-NOTFOUND | 그 체인에서 거래를 찾지 못했습니다. 체인을 확인합니다. |
| R-RPC | 체인이나 프로젝트 서버에 닿지 못했습니다. RPC 상태를 확인합니다. |
| R-BUDGET | 조회 시간이 끝났습니다. 다시 하거나 지갑 수를 줄입니다. |
| R-HUMAN-CHECK | 사이트가 캡차를 요구합니다. 프로젝트 사이트에서 직접 민팅해야 합니다. |
| R-POW-REQUIRED | 지갑마다 계산(채굴)이 필요한 민팅이라 앱이 하지 않습니다. |
| R-RESOLVE | 그 밖의 이유로 경로를 찾지 못했습니다. 다시 하거나 ABI / Hex를 씁니다. |

## 작업

**"RPC 없음, 공개 RPC 사용"이 떠요**
그 체인의 RPC를 저장하지 않았습니다. 공개 RPC로도 보낼 수 있지만, 경쟁 민팅이라면 [RPC](../prepare/rpc-and-chains.md)를 넣으세요.

**연사 작업이 만들어지지 않아요**
연사에서는 최대 수수료, 우선 수수료, 가스 한도를 자동으로 둘 수 없습니다. 세 칸에 숫자를 넣습니다.

**잔액 부족으로 실패해요**
지갑에 민팅 가격과 가스비만큼의 코인을 넣고 작업을 다시 시작합니다. 필요한 양은 [가스 계산기](../app/calculator.md)의 **필요 잔액**을 봅니다.

**execution reverted로 실패해요**
컨트랙트가 거래를 거절했다는 뜻입니다. 판매가 아직 열리지 않았거나, 지갑에 자격이 없거나, 가격이나 수량이 맞지 않는 경우가 많습니다. 열리기 전에 시작해 두려면 시뮬레이션을 켜서, 시험이 통과할 때 보내게 합니다.

**RPC 잔액이나 크레딧이 떨어졌다고 멈췄어요**
작업이 가진 RPC가 모두 요금 부족을 알렸습니다. RPC 제공사에서 충전하거나 다른 RPC를 넣습니다.

**OpenSea 가격이 내 최대 가격보다 높다며 멈췄어요**
발사 때 OpenSea가 알려 준 가격이 작업의 **NFT당 가격**보다 높았습니다. 그 가격이 맞다면 NFT당 가격을 올립니다.

**OpenSea가 이 지갑을 거절했다고 나와요**
자격이 없거나, 잔액이 모자라거나, 일시적인 오류일 수 있습니다. 앱은 몇 번 다시 시도한 뒤 멈춥니다.

**작업을 편집할 수 없어요**
돌고 있는 작업은 편집할 수 없습니다. 먼저 멈춥니다.

**정각에 늦게 나가요**
- 발사 시각은 PC 시계로 셉니다. 아래 상태줄 시계 옆에 PC 시계와의 차이가 보이면 Windows 시간 동기화를 합니다.
- 작업을 정각 직전이 아니라 미리 시작해 둡니다.
- RPC를 여러 개 넣고 **여러 RPC로 전파**를 켜 봅니다.

**보낸 거래가 들어가지 않아요**
가스가 낮을 수 있습니다. 작업 화면 아래 막대의 [부스트](../tasks/running.md#부스트)로 올립니다.

## NFT와 마켓

**올리기, 오퍼 수락, 리스팅 취소 버튼이 꺼져 있어요**
OpenSea API 키가 필요합니다. [OS API](../prepare/opensea-keys.md)에서 키를 넣습니다.

**보유 NFT 위에 "오류 N건"이 나와요**
일부 지갑을 읽지 못했습니다. 잠시 뒤 새로고침합니다. 계속되면 그 체인의 RPC를 확인합니다.

**손익이 계산되지 않아요**
지원하지 않는 체인일 수 있습니다. Alchemy를 지원하는 체인이라면 RPC 메뉴나 **설정 → 연동 → PnL Alchemy URL**에 Alchemy 주소를 넣습니다.

**마켓에 아무것도 나오지 않아요**
**설정 → 연동 → 마켓 허브**의 상태를 확인하고 새로고침합니다.

## 자주 묻는 것

**Mac에서 되나요?** 아니요. Windows 앱입니다. Mac이라면 Windows VPS를 쓸 수 있습니다. → [내려받기와 첫 실행](../getting-started/install.md#vps에서-쓰기)

**어떤 체인에서 민팅하나요?** 이더리움과 EVM 체인입니다. 목록은 [RPC와 체인](../prepare/rpc-and-chains.md#지원-체인)에 있고, 없는 EVM 체인은 직접 추가할 수 있습니다.

**앱을 꺼도 작업이 도나요?** 아니요. 작업은 앱 안에서 돕니다.

**한 키로 PC 두 대에서 쓸 수 있나요?** 아니요. 키는 한 번에 PC 한 대에서만 돕니다. 같은 기기 ID로 다시 켜면 먼저 쓰던 쪽이 끝나고, 기기 ID가 다른 PC는 먼저 **기기 초기화**를 해야 합니다. → [라이선스](../getting-started/license.md#키-하나에-pc-한-대)

**자격이 없다고 나오는데 왜 막지 않나요?** 앱이 보여 주는 자격과 잔액은 판단을 돕는 정보입니다. 보낼지는 사용자가 정하고, 최종 결과는 체인이 정합니다. 스마트 민트의 **안전 (시뮬레이션 후)**을 고르면 시뮬레이션에서 실패할 지갑은 건너뜁니다.

**민팅 성공을 보장하나요?** 아니요. 가스, RPC, 경쟁, 프로젝트 사정에 달려 있습니다.

**환불되나요?** 디지털 상품이라 환불은 되지 않습니다. → [이용 조건과 개인정보](terms-and-privacy.md)

## 문의하기

1. 작업 문제라면 그 작업의 **⋯ → 로그 보기**를 열고 **전체 복사**를 누릅니다.
2. **설정 → 일반 → 앱 로그**에서 **로그 보내기**를 누르고, **사유**에 무슨 일이 있었는지 적어(선택, 500자까지) 보냅니다. 다 올라가면 앱이 로그 묶음 ID를 보여 줍니다. 지갑 키, RPC API 키, 프록시 자격 증명은 묶음에 들어가지 않습니다.
3. 그 ID와 복사한 작업 로그를 아래 가운데 한 곳으로 운영자에게 보냅니다.

|---|---|
| Discord | `@crocy.eth` |
| Telegram | [@min0119](https://t.me/min0119) |
| X (Twitter) | [@0xCrocy](https://x.com/0xCrocy) |

앱의 **설정 → 일반 → 도움말과 문의**에도 같은 연락처가 있습니다.
