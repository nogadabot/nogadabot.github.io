# 키·데이터·실행 범위
## 앱과 봇의 차이
앱 개인키는 Windows DPAPI로 로컬 암호화됩니다. 봇 지갑 키는 서버에서 암호화 보관됩니다. 두 제품의 지갑·작업·nonce 상태는 공유되지 않습니다.

암호화는 모든 위험을 없애지는 않습니다. 개인키를 내보내거나 복사한 뒤의 파일·클립보드·스크린샷은 별도로 관리해야 합니다. 기기를 옮기기 전에 복구 방법을 확인하세요.

## 화면과 공유
앱의 프라이버시 모드는 민감한 표시를 가리지만 거래를 취소하거나 자산을 옮기지는 않습니다. QR에는 주소가 들어 있으며 개인키가 들어가지는 않습니다. Telegram 인증코드와 키 내보내기 메시지는 다른 사람에게 전달하지 마세요.

## 실행 전후
체인·컨트랙트·수량·금액·수령 지갑과 선택 옵션을 확인합니다. 높은 가스나 ‘안전’ 모드라는 이름은 민팅 성공 보장이 아닙니다. 삭제·Stop·다시 실행이 이미 전송된 거래에 미치는 영향은 서로 다릅니다.

## 백업과 초기화
DPAPI로 보호된 DB 파일을 다른 PC로 복사하는 것만으로 복구가 보장되지는 않습니다. 백업과 키 복구 방법을 확인한 뒤 기기 해제나 초기화를 진행하세요. 조회 오류가 발생했다는 이유만으로 DB·키 파일을 삭제하지 마세요.

앱·봇의 시간대, 알림과 로그인 설정은 별도 개인 설정입니다. 개인 설정 변경으로 다른 제품이나 다른 사용자의 설정이 함께 바뀌지는 않습니다.
