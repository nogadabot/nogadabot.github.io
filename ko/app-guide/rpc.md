# RPC 연결
RPC는 앱이 체인을 조회하고 서명된 거래를 보내는 연결입니다. **고급 메뉴 → RPC**에서 그룹을 만들고 URL을 한 줄에 하나씩 가져옵니다.

등록 후에는 지연뿐 아니라 **체인 일치·블록 갱신·요청 성공 여부**도 확인하세요. 검사 실패와 실제 빈 목록은 다릅니다. 실패하면 마지막 저장값을 확인하고 재시도합니다.

## 작업에서 선택
선택한 RPC가 어느 체인에 속하는지 확인합니다. 특정 엔드포인트를 명시한 작업은 그 선택을 존중합니다. 선택이 없는 경우의 기본 풀은 앱 설정과 해당 체인의 등록 상태에 따라 달라지므로 “아무것도 고르지 않으면 특정 제공사만 사용한다”고 가정하지 마세요.

여러 RPC로 **같은 서명 거래**를 전파할 수 있습니다. 이는 새로운 민팅을 여러 번 실행하거나 가스를 자동 인상하는 기능이 아닙니다. RPC의 접수와 블록 포함은 별개입니다.

앱과 봇의 RPC 설정은 공유되지 않습니다. 봇에서는 **설정**에서 따로 등록합니다. 봇 RPC 상세·연결 확인·삭제 버튼은 해당 항목 번호를 확인한 뒤 사용하세요.

API 키가 URL에 들어 있을 수 있으므로 전체 주소를 공개 로그나 스크린샷에 노출하지 마세요. 제공사 링크는 [RPC 자료](../resources/nodes.md)에 있습니다.
