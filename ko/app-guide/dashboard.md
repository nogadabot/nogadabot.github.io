# 대시보드
대시보드는 앱의 실행 준비, 다음 작업, 최근 결과와 확인할 문제를 모아 보여줍니다. Telegram 봇의 지갑이나 서버 작업을 합쳐 보여주는 화면은 아닙니다.

## 메뉴와 이동
기본 메뉴는 대시보드·Smart Mint·작업·지갑·마켓·설정입니다. 손익·RPC·프록시·도구·관리자는 고급 메뉴에서 찾습니다. 관리자 기능은 권한이 있는 경우에만 표시됩니다.

**Ctrl+K**로 명령 팔레트를 열 수 있습니다. 일반 메뉴와 팔레트에서는 Drops를 숨겼습니다. Smart Mint와 수동 ABI/Hex 작업은 서로 다른 진입점입니다.

## 읽는 순서
- 먼저 실행 중인 작업과 다음 예약을 확인합니다.
- 준비 정보와 실행 결과를 구분합니다. 준비됨은 민팅 성공을 뜻하지 않습니다.
- 조회 오류가 있으면 재시도하고, 마지막 확인값인지 최신값인지 확인합니다.
- 자세한 거래 결과는 [작업의 결과 요약](results.md)으로 이동합니다.

## 감시 목록
체인과 NFT 컨트랙트를 등록하면 공급량 변화·비율·속도 변화를 관측합니다. 앱이 실행 중이어야 합니다. 공급량 증가가 민팅 오픈을 뜻하지 않으며 자동 Start도 하지 않습니다.

**다음 업데이트:** 감시 목록을 바꾸는 도중 도착한 이전 조회는 새 알림 상태를 덮어쓰지 않습니다. 조회 실패 시 마지막 데이터를 유지하고 재시도 중임을 표시합니다.

새 작업을 만든 것만으로 발사되지는 않습니다. 실제 실행은 해당 작업의 Start에서 시작합니다.
