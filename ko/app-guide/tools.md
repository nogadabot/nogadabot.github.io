# 비용·시간 도구
**고급 메뉴 → 도구**에서 가스 비용과 시간을 계산합니다. 계산기를 사용하는 것만으로 거래가 전송되지는 않습니다.

## 가스 비용
민팅 가격·수량·가스 단가·가스 한도를 입력해 예상 비용을 비교합니다. **gwei는 가스 단가**, **Gas Limit은 사용량 상한**입니다. 네이티브 코인과 ERC-20 민팅 대금은 같은 단위가 아닐 수 있습니다.

계산은 입력값에 따른 추정 또는 상한입니다. 실제 가스 사용량과 네트워크 수수료는 달라질 수 있으므로 특정 여유 비율이 항상 충분하다고 가정하지 마세요.

## 시간 변환
Unix timestamp의 초·밀리초를 구분하고, UTC와 사용자 PC의 현지 시각을 비교합니다. 변환 결과를 예약에 쓸 때는 해당 입력칸이 요구하는 기준을 확인하세요.

봇의 개인 시간대 설정은 PC 시간대를 바꾸지 않습니다. 자세한 차이는 [봇 시간대](../telegram/timezone.md)에 있습니다.
