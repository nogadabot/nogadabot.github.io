# 결과와 거래 시간 읽기

거래 해시, RPC 접수, NFT 민트 성공은 서로 다른 단계입니다.

## 작업 행 읽기

**상태**는 짧게, **결과**는 실패 이유·거래 링크·확인된 온체인 근거를 보여줍니다. 자세한 원인과 확인할 항목은 작업 상세에서 볼 수 있습니다.

| 결과 | 확인된 사실 |
|---|---|
| 민트 성공 | 영수증에서 기대한 NFT 민팅 결과를 확인 |
| 실패 | 제출 실패 또는 온체인 리버트 확인 |
| 확인 대기 | 거래가 있지만 최종 영수증은 아직 확인되지 않음 |
| 민팅 미확인 | 거래는 관측했지만 기대한 NFT 민팅 결과를 확인하지 못함 |
| 부분 완료 | 지갑이나 분할 거래마다 결과가 다름 |

조회가 실패했다는 이유만으로 다시 Start를 누르지 마세요. 새 실행은 중복 민팅을 일으킬 수 있습니다.

## 결과 요약

현재 작업 그룹의 **결과 요약**에서 지갑별 결과와 거래 링크를 모아 봅니다. 총 NFT에는 영수증으로 확인된 민팅 수량만 집계됩니다.

**다음 업데이트:** 결과는 **작업 × 지갑** 단위로 세고 고유 지갑 수는 별도로 표시합니다. 같은 지갑으로 두 작업을 실행했다면 결과는 2건, 고유 지갑은 1개입니다. 없는 결과는 미보고로 남기며 같은 영수증을 중복 집계하지 않습니다.

## 발사 기록

작업 상세에서 첫 제출 시도와 RPC 접수는 **ms**, 온체인 영수증 관측은 **s**로 표시합니다. 142 ms는 0.142초, 7.811 s는 7.811초입니다. 기록이 없으면 빈칸 또는 미기록으로 표시하며 0초로 만들지 않습니다.

접수됐다고 블록에 포함됐거나 민팅에 성공한 것은 아닙니다. 시간은 관측된 기록이며 블록체인 처리 속도를 보장하는 수치가 아닙니다.
