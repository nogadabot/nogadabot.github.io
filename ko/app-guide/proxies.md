# 프록시
프록시는 요청을 사용자가 지정한 네트워크 경로로 보낼 때 사용합니다. 모든 민팅에 필수인 것은 아니며 경로가 하나 더 생기므로 더 느려질 수도 있습니다.

**고급 메뉴 → 프록시**에서 그룹을 만들고 지원되는 형식으로 가져옵니다.

```text
host:port:username:password
```

가져오기 후 전체 테스트와 호스트 검색을 사용할 수 있습니다. 삭제·그룹 비우기는 화면에 표시된 범위를 확인하세요.

작업에서 프록시 그룹을 지정했다면 실제 사용하는 RPC·민팅 데이터 API가 그 경로로 연결되는지 확인합니다. 지정 경로가 실패했다고 임의로 직접 연결로 바꾸어 성공한 것처럼 표시하지 않습니다.

프록시 비밀번호를 메시지·사진·로그로 공유하지 마세요. 앱 프록시와 봇 프록시는 별도로 관리됩니다. 선택 기준은 [프록시 자료](../resources/proxies.md)를 참고하세요.
