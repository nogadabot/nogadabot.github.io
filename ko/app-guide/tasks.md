# 작업(Tasks): 모든 앱 민팅의 시작점

작업은 “무엇을, 어떤 지갑으로, 어떤 수량·가스·시각에 민팅할지”를 저장합니다. Dashboard는 첫 화면으로 유지되지만, **앱의 모든 민팅 거래는 작업을 만든 뒤 작업 화면의 Start에서만 발사**됩니다.

## 가장 쉬운 작업 생성

1. **Smart Mint**에 컨트랙트, 블록 탐색기, OpenSea 컬렉션·아이템·assets, 마켓플레이스, 런치패드 또는 프로젝트 민트 링크를 넣습니다.
2. 프로젝트가 실제 등록한 페이즈가 여러 개면 정확한 이름 중 하나를 선택합니다.
3. 지갑, 지갑당 수량, 가스, 시작 시각과 필요한 옵션을 확인합니다.
4. **작업 만들기**를 누릅니다.
5. **작업** 화면에서 생성된 작업을 선택하고 **Start**를 누릅니다.

Smart Mint와 작업 화면을 오가는 것은 정상 흐름입니다. Smart Mint 조회 완료나 **빠른 작업 생성**은 작업만 만들며 자동으로 발사하지 않습니다.

## 작업 화면

* **그룹 레일**: 작업을 프로젝트나 전략별 그룹으로 정리합니다.
* **+ 새 작업**: 수동 또는 고급 작업 편집기를 엽니다.
* **빠른 작업 생성**: 설정에 저장한 지갑·RPC를 넣은 새 작업을 빠르게 만듭니다. 발사는 Start에서 합니다.
* **그룹 시작/중지**: 그룹의 작업에 Start/Stop을 일괄 요청합니다.
* **일괄 편집**: 선택 작업의 공통 설정을 변경합니다.
* **행의 Start/Stop/Boost/로그/편집/복제/삭제**: 각 작업을 직접 제어합니다.

준비 상태는 설명 정보입니다. 잔액, 예상 실패, 적격 추측 때문에 Start나 선택을 막지 않습니다. Start 요청은 먼저 저장되며 필요한 준비가 끝나면 자동 발사됩니다.

## 수동 컨트랙트·ABI·Hex 작업

자동 조회가 부족할 때 **+ 새 작업**에서 직접 입력합니다.

| 항목 | 의미 |
|---|---|
| 체인 | 실제 거래를 보낼 체인 |
| 거래 대상 | 호출할 컨트랙트 주소. 라우터/공용 민터일 수도 있음 |
| ABI 함수·인자 | ABI에서 함수를 고르거나 정확한 시그니처와 인자를 입력 |
| Raw calldata | 사용자가 만든 hex를 그대로 보냄 |
| 지갑당 요청 수량 | 각 지갑 영수증에서 기대할 NFT 총수량 |
| 거래 전송액 | **트랜잭션 한 번에 보낼 네이티브 토큰 총액**. 개당 가격이 아님 |
| 기대 NFT 컨트랙트 | 라우터가 다른 NFT 컨트랙트를 민팅할 때 영수증에서 확인할 대상 |
| NFT 수령인 | 민팅 결과를 받아야 할 주소 |

ABI/Hex의 기대 수량은 calldata나 전송액을 몰래 바꾸지 않습니다. SeaDrop처럼 의미가 확정된 경로에서 증명 가능한 수량 충돌만 전송 전에 알리고, 임의 calldata의 의미를 추측해 발사를 막지 않습니다.

## 지갑과 정확한 수량

* 화면에는 **지갑당 수량**, 선택 지갑 수, **총 목표 수량**을 구분해 표시합니다.
* 알려진 1회 상한이 있으면 정확한 요청량을 여러 nonce로 분할합니다. 수량을 조용히 줄이지 않습니다.
* 앱 안의 여러 작업은 앱의 nonce 조정기로 관리됩니다.
* 같은 지갑을 독립 Telegram 봇에서도 동시에 실행할 수 있으며 앱은 막지 않습니다. 다만 두 제품은 nonce를 공유하지 않으므로 충돌 가능성을 경고합니다.

## 실행 방식

| 방식 | 동작 |
|---|---|
| 즉시 1회 | 사용자가 선택한 거래를 시뮬레이션 없이 바로 전송 |
| 안전 1회 | 사용자가 고른 경우에만 같은 호출을 eth_call로 시험하고, 실제 revert가 예상되지 않는 지갑을 1회 전송 |
| 연사 | Stop, 사용자가 정한 상한, 또는 정확한 NFT 민팅 영수증이 확인될 때까지 반복 |

안전 1회는 적격 판정 기능이 아니라 사용자가 선택하는 실제 호출 시뮬레이션입니다. 가장 낮은 첫 전송 지연이 중요하면 즉시 또는 예약 실행을 사용하세요.

## 예약과 발사

Start를 미리 눌러 예약 작업을 무장하면 지갑 키, RPC 연결, 가스, nonce, 승인과 결정 가능한 calldata를 앞서 준비합니다. 지정 시각에는 새 온라인 확인을 추가하지 않고 첫 raw 거래를 전파합니다. 자동 RBF나 자동 가스 인상은 하지 않으며 실행 중 가스 교체는 사용자가 누르는 **Boost**만 사용합니다.

## 결과 상태

| 상태 | 의미 |
|---|---|
| 준비/대기 | Start가 저장되었고 발사 준비 또는 예약 시각을 기다림 |
| 제출/확정 대기 | 거래 hash가 있으며 같은 거래의 영수증을 확인 중 |
| 민팅 완료 | 성공 영수증에서 기대 NFT 컨트랙트·수령인·정확한 수량을 확인함 |
| 실패 | 온체인 revert 또는 발사 실패가 확인됨 |
| 민팅 미검증 | 영수증 status는 성공이지만 정확한 NFT Transfer를 확인하지 못함 |
| 일부 완료 | 지갑 또는 분할 거래 중 완료·실패·대기·미검증 결과가 함께 있음 |

확정 대기에는 새 nonce를 자동으로 만들지 않습니다. 민팅 미검증도 자동·그룹·일괄 재실행에서 제외됩니다. 사용자가 해당 행에서 다시 Start할 수는 있지만, 모든 실행 지갑에 새 거래가 나가 중복 민팅될 수 있다는 경고가 표시됩니다.

## 발사 전에 확인할 것

선택 지갑, 지갑당 수량, 총 목표 수량, 거래당 전송액, 총 최대 전송액, 체인, 거래 대상, NFT 수령인, 페이즈를 확인하세요. 체인·대상·수령인·금액·선택 페이즈 또는 의미가 확정된 calldata 수량이 사용자 설정과 달라진 경우는 의도 보존을 위해 발사하지 않습니다. 적격·잔액·가격 추측이나 앱/봇 같은 지갑 사용은 차단 사유가 아닙니다.
