# 작업과 Start
작업에는 체인·컨트랙트·페이즈·지갑·수량·가스·예약을 저장합니다. **작업 생성과 실행은 별개**입니다.

## 만들고 실행하기
1. [Smart Mint](../minting/smart-mint.md) 또는 수동 ABI/Hex 편집기에서 작업을 만듭니다.
2. 작업 그룹에서 저장된 설정을 확인합니다.
3. 즉시 실행하려면 Start, 예약 실행이라면 미리 Start를 눌러 준비합니다.
4. 상태·결과를 보고, 필요하면 로그나 결과 요약을 엽니다.

그룹 시작·중지, 선택 작업 편집·복제·삭제는 화면에 표시된 대상에 적용됩니다. 삭제한다고 이미 전송된 거래가 취소되지는 않습니다. 실행 중 편집한 설정은 화면의 적용 시점 안내를 확인하세요.

## 수량과 금액
**지갑당 수량**, **선택 지갑 수**, **총 목표 수량**은 다릅니다. 알려진 거래당 상한이 있으면 정확한 요청량을 여러 거래로 나눌 수 있습니다. 각 거래에는 별도 가스가 들 수 있습니다.

수동 ABI/Hex의 실제 호출 수량은 함수 인자·calldata로 정합니다. 거래 전송액은 **거래 한 번에 보낼 네이티브 코인 총액**이며 NFT 개당 가격이 아닙니다. 고급 영수증 검증의 NFT 컨트랙트·기대 수량은 결과 확인용이며 calldata를 다시 쓰지 않습니다. 민팅 수령인은 서명한 지갑입니다.

## 상태와 결과
상태 칸은 짧게 유지하고 실패 이유·거래 링크·온체인 근거는 결과 칸에 표시합니다. [결과 읽기](results.md)에서 성공·실패·대기·미확인을 구분하세요.

잔액이나 적격 추측은 준비 정보입니다. 표시만 보고 성공을 보장하거나 실패했다고 단정하지 않습니다. 제출된 거래가 미확정이면 새 실행 대신 기존 거래를 확인하세요. 다시 Start하면 같은 지갑에 새 거래가 나가 중복 민팅될 수 있습니다.

실행 방식은 [즉시·안전·연사](../minting/modes.md), 수동 가스 교체는 [Boost](../minting/boost.md)를 참고하세요.

## 편집·재시도 도구
| 기능 | 확인할 점 |
|---|---|
| 실패 지갑만 재시도 | 실패한 지갑으로 새 유휴 작업을 만듭니다. 설정 확인 후 별도로 Start를 눌러야 합니다. |
| 작업 템플릿 | 자주 사용하는 작업 설정을 저장·불러옵니다. 적용 후 현재 체인·대상·가격·수량을 확인하세요. |
| 저장 버전 비교·복원 | 변경 이력을 비교하고 이전 설정을 복원합니다. 실행 중인 작업은 화면의 적용 시점 안내를 따릅니다. |

Stop은 아직 전파되지 않은 후속 실행을 멈추는 요청입니다. 이미 체인에 보낸 거래를 취소하는 버튼으로 해석하지 마세요.
