# 앱 설정
현재 설정은 **일반·언어·연동·발사 엔진·체인/RPC·라이선스·빠른 작업 설정**으로 나뉩니다. 별도 설명이 없다면 이 PC의 앱에 저장되는 설정입니다.

## 일반과 언어
배율·시작 시 실행·프라이버시·Windows 알림을 설정합니다. 영어·한국어·중국어 선택은 로컬에 저장됩니다. 앱의 현지 시각은 Windows 시간대를 따르며 봇의 시간대 설정을 가져오지 않습니다.

**다음 업데이트:** 첫 제출·RPC 접수·온체인 영수증 관측을 개별 알림으로 선택할 수 있으며 기본값은 꺼짐입니다. 최종 민팅 결과 알림과는 구분됩니다.

## 연동
OpenSea 키는 서명 민팅 데이터와 지원되는 마켓 기능에 쓰입니다. Alchemy 데이터 URL은 체인별 NFT/PnL 조회에 사용합니다. Etherscan V2 키는 ABI 조회뿐 아니라 Stable의 기존 NFT 조회에도 필요합니다. 이는 Stable의 모든 마켓 기능을 지원한다는 뜻은 아닙니다. 웹훅은 해당 알림 기능에서 사용할 때 적용됩니다.

모든 기능에 API 키가 반드시 필요하거나 전혀 필요 없는 것은 아닙니다. 기능의 실제 요청·오류 안내를 확인하세요. 앱의 키는 봇으로 복사되지 않습니다.

## 발사 엔진과 체인/RPC
가스 기본값, 전파 설정, 지원되는 프라이빗 제출, 표시할 체인, 공개 RPC 오버라이드를 확인합니다. 빈칸과 0을 모두 ‘무제한’으로 해석하지 말고 각 입력의 설명을 따르세요. 자동 가스는 이미 전송한 거래를 계속 비싸게 교체하는 기능이 아닙니다.

## 라이선스와 빠른 작업 설정
라이선스는 활성화·기기 바인딩을 관리합니다. 빠른 작업 설정은 새 작업을 만드는 기본값이며 자동 Start가 아닙니다. 만들어진 작업에서 다시 확인하세요.

업데이트·새로고침·데이터 초기화는 서로 다릅니다. 조회 실패를 해결하려고 로컬 데이터를 초기화할 필요는 없습니다.
