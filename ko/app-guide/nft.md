# 마켓과 NFT
선택한 체인·지갑 그룹의 NFT를 조회하고, 지원되는 OpenSea/Seaport 주문을 관리합니다. 목록이 보이지 않으면 먼저 데이터 제공사 설정과 조회 오류를 확인하세요. 조회 실패는 보유 NFT가 없다는 뜻이 아닙니다.

## 보유 NFT
체인과 지갑을 선택해 새로고칩니다. 필요한 체인별 NFT 데이터 연동은 **설정 → 연동**에서 확인합니다. NFT 전송 시에는 토큰·수량·보내는 지갑·받는 주소·체인을 구분합니다.

## 주문과 매수
지원되는 경로에서 리스팅 생성·취소, 오퍼 확인·수락, floor sweep·snipe를 사용할 수 있습니다. 미리보기와 실제 주문 실행은 다릅니다. 통화·가격·수량·수수료·가스·대상 NFT를 실행 화면에서 확인하세요.

**선택 리스팅 취소**와 **지갑/그룹 전체 취소**는 범위가 다릅니다. 전체 취소는 화면에 없거나 선택하지 않은 해당 지갑의 주문에도 영향을 줍니다. 지갑별 취소 거래와 실패·대기 결과를 확인하고 필요한 항목만 다시 처리하세요.

체인 목록에 보인다고 그 체인의 모든 마켓·NFT 데이터 경로가 지원되는 것은 아닙니다. 지원되지 않거나 확인할 수 없는 경로는 안내를 따르세요.

이 화면의 거래 기능과 [민팅 작업의 Start](tasks.md)는 서로 다른 동작입니다.
