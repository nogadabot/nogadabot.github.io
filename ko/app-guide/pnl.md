# 손익(PnL)
체인·컬렉션·지갑을 선택해 확인 가능한 비용과 수익을 계산합니다. 카드 꾸미기보다 먼저 **계산 결과와 데이터 범위**를 확인하세요.

1. 체인과 컬렉션 컨트랙트를 선택합니다.
2. 계산에 포함할 지갑을 고릅니다.
3. 필요한 데이터 연동을 확인하고 계산합니다.
4. 누락·미확인 항목을 검토한 뒤 원하면 공유 카드를 꾸밉니다.

실현 손익, 가스, 지출, 회수액은 서로 다른 항목입니다. 모든 체인·마켓·외부 전송이 완전히 집계된다고 가정하지 마세요. 조회 실패나 누락이 있으면 완전한 0원 결과로 해석하지 않습니다.

배경·카드 설정은 표시용입니다. 바꿔도 실제 거래나 민팅 결과는 달라지지 않습니다. 공유 전에 지갑·금액 등 공개할 정보를 확인하세요.

연동은 [앱 설정](settings.md), 실제 민팅 결과는 [결과 요약](results.md)을 참고하세요.

## 내보내기 조건
불완전한 계산 결과는 확인용으로 볼 수 있지만 카드 복사·다운로드가 제한됩니다. 누락 안내를 해결해 완전한 결과가 된 뒤 내보내세요. 표시 형식을 꾸며도 데이터 완전성은 바뀌지 않습니다.
