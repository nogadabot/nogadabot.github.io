# Windows VPS와 원격 접속

VPS는 데이터 센터에서 계속 켜져 있는 원격 컴퓨터입니다. 없어도 됩니다. 하지만 경쟁이 심한 민팅에서는 지연이 곧 순서이므로, 많은 사용자가 VPS를 씁니다.

## 왜 빨라지나요

RPC 제공사와 런치패드 서버는 미국에 많습니다. 집 PC가 아시아에 있으면 요청이 미국까지 수백 ms 걸릴 수 있습니다. 미국에 있는 VPS에 Nogada를 설치하면 요청이 VPS에서 바로 나가므로 거리가 크게 줄어듭니다.

처음에는 버지니아 북부나 뉴욕 같은 미국 동부에서 시험해 보세요. 항상 가장 빠른 것은 아닙니다. 제공사마다 데이터 센터와 경로가 다르니 실제로 재 보고 고르세요.

집에서 VPS로 가는 원격 화면이 느려도 민팅과는 상관없습니다. 중요한 것은 VPS에서 런치패드, VPS에서 RPC까지의 지연입니다.

## 원격 데스크톱으로 연결하기

1. 원하는 지역에 RDP가 되는 Windows VPS를 빌립니다.
2. 내 PC에서 **원격 데스크톱 연결**을 엽니다.
3. 제공사가 준 IP와 사용자 이름, 비밀번호를 넣습니다.
4. VPS 안에서 [설치와 첫 실행](install.md)을 그대로 따릅니다.
5. RPC를 넣고 테스트한 뒤 나머지 데이터를 설정합니다.

VPS는 별개의 PC입니다. 파일, 앱 데이터, 브라우저 프로필, 라이선스 활성화는 집 PC와 저절로 맞춰지지 않습니다. 키 하나는 PC 한 대에만 묶이므로 VPS와 집 PC를 오갈 때마다 운영자에게 기기 초기화를 요청해야 합니다. [라이선스](license.md)를 보세요.

## 앱을 끄지 않고 연결만 끊기

원격 창을 닫기만 하면 VPS와 Nogada는 계속 돕니다. 집 PC를 꺼도 예약 작업이 그대로 돌아갑니다.

로그아웃, 재시작, 종료는 Nogada도 함께 닫습니다. 제공사의 점검 재부팅도 마찬가지입니다.

## 점검 목록

- Windows 업데이트는 켜 두되, 재시작 시간은 중요한 민팅과 겹치지 않게 정합니다.
- 절전과 최대 절전을 끕니다.
- Windows 시간 동기화가 되는지 확인합니다. 예약 발사는 이 PC의 시계를 씁니다.
- CPU, 메모리, 디스크에 여유를 둡니다.
- 강하고 고유한 Windows 비밀번호를 쓰고, 가능하면 RDP를 내 IP에서만 열어 둡니다.
- 지갑 내보내기와 API 키를 공유 클립보드로 옮기지 않습니다. 데스크톱에 들어올 수 있는 사람은 앱을 조작할 수 있습니다.
- VPS를 지우기 전에 Nogada 백업을 받습니다.

## RPC도 여전히 중요합니다

VPS 지역이 좋아도 느리거나 막힌 RPC를 고쳐 주지는 않습니다. 좋은 RPC를 여럿 준비하고 RPC 메뉴의 테스트로 확인하세요. 다음은 [지갑](../setup/wallets.md)입니다.
