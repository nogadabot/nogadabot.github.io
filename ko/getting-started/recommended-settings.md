# 필요할 때 추가하는 설정
모든 설정을 처음부터 켤 필요는 없습니다. 사용 목적에 맞는 항목부터 준비하세요.

| 목적 | 확인할 설정 |
|---|---|
| 같은 설정으로 작업을 빠르게 생성 | 설정 → 빠른 작업 설정 |
| NFT 조회·손익 계산 | 해당 체인의 Alchemy 등 데이터 연동 |
| OpenSea 서명 데이터·마켓 기능 | 각 제품의 OpenSea 키와 지원 경로 |
| 지정한 네트워크 경로 사용 | 작업의 RPC·프록시 선택 |
| 결과 알림 선택 | 앱과 봇 각각의 알림 설정 |
| 예약 실수 줄이기 | PC 시각, 봇 시간대, UTC 시작 시각 확인 |

빠른 작업 기본값은 새 작업을 만들 때 쓰는 설정입니다. 저장된 calldata를 무조건 재사용하는 기능도, 자동 Start도 아닙니다.

[RPC](../app-guide/rpc.md)는 연결 성공·체인 일치·최근 응답을 함께 보고 선택하세요. [프록시](../app-guide/proxies.md)는 추가 경로이므로 반드시 더 빨라지는 것은 아닙니다. 특정 제공사의 요금제나 속도를 이 가이드가 보장하지 않습니다.

Flashbots와 가스 설정은 [가스 가이드](../minting/gas.md)를 확인하세요. 이미 전송한 거래의 가스는 자동으로 올라가지 않습니다.
