# 앱 초기 설정
민팅 작업을 만들기 전에 아래 순서로 확인하세요.

1. **지갑:** 그룹을 만들고 사용할 지갑을 생성하거나 가져옵니다. 주소와 선택한 체인을 확인합니다.
2. **RPC:** 해당 체인의 엔드포인트를 등록하거나 사용 가능한 기본 경로를 확인합니다. 지연뿐 아니라 체인 일치와 요청 성공 여부도 봅니다.
3. **가스·전송액:** 가스를 내는 네이티브 코인, 민팅 대금의 자산, 수량과 거래당 전송액을 확인합니다.
4. **Smart Mint:** 프로젝트 링크나 컨트랙트를 입력하고 실제 체인·페이즈를 선택해 작업을 만듭니다.
5. **작업:** 저장된 설정을 확인하고 Start를 누릅니다. 예약 민팅은 미리 Start를 누르세요.

전용 RPC가 모든 경우에 필수인 것은 아닙니다. 유료 서비스에도 호출·트래픽 제한이 있으며 낮은 ping만으로 거래 접수가 안정적이라고 판단할 수 없습니다.

API 키와 프록시는 기능·제공사에 따라 필요 여부가 다릅니다. OpenSea 키는 마켓뿐 아니라 서명 민팅 데이터에도 쓰일 수 있습니다. [연동 설정](../app-guide/settings.md)을 확인하세요.

지갑·RPC·작업 목록을 불러오지 못했다고 데이터가 삭제된 것은 아닙니다. 재시도 버튼으로 다시 확인하세요.
