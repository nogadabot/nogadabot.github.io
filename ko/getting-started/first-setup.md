# 처음 5분 세팅

민팅 하나를 해 보기 위한 최소 순서입니다. 프록시, API 키, 캡차 키는 없어도 됩니다.

## 1. 언어 고르기

**설정 → 일반 → 언어**에서 English, 한국어, 简体中文 가운데 고릅니다. 바로 바뀌고 이 PC에 저장됩니다.

## 2. 지갑 넣기

1. **지갑** 메뉴에서 **+ 새 그룹**을 눌러 그룹을 만듭니다.
2. **키 가져오기**로 개인키를 넣거나 **키 만들기**로 새 지갑을 만듭니다.
3. 체인을 고르고 잔액이 보이는지 확인합니다.

자세한 내용은 [지갑](../setup/wallets.md)에 있습니다.

## 3. RPC 넣기 (권장)

RPC를 넣지 않아도 내장 공개 RPC로 돌아갑니다. 하지만 공개 RPC는 쉽게 막힙니다. 경쟁이 있는 민팅이라면 **RPC** 메뉴에 내 RPC를 넣으세요. [RPC](../setup/rpc.md)를 보세요.

## 4. 민팅 작업 만들기

1. **스마트 민트**를 엽니다.
2. 체인을 고르고 민팅 링크, 컨트랙트 주소, 거래 해시 가운데 하나를 붙여넣습니다.
3. **민팅 경로 확인**을 누릅니다.
4. 페이즈와 지갑, 수량을 고르고 작업을 만듭니다.

자세한 내용은 [스마트 민트](../tasks/smart-mint.md)에 있습니다.

## 5. 시작

작업을 만들어도 저절로 발사되지 않습니다. **작업** 메뉴에서 그 작업의 시작 버튼을 눌러야 합니다.

## 해 두면 좋은 것

- **설정 → 일반 → 백업 및 복원**: 지갑을 넣었으면 백업부터 받아 두세요.
- **설정 → 연동 → Discord 웹훅**: 작업이 끝날 때마다 Discord로 결과를 받습니다.
- **설정 → 빠른 작업 설정**: 자주 쓰는 지갑을 정해 두면 작업을 더 빨리 만듭니다.
- **프록시**: 지갑이 많은 드롭에서 사이트 요청을 나눕니다. [프록시](../setup/proxies.md)를 보세요.
