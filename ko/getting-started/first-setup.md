# 첫 민팅까지 따라 하기

활성화를 마쳤다면 아래 다섯 단계로 첫 작업을 돌릴 수 있습니다. 각 단계의 자세한 설명은 링크한 쪽에 있습니다.

## 1. 지갑 넣기

**지갑** 메뉴에서 **+ 새 그룹**으로 그룹을 만들고, **키 가져오기**에 개인키를 한 줄에 하나씩 붙여넣습니다. 새 지갑이 필요하면 **키 만들기**로 원하는 개수만큼 만듭니다. → [지갑](../prepare/wallet-groups.md)

처음에는 큰돈이 없는 민팅 전용 지갑으로 시작하세요.

## 2. 가스비 채우기

지갑마다 민팅 가격과 가스비만큼의 코인이 있어야 합니다. **지갑 → 자금 관리**의 **나눠 보내기**로 지갑 하나에서 그룹의 여러 지갑에 한 번에 보냅니다. → [자금 나눠 보내기와 모으기](../prepare/funding.md)

얼마가 필요한지 모르겠다면 [가스 계산기](../app/calculator.md)에 가스 한도와 NFT 가격을 넣어 보세요.

## 3. RPC 넣기

RPC가 없어도 앱은 체인마다 정해진 공개 RPC로 보냅니다. 하지만 공개 RPC는 쉽게 막히므로, 민팅할 체인의 RPC를 **RPC → RPC 추가**에 넣고 **전체 테스트**로 확인해 두는 편이 좋습니다. → [RPC와 체인](../prepare/rpc-and-chains.md)

## 4. 스마트 민트로 작업 만들기

**스마트 민트**에 민팅 링크, 컨트랙트 주소, 또는 그 드롭의 민팅 거래 해시를 붙여넣고 체인을 고른 뒤 **민팅 경로 확인**을 누릅니다. 화면은 단계 탭으로 한 번에 한 단계씩 보이고, 조회가 끝나면 **페이즈 선택** 탭으로 넘어갑니다.

1. **페이즈 선택**에서 민팅할 페이즈를 고릅니다.
2. **실행 설정** 탭에서 지갑 그룹, 지갑당 수량, 가스, 발사 방식을 정합니다. **즉시 1회**와 **연사**는 가스 세 칸을 숫자로 채워야 합니다.
3. **최종 확인** 탭을 보고 **민팅 작업 생성**을 누릅니다.

→ [스마트 민트](../tasks/smart-mint.md)

OpenSea 화이트리스트처럼 지갑마다 서명된 민팅 데이터를 받아야 하는 드롭은 **실행 설정**의 **방식**에서 받는 방법을 고릅니다. 익명 모드는 프록시 IP로 받고, OpenSea API와 듀얼 모드는 등록한 OpenSea API 키를 씁니다. 지갑이 많다면 둘 다 준비해 두세요. → [프록시](../prepare/proxy-groups.md), [OpenSea API 키](../prepare/opensea-keys.md)

## 5. 작업 화면에서 시작하기

스마트 민트는 작업을 만들기만 합니다. **작업** 메뉴로 가서 행의 ▶ 버튼이나 아래 막대의 **시작**을 누릅니다.

- 페이즈가 이미 열려 있으면 바로 보냅니다.
- 페이즈가 나중에 열리면 작업은 그 시각까지 기다렸다가 보냅니다. 앱을 켜 둬야 합니다.

결과는 행의 **상태** 칸에 나옵니다. 실패하면 그 칸에 이유가 짧게 나오고, 행의 **⋯ → 로그 보기**에서 자세한 기록을 봅니다. → [작업 실행과 부스트](../tasks/running.md)
