# 내려받기와 첫 실행

Nogada는 설치 파일로 받아 설치합니다. 관리자 권한 없이 지금 Windows 계정에만 설치됩니다. 설치한 앱의 이름은 **Nogada App**입니다.

## 받아서 메인 화면까지

1. 결제 완료 화면이나 [내 라이선스](https://nogada-lic.duckdns.org/dashboard)의 키 카드에 있는 **앱 내려받기**로 설치 파일 `nogada-setup-<버전>.exe`를 받습니다. 이 버튼은 라이선스가 기간 안일 때만 보입니다. 키를 사는 법은 [라이선스](license.md)에 있습니다.
2. 설치 파일을 두 번 누릅니다. 처음 보는 프로그램이라 Windows가 파란 경고 창을 띄우면 **추가 정보**를 누른 뒤 **실행**을 누릅니다.
3. 설치 화면은 누구에게나 영어로 나옵니다. 화면을 따라 설치합니다. 설치 폴더는 기본으로 `%LOCALAPPDATA%\Programs\Nogada App`이고, 설치 중에 바꿀 수 있습니다.
4. 바탕화면이나 시작 메뉴에 생긴 **Nogada App**으로 앱을 켭니다.
5. 라이선스 화면이 나오면 키를 붙여넣고 **활성화**(영어 화면에서는 **Activate**)를 누릅니다. 이 첫 활성화에는 인터넷이 필요합니다.

왼쪽에 메뉴가 보이면 끝입니다. 앱은 처음 켜면 영어로 나옵니다. 한국어로 바꾸려면 **Settings → General → Language**에서 **한국어 (Korean)**를 고릅니다.

## 파일이 놓이는 곳

| 무엇 | 어디 | 알아 둘 것 |
|---|---|---|
| 프로그램 | 설치 폴더(기본 `%LOCALAPPDATA%\Programs\Nogada App`) | 평범한 로컬 폴더가 좋습니다. OneDrive 같은 동기화 폴더와 네트워크 드라이브는 문제를 일으킵니다. |
| 기록(로그) | 설치 폴더 안의 `logs` 폴더 | 프로그램 옆에 생깁니다. |
| 지갑, 작업, 설정 | `%LOCALAPPDATA%\nogada` | 설치 폴더 밖이라 새 버전으로 바뀌어도, 앱을 지워도 모두 남습니다. |

## 다시 설치하거나 지울 때

- 앱이 켜져 있으면 설치와 지우기가 멈추고 앱을 닫으라고 나옵니다. 앱을 닫고 다시 합니다.
- 다시 설치하면 처음 고른 설치 폴더로 갑니다.
- Windows 설정의 앱 목록에서 **Nogada App**을 지우면 설치한 프로그램 파일만 지워집니다. `logs` 폴더와 `%LOCALAPPDATA%\nogada`(지갑, 키, 작업)는 남습니다. 이 PC에서 데이터까지 없애려면 지우기 전에 앱의 **설정 → 일반 → 모든 데이터 지우기**를 씁니다. → [백업과 데이터](../app/backup-and-data.md)

## 앱이 알아서 하는 일

- **라이선스 확인**: 켠 뒤 90초에 한 번, 그 뒤로 15분마다 확인합니다. 인터넷이 잠깐 끊기는 정도로는 아무 일도 없습니다. 서버가 키를 거절할 때(만료, 정지, 다른 PC에 묶임)만 라이선스 화면으로 돌아갑니다.
- **업데이트**: **설정 → 일반 → 업데이트**의 **시작할 때 강제 업데이트**가 켜져 있으면, 켤 때 라이선스 확인이 끝나자마자 새 버전을 깔고 다시 켭니다. 꺼져 있으면 새 버전이 나왔다고 알려만 줍니다.
- **하나만 켜기**: 이미 켜져 있는데 다시 실행하면 새로 보이는 것이 없습니다. 이미 열려 있는 창을 찾아보세요. 최소화되어 있거나 다른 창 뒤에 있을 수 있습니다.
- **닫으면 모두 멈춤**: 오른쪽 위 X는 창만 닫는 게 아니라 앱을 끝냅니다. 돌던 작업과 예약한 작업도 함께 끝납니다.

창은 가로 1100, 세로 720보다 작게 줄일 수 없습니다.

## VPS에서 쓰기

내 PC를 꺼 둔 동안에도 작업이 돌아야 한다면, 늘 켜져 있는 Windows 컴퓨터(VPS)를 빌려 거기서 Nogada를 켭니다.

1. 원격 데스크톱(RDP)으로 접속합니다.
2. 원격 화면 안에서 위의 "받아서 메인 화면까지"를 똑같이 합니다.
3. 키는 PC 한 대에서만 됩니다. 집 PC에서 쓰던 키라면 먼저 [내 라이선스](https://nogada-lic.duckdns.org/dashboard)에서 **기기 초기화**를 누릅니다(24시간에 한 번).

주의할 것:

- 원격 데스크톱 창의 X는 접속만 끊습니다. Nogada는 VPS 안에서 계속 돕니다. VPS 안에서 로그아웃이나 다시 시작을 고르면 그 Windows 세션이 끝나면서 Nogada도 꺼집니다.
- 예약한 작업은 VPS 자신의 시계로 발사되니, 그곳의 Windows 시간 동기화를 켜 두세요. 앱 아래쪽 상태 줄의 시계 옆에 차이가 보이면 그 시계가 어긋난 것입니다.
- VPS를 돌려주기 전에는 [백업](../app/backup-and-data.md)을 받고 **설정 → 일반 → 모든 데이터 지우기**를 합니다. 앱만 지우면 지갑이 그 디스크에 남습니다.

## 켜지지 않을 때

[막혔을 때](../help/when-stuck.md)의 "앱이 켜지지 않아요"를 보세요.
