# 설치와 첫 실행

Nogada는 Windows 앱입니다. 설치 프로그램 없이 `nogada.exe` 파일 하나로 실행합니다. 백그라운드 서비스도 없어서 앱을 닫으면 아무것도 돌지 않습니다. 단, 앱을 닫으면 예약한 작업도 돌지 않습니다.

## 설치 순서

1. **내려받기.** 구매 안내에 있는 링크에서 `nogada.exe`를 받습니다.
2. **폴더 만들기.** `C:\Nogada\`처럼 고정된 폴더를 만들고 파일을 넣습니다. 로그는 이 파일 옆 `logs` 폴더에 쌓이므로, 바탕화면이나 다운로드 폴더에 두었다가 옮기지 않는 편이 좋습니다.
3. **Windows 허용.** 파란 SmartScreen 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 백신이 파일을 지우면 **Windows 보안 → 바이러스 및 위협 방지 → 설정 관리 → 제외**에 이 폴더를 넣습니다.
4. **실행과 활성화.** `nogada.exe`를 두 번 눌러 켜고 라이선스 키를 넣습니다. [라이선스](license.md)를 보세요.

활성화에는 인터넷이 필요합니다. 앱은 라이선스를 주기적으로 다시 확인합니다. 잠깐 끊기는 정도는 괜찮지만, 오래 확인하지 못하면 라이선스 화면으로 돌아갑니다.

소셜 작업이나 브라우저가 필요한 사이트에는 Chrome, Brave, Edge 가운데 하나가 있어야 합니다.

## 아무것도 안 열릴 때

대개 아래 셋 가운데 하나입니다.

- **백신이 격리했습니다.** Windows 보안의 보호 기록을 확인하세요.
- **OneDrive나 네트워크 드라이브에 있습니다.** `C:\Nogada\` 같은 로컬 폴더로 옮기세요.
- **이미 켜져 있습니다.** Nogada는 한 번에 하나만 실행됩니다. 두 번째로 켜면 조용히 닫힙니다. 작업 표시줄을 확인하세요.

그래도 안 되면 [문제 해결](../reference/troubleshooting.md)을 보세요.
