# 설치와 첫 실행
1. [다운로드 페이지](download.md)에서 공식 설치 파일을 받습니다.
2. 설치 프로그램을 열고 안내에 따라 설치합니다.
3. 시작 메뉴나 바탕화면의 Nogada를 실행합니다.
4. 표시되는 이용 안내를 읽고 라이선스를 활성화합니다.

Nogada는 Windows 데스크톱 앱이며 최소 창 폭은 1024px입니다. 창이 답답해 보이면 앱 배율과 Windows 화면 배율을 확인하세요. 모바일 앱 설치 과정과는 다릅니다.

Windows 경고가 나오면 파일 출처와 경고 내용을 먼저 확인하세요. 앱 자체의 업데이트 검증과 Windows의 파일 평판 판단은 별개입니다. 실행할 수 없다면 경고 화면과 Windows 버전을 운영자에게 전달하되 키·인증코드는 가리세요.

앱을 실행하는 동안 PC가 절전 상태로 들어가면 예약 작업에 영향을 줄 수 있습니다. 앱 없이 서버에서 실행하려면 [Telegram 봇](../telegram/telegram-bot.md)을 별도로 설정하세요.
