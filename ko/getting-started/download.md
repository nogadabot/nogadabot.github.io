# 다운로드
Windows 10/11 64비트용 [공식 설치 파일](https://nogada-lic.duckdns.org/updates/nogada-app-setup.exe)을 받으세요. 파일명은 `nogada-app-setup.exe`입니다.

처음이라면 [설치](installation.md) 후 [라이선스 활성화](license.md)를 진행하세요. Telegram만 이용한다면 앱 설치 없이 [봇](../telegram/telegram-bot.md)에서 시작할 수 있습니다.

이미 설치했다면 앱의 업데이트 안내 또는 **설정 → 일반**에서 새 버전을 확인하세요. 업데이트 확인과 설치 완료는 다릅니다. 실행 중인 작업이 있다면 작업 상태를 먼저 확인하고 화면 안내에 따라 적용하세요.

보안 프로그램이 파일을 차단했다면 경고 내용과 다운로드 출처를 확인하고 운영자에게 문의하세요. 백신을 끄거나 경고를 정상이라고 단정할 필요는 없습니다.
