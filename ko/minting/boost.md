# Boost: 사용자가 요청하는 가스 교체
앱 작업의 **Boost**는 미확정 거래를 같은 nonce의 더 높은 가스 설정으로 교체 요청하는 기능입니다. 자동으로 실행되지 않습니다.

1. 작업의 거래 상태와 대상 지갑을 확인합니다.
2. Boost 화면에서 적용할 가스와 범위를 확인합니다.
3. 실행 후 원래 거래와 교체 거래의 접수·영수증을 확인합니다.

이미 확정된 거래를 다시 미확정으로 만들거나, mint 수량을 늘리는 기능은 아닙니다. 네트워크가 교체를 거부하거나 원래 거래가 먼저 확정될 수도 있습니다.

가스 미리보기와 실제 Boost 실행을 구분하세요. 이전 버전의 숫자 입력 예시를 그대로 적용하지 말고 현재 화면의 단위·상한을 따르세요.

Telegram 봇과 앱은 독립 제품입니다. 앱의 Boost 버튼으로 봇 작업을 제어할 수는 없습니다. [대기·미확인 결과](../app-guide/results.md)를 확인한 뒤 재실행 여부를 판단하세요.
