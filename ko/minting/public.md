# 퍼블릭 민트

퍼블릭 민트는 프로젝트가 누구나 호출할 수 있도록 연 민팅 경로입니다. Nogada는 이름이 없거나 index가 빠진 페이즈를 임의로 Public으로 만들지 않습니다.

## Smart Mint로 만들기

1. **Smart Mint**에 컨트랙트, 블록 탐색기, OpenSea 컬렉션·아이템·assets, 마켓플레이스, 런치패드 또는 프로젝트 민트 링크를 넣습니다.
2. 프로젝트가 실제 등록한 페이즈 이름과 확인 가능한 시간·가격을 검토합니다.
3. 원하는 페이즈, 지갑, 지갑당 수량, 가스와 시작 시각을 선택합니다.
4. **작업 만들기**를 누릅니다.
5. **작업** 화면에서 만든 작업을 선택하고 **Start**를 누릅니다.

현재/예정/종료 상태는 완전하고 신뢰할 수 있는 시간 정보가 있을 때만 표시합니다. 불완전하면 모름으로 남기며, Public 또는 종료됨으로 추측하지 않습니다.

## 컨트랙트로 직접 만들기

자동 조회가 불가능하면 **작업 → + 새 작업**에서 직접 입력합니다.

1. 실제 체인과 호출 대상 컨트랙트를 확인합니다.
2. **ABI 가져오기**로 민트 함수를 선택하거나 정확한 함수 시그니처/인자 또는 raw calldata를 입력합니다.
3. **지갑당 요청 수량**과 **트랜잭션 한 번에 보낼 총 네이티브 토큰 전송액**을 입력합니다.
4. 라우터/공용 민터가 별도 NFT 컨트랙트를 민팅한다면 **기대 NFT 컨트랙트**를 입력합니다.
5. 지갑과 RPC를 선택해 작업을 만든 뒤 작업 화면의 **Start**에서 실행합니다.

ABI/Hex의 기대 수량은 calldata와 전송액을 바꾸지 않습니다. 임의 calldata의 의미를 앱이 추측해 발사를 막지도 않습니다.

## 성공 판정

거래가 제출되면 같은 거래의 영수증을 확인합니다. 성공 영수증에서 기대 NFT 컨트랙트·서명 지갑·정확한 수량의 Transfer가 확인돼야 **민팅 완료**입니다. status는 성공이지만 NFT 결과가 맞는지 확인할 수 없으면 **민팅 미검증**으로 표시합니다.
