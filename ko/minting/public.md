# 퍼블릭 민팅
프로젝트가 공개한 Public 페이즈를 정확히 선택합니다. 정보가 불완전한 페이즈를 임의로 Public으로 바꾸지 않습니다.

1. Smart Mint에 링크나 컨트랙트를 입력합니다.
2. 실제 체인과 Public 페이즈의 가격·시간·수량 조건을 확인합니다.
3. 지갑·수량·가스·예약을 저장하고 작업을 만듭니다.
4. 작업에서 Start를 누릅니다.

자동 조회가 안 되면 [수동 ABI/Hex 작업](../app-guide/tasks.md)을 사용합니다. 함수 인자·calldata의 실제 수량과 거래당 전송액을 확인하세요. 영수증 검증 수량을 바꾸는 것만으로 실제 호출 수량이 달라지지는 않습니다.

무료 민팅이라도 가스가 필요할 수 있습니다. RPC 접수나 성공 상태의 영수증만으로 NFT 획득을 단정하지 말고 [결과](../app-guide/results.md)를 확인하세요.
