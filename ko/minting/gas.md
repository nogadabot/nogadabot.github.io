# 가스 설정

가스는 거래가 블록에 포함될 가능성과 최대 비용에 영향을 줍니다. 높은 값을 넣어도 순서나 민팅 성공을 보장하지 않습니다.

## Auto와 Custom

### Auto

작업 준비 단계에서 현재 네트워크의 base fee와 priority 제안을 바탕으로 전송 가스를 계산합니다. 예약 작업은 발사 전에 값을 준비해 두며, T0 뒤에 새 조회를 넣지 않습니다.

Auto는 이미 보낸 거래의 가스를 계속 올리는 기능이 아닙니다. 각 nonce는 한 번 발사되고, 자동 RBF·자동 fee escalation은 없습니다.

### Custom

사용자가 **Max fee**와 **Priority fee**를 직접 정합니다. 입력한 상한과 tip을 작업이 보존합니다. 체인 규칙상 priority를 지원하지 않는 Stable은 tip을 0으로 전송합니다.

## Gas Limit

Gas Limit은 거래가 사용할 수 있는 계산량의 상한입니다.

* 비우거나 0으로 두면 작업 준비 단계에서 추정합니다.
* 직접 입력하면 사용자가 정한 값을 사용합니다.
* 너무 낮으면 out of gas로 revert될 수 있으며, 낮춘다고 사용한 가스의 단가가 싸지는 것은 아닙니다.

## 비용 표시

화면의 예상 비용은 선택한 가스와 Gas Limit을 기준으로 한 최대치 또는 추정치입니다. 실제 사용량과 base fee에 따라 영수증 비용은 달라질 수 있습니다. 잔액 부족 추정은 정보일 뿐 Start를 막지 않으며, 최종 수락 여부는 네트워크가 결정합니다.

## Boost

제출된 거래의 가스를 바꾸려면 사용자가 작업의 **Boost**를 누릅니다. Boost는 같은 nonce의 사용자 요청 교체이며 자동으로 실행되지 않습니다. 거래가 이미 채굴됐거나 정확한 대상을 확인할 수 없으면 교체하지 않습니다.

## Flashbots

Ethereum 메인넷에서 사용자가 Flashbots를 선택하면 공개 멤풀 대신 지원되는 프라이빗 번들 경로로 제출합니다. 프라이빗 경로가 실패했다고 공개 경로로 몰래 바꾸지 않습니다.
