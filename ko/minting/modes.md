# 즉시·안전·연사
발사 방식과 예약 시각은 별도 설정입니다. **즉시 1회**를 선택했어도 예약 시각을 지정했다면 그 시각에 실행합니다.

| 방식 | 동작 |
|---|---|
| 즉시 1회 | 선택한 호출을 시뮬레이션 없이 전송 |
| 안전 1회 | 사용자가 선택한 시뮬레이션 경로로 같은 호출을 확인한 뒤 실행 |
| 연사 | 사용자의 상한·중지 조건과 거래 결과에 따라 반복 |

안전 모드는 프로젝트가 발급하는 적격 판정이 아니며 성공을 보장하지 않습니다. 일반 1회 경로도 정확한 수량을 맞추기 위해 여러 거래가 필요할 수 있습니다.

## 예약 준비
작업 생성 뒤 Start를 미리 누르면 연결·가스·nonce·가능한 calldata를 준비합니다. 늦게 공개되는 서명 데이터는 지원되는 경로에서 자동으로 다시 확인합니다. [시간대](../telegram/timezone.md)와 실제 예약 값을 함께 보세요.

## 연사의 상한
앱의 연사 시간 제한은 빈칸/0이면 기본 120초이며, 무제한 선택은 시간 제한만 해제합니다. 최대 거래 수와 종료 시각 등 다른 제한은 남을 수 있습니다. 봇 고급 입력도 해당 프롬프트의 단위·범위를 따릅니다.

민팅 완료·사용자 Stop·명시 상한 외에, 거래의 온체인 실패가 확인된 뒤 같은 민팅 설정으로 다시 조회해 매진임을 확인하면 추가 전송을 중단합니다. 공급량 표시 하나만으로 Start를 임의 차단하는 방식은 아닙니다.

미확정 거래는 같은 거래를 추적하며, 확인되지 않은 결과를 성공으로 바꾸지 않습니다. 자동 가스 인상·자동 RBF는 하지 않습니다.
