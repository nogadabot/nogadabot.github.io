# Smart Mint: 링크에서 작업까지

Smart Mint는 사용자가 입력한 NFT 민팅 대상을 조회해 작업 초안을 만드는 화면입니다. **조회나 페이즈 선택만으로 발사하지 않으며**, 만든 작업은 반드시 작업 화면의 Start에서 실행합니다.

## 넣을 수 있는 입력

* NFT 또는 민터 컨트랙트 주소
* Etherscan 계열 블록 탐색기 링크
* OpenSea 컬렉션·아이템·assets 링크
* 마켓플레이스·런치패드 링크
* 프로젝트 공식 민트 사이트 링크

## 사용 순서

1. 컨트랙트가 배포된 체인을 직접 선택하고 링크나 컨트랙트를 붙여넣은 뒤 **민팅 경로 조회**를 누릅니다.
2. 프로젝트가 등록한 페이즈가 여러 개면 실제 이름 그대로 표시됩니다. 원하는 페이즈를 고릅니다.
3. 체인, 거래 대상, NFT 대상, 지갑, 지갑당 수량, 총 목표 수량, 전송액, 가스와 예약 시각을 확인합니다.
4. **작업 만들기**를 누릅니다.
5. **작업** 화면으로 이동해 만든 작업을 선택하고 **Start**를 누릅니다.

“자동(최적 페이즈)”은 없습니다. 앱이 사용자를 대신해 페이즈를 고르지 않습니다.

직접 컨트랙트 조회는 사용자가 명시적으로 선택한 체인을 기준으로 지원 EVM 익스플로러와 Blockscout·Sourcify 같은 검증 소스 대체 경로를 확인합니다. 검증 ABI를 찾으면 작업 편집기에 실행 가능한 함수를 자동으로 불러옵니다. ABI가 없을 때도 실제 컨트랙트 존재, 컨트랙트 코드 없음, 체인/RPC 확인 불가를 구분해 모든 실패를 같은 오류로 표시하지 않습니다.

## Telegram 빠른 경로

Telegram 봇에서는 **Smart Mint**를 누르거나 `/mint`를 보냅니다. 봇 지갑이 1개면 자동 선택되고, 여러 개면 실행 범위를 고릅니다. 그다음 프로젝트 민트·마켓/OpenSea·탐색기·런치패드 링크 또는 `0x` 주소 하나만 보냅니다. 체인을 버튼으로 직접 고르고, 프로젝트가 등록한 정확한 페이즈를 선택합니다.

페이즈 선택 뒤 민팅 설정 화면에서 지갑당 수량·발사 방식·예약·가스를 버튼으로 정하고 작업을 만듭니다. 미래 페이즈는 게시된 시작·종료 시각을 기본값으로 제안합니다. 기존 한 줄 옵션은 숙련 사용자용 선택 경로로만 남아 있습니다.

## 페이즈 정보 원칙

* API·온체인·프로젝트 데이터에 있는 정확한 페이즈 이름을 유지합니다.
* index가 없거나 이름이 비어 있는 페이즈를 Public 0번으로 바꾸지 않습니다.
* 시작·종료 시간이 완전하고 신뢰할 수 있을 때만 현재/예정/종료를 표시합니다.
* 시간이 빠졌거나 서로 충돌하면 상태를 추측하지 않습니다.
* 적격/WL 배지를 보여주거나 그 추측으로 선택·Start를 막지 않습니다.

## 링크를 못 찾을 때

정상 링크라도 보호된 클라이언트 렌더링, 지역 제한, 봇 차단, 공개 메타데이터 부재 때문에 자동 조회가 실패할 수 있습니다. 이때는 순서대로 시도하세요.

1. 같은 프로젝트의 OpenSea 컬렉션 링크 또는 블록 탐색기 링크
2. 실제 민터/NFT 컨트랙트 주소와 정확한 체인
3. 작업 편집기의 ABI 가져오기
4. 프로젝트가 제공한 정확한 함수 인자 또는 raw calldata

입력을 못 찾았다는 이유로 임의의 Public 페이즈나 컨트랙트를 만들어내지 않습니다.

## 수량과 결과

수량은 지갑 한 개당 요청량이며 총 목표는 선택 지갑 수를 곱해 표시합니다. 알려진 1회 상한이 있으면 정확한 수량을 여러 nonce로 나누고 몰래 줄이지 않습니다. 민팅 NFT는 항상 거래에 서명한 지갑이 받으며, **민팅 완료**는 영수증에서 기대 NFT 컨트랙트·서명 지갑·수량을 모두 확인했을 때만 표시합니다.
