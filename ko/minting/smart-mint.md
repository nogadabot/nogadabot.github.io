# Smart Mint: 링크에서 작업까지
Smart Mint는 프로젝트 링크나 컨트랙트를 해석해 민팅 작업의 설정을 만듭니다. 조회·작업 생성만으로 거래를 보내지는 않습니다.

## 기본 흐름
1. 프로젝트 민트 링크, OpenSea 링크, 탐색기 링크 또는 컨트랙트 주소를 입력합니다.
2. 실제 컨트랙트가 있는 체인을 확인합니다. 봇에서는 체인을 직접 선택합니다.
3. 프로젝트가 등록한 정확한 페이즈를 고릅니다.
4. 지갑·지갑당 수량·총 목표·가격·가스·예약을 확인합니다.
5. 작업을 만든 뒤 작업 목록에서 **Start**를 누릅니다.

페이즈 이름만 보고 GTD·FCFS·Public을 서로 바꾸지 마세요. 가격·시각·지갑 한도·서명 조건이 다를 수 있습니다. 정보가 없으면 Public이나 종료 상태로 추측하지 않습니다.

## 자동 조회가 안 될 때
같은 프로젝트의 공식 컬렉션 링크나 컨트랙트와 체인을 확인하세요. 그래도 해석할 수 없다면 [작업 편집기](../app-guide/tasks.md)에서 검증 가능한 ABI·함수 인자 또는 정확한 calldata를 사용합니다. 다른 지갑의 서명·proof를 그대로 복사하면 적용되지 않을 수 있습니다.

일반 서명 민트 사용자가 voucher를 직접 입력할 필요는 없습니다. 지원되는 경로에서는 [지갑별 실행 데이터](whitelist.md)를 자동으로 구합니다.

작업을 만든 뒤에도 실행 대상·선택 페이즈·수량·금액을 확인하세요. 설명이나 추측보다 실제 설정과 거래 결과가 기준입니다.
