# OpenSea API 키

OpenSea API 키는 앱이 OpenSea의 인증된 기능을 쓰게 해 줍니다. RPC와는 다릅니다. RPC는 체인에 연결하고, 이 키는 OpenSea에 연결합니다.

## 키가 필요한 일

- 리스팅 올리기와 취소
- 오퍼 불러오기와 수락
- 뷰어 일괄 구매
- 민트 캘린더 일정
- 작업의 OpenSea API 방식

키가 없어도 되는 일도 많습니다. 마켓과 대시보드 시세는 Nogada 서버에서 받으므로 키가 필요 없습니다. 드롭 민팅도 일반 모드와 익명 모드는 키 없이 됩니다. 익명 모드는 익명 요청으로 답을 못 받은 지갑에만 키를 예비로 씁니다.

## 키 넣기

1. **OS API** 메뉴에서 그룹을 만들거나 고릅니다.
2. **키 추가**를 누르고 한 줄에 하나씩 붙여넣습니다. 빈 줄과 `#`으로 시작하는 줄은 무시합니다.
3. **확인 후 N개 추가**를 누릅니다.

앱은 키마다 저장하기 전에 OpenSea로 확인합니다. 잘못된 키와 중복 키는 넣지 않습니다.

키는 평소 가려져 있습니다. **모두 보기**와 복사를 눌렀을 때만 보입니다.

## 키 얻기

- **OpenSea 개발자 설정에서 직접**: OpenSea 계정의 개발자 설정에서 신청한 뒤 위 순서로 넣습니다. 이메일 인증과 간단한 사용 정보가 필요합니다.
- **모듈로**: 운영자가 **작업 → 모듈**에 OpenSea 키 모듈을 올렸다면 그 모듈로 만들 수 있습니다. 만들어진 키는 암호화되어 OS API에 저장됩니다.

## 키 테스트

테스트나 **전체 테스트**를 누르면 지연이 나옵니다. **유형**과 **만료** 칸도 함께 보세요. 드롭 전에 만료되는 키가 없는지 확인합니다.

| 상태 | 할 일 |
| --- | --- |
| 잘못됨 | 지우고 새 키를 넣습니다. **잘못된 것 지우기**로 한 번에 지웁니다 |
| 오류 | 연결을 확인하고 다시 테스트합니다 |
| 만료 임박 | 만료되기 전에 새 키를 넣습니다 |
| 만료됨 | 새 키를 넣은 뒤 지웁니다 |

한 OpenSea 계정의 키들은 요청 한도를 함께 씁니다. 같은 계정에서 키를 여러 개 만든다고 한도가 늘지 않습니다.

## OpenSea 얼리 스타트

**설정 → 발사 엔진 → OpenSea 얼리 스타트**를 켜면 시작 1초 전(T-1초)부터 민팅 데이터를 요청합니다. 거래를 일찍 보내지는 않습니다. 큰 작업 그룹에서는 한도를 빠르게 쓰니 잔여 한도를 보고 켜세요.

## 키 지키기

- 키를 Discord, 스크린샷, 로그, 문의에 올리지 마세요.
- 키가 노출되면 OpenSea에서 폐기하고 앱에서도 지우세요.
- 문의할 때는 가려진 키 행, 상태, 앱 버전, 실패한 시각을 보내세요.
