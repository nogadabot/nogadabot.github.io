# 사용자 체인 추가

내장 목록에 없는 EVM 체인을 넣습니다. **설정 → 발사 엔진 → 사용자 체인 추가**를 씁니다.

## 추가하기

1. 작동하는 RPC URL을 붙여넣고 **감지**를 누릅니다.
2. 앱이 `eth_chainId`를 부르고, 알려진 정보를 찾아 채웁니다.
3. 체인 ID, 이름, 네이티브 심볼, 익스플로러(선택)를 확인합니다.
4. 추가합니다.

RPC URL, 체인 ID, 이름, 심볼은 꼭 필요합니다. 같은 체인 ID는 넣을 수 없습니다. RPC, 이름, 심볼, 익스플로러는 나중에 고칠 수 있습니다. 체인 ID는 고칠 수 없으니 지우고 다시 넣으세요.

> **주의**: 앱은 네이티브 토큰을 소수점 18자리로 봅니다. 감지 때 다른 값이면 경고합니다. 저장은 되지만 잔액과 금액이 틀리게 보일 수 있습니다.

## 사용자 체인에서 되는 것

고르는 곳에 나오고, 넣은 RPC와 익스플로러를 씁니다. 나눠 보내기 컨트랙트, Multicall3, NFT 일괄 도우미, 마켓과 인덱서, 체인 전용 모듈은 저절로 생기지 않습니다.

기본 호출은 되어도 일부 도구는 안 될 수 있습니다. 큰 작업 전에 잔액 읽기와 소액 거래를 먼저 시험하세요. 경쟁 민팅에는 RPC 메뉴에 전용 RPC를 넣으세요.

체인을 지우면 이 PC의 항목만 지워집니다. 이미 보낸 거래에는 영향이 없습니다.
