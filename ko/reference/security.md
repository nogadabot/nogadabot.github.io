# 보안과 개인정보

중요한 데이터는 이 PC에 암호화해 두고, 업데이트 파일은 설치 전에 검증하며, 라이선스는 서버에서 PC에 묶습니다.

## 로컬 암호화

`wallets.dat`, `rpc.dat`, `proxies.dat`, `accounts.dat`, `opensea_developer_keys.dat`는 Windows DPAPI로 암호화됩니다. 이 PC와 이 Windows 사용자에 묶입니다. 평소 앱 비밀번호를 묻지 않습니다.

## 암호화하지 않는 파일

`tasks.json`, 라이선스 상태, `flashbots.key`, NFT 캐시, 손익 설정과 배경, 계정 인증 상태, 브라우저 프로필, 로그는 암호화하지 않습니다. 지갑 개인키는 들어가지 않습니다. 브라우저 프로필에는 사이트 쿠키가 있으니 Windows 사용자 프로필 전체를 민감하게 다루세요.

## 서버가 받는 것과 받지 않는 것

- **받지 않음**: 지갑 개인키. 서명은 언제나 이 PC에서 합니다.
- **받음**: 라이선스 확인에 필요한 키와 기기 식별값.
- **문제 보고**: 앱 화면 오류는 진단을 위해 민감한 값을 가려 보냅니다. **로그 보내기**는 직접 눌렀을 때만 갑니다.

## 업데이트

앱은 릴리스 정보의 서명, 내려받은 파일의 서명, 버전 순서를 확인합니다. 서명된 옛 빌드도 받지 않습니다. 확인에 실패하면 적용하지 않고 까닭을 기록합니다.

## 라이선스와 기기

활성화하면 서버가 키를 이 PC의 기기 식별값에 묶습니다. 로컬 상태 파일을 지워도 서버의 묶임은 그대로입니다. [라이선스](../getting-started/license.md)

## 막지 못하는 것

- 내 Windows 사용자 권한으로 도는 악성코드
- 내 데스크톱을 조작할 수 있는 사람
- 뚫린 브라우저 프로필이나 계정 세션
- 개인키나 라이선스 키를 엉뚱한 곳에 넣게 하는 피싱

## 습관

- 민팅에는 소액 지갑을 쓰고, 큰 자산은 앱에 넣지 않은 지갑에 둡니다.
- 시드 문구와 개인키를 누구에게도 보내지 않습니다. 운영자도 묻지 않습니다.
- 공식 링크만 씁니다. 처음 보는 컨트랙트는 작은 지갑으로 먼저 시험합니다.
- 내보내기 파일과 클립보드의 키를 바로 지웁니다.
