# 문제 해결

먼저 작업 행, 알림, 창에 나온 오류 글을 그대로 보세요. 그 일에 필요한 것부터 확인합니다. 지갑 자금, RPC 상태, 프록시 상태, 계정 인증, API 키, 캡차 잔액, 인터넷입니다. 그런 다음 실패한 것만 다시 하세요.

## 설치와 실행

- **파일이 사라집니다.** 백신이나 브라우저가 지운 경우가 많습니다. 폴더를 제외 목록에 넣고 다시 받으세요.
- **SmartScreen이 막습니다.** **추가 정보 → 실행**을 누릅니다.
- **아무것도 안 열립니다.** [설치와 첫 실행](../getting-started/install.md)을 보세요.

## 라이선스

- **활성화가 안 됩니다.** 키에 공백이 없는지, 인터넷이 되는지 확인하세요.
- **다른 기기에서 사용 중입니다.** 운영자에게 기기 초기화를 요청하세요. [라이선스](../getting-started/license.md)
- **키를 못 받았습니다.** 스팸함을 보고, 구매한 이메일을 적어 운영자에게 문의하세요.

## 거래가 안 나갑니다

- **잔액**: 민팅 금액과 가스가 지갑마다 있는지 봅니다.
- **RPC**: RPC 메뉴에서 테스트합니다. 작업에서 고른 RPC가 그 체인의 것인지 봅니다.
- **가스**: 너무 낮지 않은지 봅니다. 가스 한도는 비워 두세요. [가스](../tasks/gas.md)
- **페이즈**: 열렸는지, 지갑에 자격이 있는지 봅니다.

## 거래가 계속 대기 중입니다

[부스트](../tasks/boost.md)로 더 높은 수수료로 교체하세요.

## ABI를 못 찾습니다

고른 체인의 검증 출처를 차례로 봅니다. **설정 → 연동 → Etherscan API 키**를 넣으면 조회 한도가 늡니다. 컨트랙트는 있는데 검증 ABI가 없으면 함수 시그니처나 Hex를 직접 넣으세요. 체인이 틀리면 코드가 없다고 나옵니다.

## 스마트 민트가 경로를 못 찾습니다

[스마트 민트](../tasks/smart-mint.md)의 "조회가 안 될 때"를 보세요.

## OpenSea 작업

[OpenSea 드롭](../tasks/opensea.md)의 문제 해결을 보세요.

## 로그 모으기

**설정 → 일반 → 앱 로그**에서 로그 폴더를 엽니다. 안전하다면 문제를 한 번 재현하고 대략의 시각을 적어 두세요. `nogada.log`, `tasks.log`, `funds-sessions.log`가 도움이 됩니다. 마지막 줄만 복사하지 말고 파일을 그대로 두세요. 원인은 더 앞에 있을 때가 많습니다.

## 문의할 때 보낼 것

- 무엇을 하려 했는지
- 화면의 오류 글과 대략의 시각
- 앱 버전과 Windows 버전
- 화면, 작업이나 모듈 이름, 체인, 공개 거래 해시나 지갑 주소
- 재현 순서

시드 문구, 개인키, 지갑 내보내기, 라이선스 키, API 키, 계정 토큰, 프록시 비밀번호, 백업 비밀번호는 보내지 마세요. 스크린샷의 민감한 칸도 확인하세요.

**로그 보내기**를 쓰면 민감한 값을 가린 묶음이 올라가고 ID가 나옵니다. 그 ID를 문의에 붙여 주세요.
