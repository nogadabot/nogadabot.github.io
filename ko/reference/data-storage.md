# 로컬 데이터와 내보내기

지갑, 계정, 작업, 설정, 캐시, 브라우저 프로필은 모두 앱을 돌리는 PC에 있습니다. Nogada 클라우드 계정은 없습니다.

## 저장 위치

| 데이터 | 위치 |
| --- | --- |
| 앱 데이터 | `%LOCALAPPDATA%\nogada\data` |
| 브라우저 프로필 | `%LOCALAPPDATA%\nogada\browser-profiles` |
| 로그 | `nogada.exe` 옆 `logs` 폴더 |

`wallets.dat`, `rpc.dat`, `proxies.dat`, `accounts.dat`, `opensea_developer_keys.dat`는 Windows DPAPI로 암호화됩니다. 이 PC와 이 사용자에 묶입니다.

작업과 화이트리스트 JSON, 캐시, 로그, 손익 표시 파일, 계정 인증 상태, 브라우저 프로필은 비밀 저장소가 아닙니다. 그래서 `.dat`만이 아니라 Windows 사용자 계정과 디스크 전체를 지키세요.

## CSV 내보내기와 백업의 차이

**설정 → 일반 → 데이터 내보내기**는 지갑, 계정, RPC, 프록시 가운데 하나를 암호화 없는 CSV로 내보냅니다. 안의 개인키와 자격 증명을 그대로 읽을 수 있습니다. CSV는 온전한 이전 수단이 아닙니다.

여러 데이터를 암호화해 옮기려면 [백업, 복원, 이전](backup-restore.md)을 쓰세요. 어느 쪽이든 공유 폴더에 두지 말고, 임시 사본은 지우세요.

## 지우기

지갑, 그룹, 작업, 화이트리스트, 브라우저 프로필을 지우면 이 PC에서 지워집니다. 휴지통은 없습니다. 크게 지우기 전에 백업을 받고, 백업 파일이 앱 데이터 폴더 밖에 있는지 확인하세요.

## 로그

로그에는 URL, 주소, 작업 오류가 들어갈 수 있습니다. 공유하기 전에 살펴보고, 문의할 때는 필요한 시간대만 보내세요. **설정 → 일반 → 로그 보내기**는 지갑 키, RPC API 키, 프록시 자격 증명을 뺀 묶음을 보냅니다.
