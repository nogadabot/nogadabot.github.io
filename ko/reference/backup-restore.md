# 백업, 복원, 이전

앱은 데이터를 어디에도 올리지 않으며 자동 백업도 없습니다. 지갑을 지우거나, PC를 바꾸거나, 위험한 변경을 하기 전에 **설정 → 일반 → 백업 및 복원**을 쓰세요.

## 백업 만들기

1. 8자 이상의 **백업 비밀번호**를 넣습니다.
2. **백업 내보내기**를 누릅니다.
3. `.nogada-backup` 파일을 이 PC가 아닌 곳에 둡니다.

비밀번호로 암호화됩니다. 비밀번호는 저장되지 않으며 잊으면 되찾을 수 없습니다.

## 백업에 들어가는 것

지갑, 계정과 인증 상태, RPC, 프록시, OpenSea 개발자 키, 작업, 화이트리스트, 손익 설정과 배경, 화면 설정과 즐겨찾기가 들어갑니다.

라이선스, 로그와 캐시, 브라우저 프로필과 세션은 들어가지 않습니다. 새 PC에서 다시 활성화하고 세션을 다시 연결하세요.

## 복원과 PC 옮기기

1. 새 PC에 Nogada를 설치하고 활성화합니다. [라이선스](../getting-started/license.md)
2. **백업 및 복원**에 비밀번호를 넣고 **백업 복원**을 누릅니다.
3. 백업 시각, 앱 버전, 내용 수를 확인합니다.
4. **복원 후 다시 시작**을 누릅니다.

복원은 이 PC의 데이터를 바꿉니다. 바꾸기 전에 지금 상태를 같은 비밀번호로 암호화해 되돌림 파일로 남기고, 앱을 닫습니다. 다시 켜서 지갑 수, 작업 그룹, 설정, RPC를 확인할 때까지 원본 백업과 되돌림 파일을 지우지 마세요.

`.dat` 파일을 다른 PC로 복사하지 마세요. Windows DPAPI에 묶여 있어 다른 PC에서 열리지 않습니다. 백업을 쓰세요.

> **주의**: 백업이나 키 내보내기 없이 지운 지갑은 되살릴 수 없습니다. 서버에 사본이 없습니다.
