# 자주 묻는 질문

## 어떤 체인을 지원하나요

이더리움과 주요 EVM 체인입니다. [지원 체인](chains.md)을 보세요. 목록에 없는 EVM 체인은 [직접 추가](custom-chains.md)할 수 있습니다. 솔라나와 비트코인은 지원하지 않습니다.

## Mac에서 되나요

아니요. Windows 앱입니다. Mac이라면 [Windows VPS](../getting-started/vps.md)를 쓸 수 있습니다.

## 지갑은 안전한가요

개인키는 이 PC에 Windows DPAPI로 암호화되어 저장되고 서버로 가지 않습니다. 그래도 민팅에는 소액 지갑을 쓰세요. [보안과 개인정보](security.md)

## RPC를 꼭 준비해야 하나요

아니요. 넣지 않아도 내장 공개 RPC로 돌아갑니다. 하지만 공개 RPC는 쉽게 막히므로 경쟁 민팅에는 유료 RPC를 권합니다. [RPC 제공사](../resources/nodes.md)

## 프록시, API 키, 캡차 키가 꼭 필요한가요

민팅 자체에는 필요 없습니다. 프록시는 지갑이 많은 사이트 요청에, OpenSea 키는 뷰어 구매와 민트 캘린더, API 방식 민팅에, 캡차 키는 캡차가 있는 소셜 모듈에 필요합니다.

## 라이선스는 어떻게 사나요

운영자의 판매 페이지에서 결제하면 이메일로 키가 옵니다. [라이선스](../getting-started/license.md)

## 여러 PC에서 쓸 수 있나요

키 하나는 PC 한 대에 묶입니다. 옮길 때는 운영자에게 기기 초기화를 요청하세요.

## 앱을 꺼도 작업이 도나요

아니요. 앱이 켜져 있어야 합니다. 계속 돌리려면 [Windows VPS](../getting-started/vps.md)를 쓰세요.

## 민팅 성공을 보장하나요

아니요. 가스, RPC 속도, 경쟁, 프로젝트 상태에 달려 있습니다. 준비를 잘할수록 확률이 올라갑니다.

## 자격이 없거나 잔액이 부족한데 왜 발사를 막지 않나요

자격과 잔액 정보는 참고용입니다. 앱이 모르는 변수(막판 화이트리스트 추가, 갑작스러운 오픈 등)가 있기 때문입니다. 최종 판단은 네트워크가 합니다.

## 환불되나요

설치가 아예 되지 않는 경우에 한해 도와드립니다. 민팅 결과는 환불 대상이 아닙니다.
