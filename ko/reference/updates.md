# 앱 업데이트

**설정 → 일반 → 업데이트**에서 설치된 버전을 보고 새 버전을 확인합니다. 앱은 릴리스 정보의 서명과 내려받은 파일의 서명, 해시를 확인한 뒤에만 앱을 바꿉니다.

## 동작

- **업데이트 확인**: 지금 확인합니다.
- **지금 업데이트**: 내려받아 확인하고 적용한 뒤 다시 켭니다.
- **시작할 때 강제 업데이트**: 켜면 라이선스 확인 뒤 새 빌드를 바로 적용합니다. 끄면 **지금 업데이트** 알림을 보여 줍니다.

## 실패할 때

앱을 고정된 쓰기 가능 폴더에 두고, 업데이트 서버에 닿는지 확인한 뒤 다시 켜서 확인해 보세요. 서명 확인에 실패하면 우회하지 마세요. **앱 로그**에서 업데이트 오류를 찾아 문의해 주세요. 비공식 사이트의 파일은 쓰지 마세요.
