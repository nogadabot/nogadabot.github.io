# 변경사항 (What's New)

최신 버전이 맨 위에 있습니다. 앱은 켤 때마다 자동으로 최신 버전으로 업데이트됩니다 — 설치는 [다운로드](getting-started/download.md) 참고.

## v0.9.36

- 과거 민팅 거래를 캡처했을 때 NFT가 서명 지갑이 아닌 주소로 발행된 사실이 확인되면 이제 작업을 만들거나 재시작할 수 없습니다. 일반 민팅 경로는 서명 지갑 수령으로 고정되며, 고급 ABI·Hex는 별도 민팅 수령자 설정 없이 입력한 calldata만 그대로 사용합니다.

## v0.9.35

- Smart Mint가 검증된 Blockscout ABI와 온체인 그룹 민팅을 사용하는 프로젝트 홈페이지 및 직접 컨트랙트를 지원하며 Robinhood Chain도 포함합니다. 그룹 가격·시작 상태·공급량·컬렉션 판매완료를 컨트랙트 사실로 표시하되 사용자의 페이즈 선택이나 발사를 막지 않습니다.
- 컨트랙트 ABI 조회가 사용자가 선택한 체인을 기준으로 지원 EVM 익스플로러와 검증 소스 대체 경로를 사용합니다. Smart Mint에서는 체인을 직접 선택하며, 작업 편집기는 올바른 컨트랙트를 입력하면 검증된 실행 함수를 자동으로 불러옵니다.
- 일반 조회형 민팅 경로는 민팅 거래에 서명한 지갑이 NFT를 받습니다. 앱과 봇에서 별도 민팅 수령자 설정을 제거했고, 다른 수령자를 저장한 예전 작업은 전송 전에 중지됩니다.
- 작업 편집기의 RPC 선택 화면에서 그룹 헤더가 RPC 이름과 URL 위에 겹치지 않습니다. 모든 체인에서 긴 RPC 이름·주소·연결 상태·선택 버튼을 읽기 쉽게 정리했습니다.
- Telegram Smart Mint는 링크나 컨트랙트 주소만 보내 시작하고, 조회 전에 사용자가 체인을 항상 버튼으로 확정합니다. 실제 페이즈·수량·발사 방식·예약·가스는 일반 설정 흐름의 버튼으로 고르며, 기존 한 줄 명령도 숙련 사용자용으로 계속 지원합니다.
- 미래 SeaDrop GTD·FCFS 작업은 설정 시점부터 바우처 도착까지 정확한 서명형 또는 allowlist 민트 함수를 유지합니다. 따라서 T0의 정상 바우처를 민트 방식 변경으로 오인하지 않고 즉시 전송합니다.
- Telegram의 페이즈·생성 작업·최종 결과 카드를 가격·한도·일정·지갑·성공·실패·확인 중·민팅 수량·짧은 트랜잭션 링크 중심으로 줄였고 nonce 및 보관 안내의 반복을 없앴습니다.

## v0.9.34

- Smart Mint가 지원되는 링크와 컨트랙트에서 프로젝트가 실제 등록한 민팅 페이즈를 조회합니다. 존재하지 않는 자동·Public·종료 페이즈를 만들어 표시하지 않으며, 적격 여부 추측으로 페이즈 선택이나 발사를 막지 않습니다.
- 앱과 텔레그램 봇은 서로 완전히 독립적으로 작동합니다. 같은 지갑을 양쪽에서 사용할 수 있지만 작업·상태·nonce 조정·인증 정보·실행은 공유하지 않으며, 동시 실행 시 온체인 nonce 충돌 가능성만 명확히 안내합니다.
- 예약한 GTD·FCFS·Public 작업은 오픈 전에 준비하고, 실제 페이즈 또는 바우처가 열리는 즉시 선택한 RPC 경로로 전송합니다. 발사 순간에 새로운 동기 대기를 추가하지 않습니다.
- 민팅 실행이 선택한 지갑·수신자·페이즈·수량·가격·calldata·가스를 정확히 보존합니다. 지원되는 다중 민팅 경로는 요청 수량을 몰래 줄이지 않고 추적 가능한 여러 거래로 정확히 나눠 실행합니다.
- 작업 상태와 민팅 결과가 저장된 실행 기록과 실제 receipt 근거를 따릅니다. 사용하지 않은 작업 상태가 저절로 바뀌거나 성공·실패·종료를 추측해 표시하던 문제를 막았습니다.
- OpenSea 드롭 링크와 컨트랙트 조회 안정성을 높였고, Smart Mint에서 만든 작업으로 자연스럽게 이동할 수 있게 했습니다. 앱과 봇의 페이즈·지갑·RPC·수신자·발사 안내도 더 명확해졌습니다.

## v0.9.33

- 민팅 발사가 더 빠르고 예측 가능해졌습니다. 앱과 텔레그램 봇은 각자 자기 지갑·가스·nonce·네트워크 경로·예약 거래를 독립적으로 준비하고, 발사 순간에는 새 온라인 대기 없이 전송합니다.
- Stable Smart Mint에 Fefer Genesis, GMCards, OmniHub public 민팅을 추가했습니다. 최신 가격과 승인 처리, 정확한 예약 실행, 안전한 재시작 복구를 함께 지원합니다.
- Stable에서 검증된 소유권 확인을 사용하는 일반 NFT 보유 조회·보내기·나눠 보내기를 지원합니다. OpenSea 마켓·SeaDrop·PnL은 데이터 경로가 독립 검증될 때까지 계속 닫혀 있습니다.
- 재시작·Safe·Boost·Flashbots·프록시·다중 RPC가 원래 지갑·거래·경로·공개 여부를 정확히 보존해 중복 전송이나 의도하지 않은 공개 전송을 막습니다.
- 텔레그램 봇은 잔액을 백그라운드에서 불러와 화면 응답을 유지하고, 민팅 게이트가 닫힌 동안 자동 가스를 갱신하며, 폐기된 OpenSea 키는 즉시 메모리에서도 제거합니다.
- 서버를 업데이트할 때 이전 버전에서 만든 대기 중인 텔레그램 민팅·승인 기록도 그대로 보존합니다.

## v0.9.32

- 체인별 가스 안내를 바로잡았습니다. Stable은 계속 우선 수수료를 0으로 전송하고, Robinhood는 사용자가 선택한 가스를 그대로 사용합니다. Public·GTD·FCFS는 프로젝트의 민팅 방식입니다.
- Base·Optimism·Ink·Shape에서 봇 지갑 잔액을 전부 회수할 때 L1 수수료용 소액을 남겨, 네트워크 수수료 부족으로 전송이 실패하지 않도록 개선했습니다.

## v0.9.31

- Robinhood Chain과 Stable을 추가했습니다. Robinhood에서는 NFT·PnL·OpenSea 기능을 사용할 수 있고, Stable에서는 USDT0 가스로 민트와 전송을 지원합니다. Stable의 OpenSea NFT·PnL 기능은 해당 조회 경로가 검증될 때까지 숨겨집니다.
- 가스 처리를 체인별로 맞췄습니다. Stable은 우선 수수료를 0으로 전송합니다. Robinhood는 사용자가 선택한 가스 설정을 그대로 사용하며, 체인의 거래 도착 순서와 프로젝트의 Public/GTD/FCFS 민팅 페이즈는 서로 별개입니다.

## v0.9.30

- PnL 결과를 더 믿기 쉽게 개선했습니다. 정확·추정·일부 결과를 분명히 구분하고, 빠진 근거를 알려주며, 확인할 수 없는 내역을 거짓 0으로 표시하지 않습니다.
- 문제가 생겨도 더 빠르게 복구할 수 있습니다. 쉬운 해결 안내를 따라 실패한 지갑만 다시 시도하고, 발사 전 작업 준비 상태를 확인하거나 필요하면 이전 작업 버전으로 되돌릴 수 있습니다.
- 활동 타임라인과 작업 전후 지갑 잔액 비교가 더 선명해졌고, 작업 기록과 변경 내역을 검색해 무슨 일이 있었는지 빠르게 확인할 수 있습니다.
- 저장한 수령주소, 가져오기 미리보기, 더 빠른 검색, 화면 공유 때 민감한 정보를 가리는 개인정보 보호 기능으로 주소가 많은 작업이 더 빠르고 안전해졌습니다.
- 관리자·운영 기능도 더 안전하고 유용해졌습니다. 고객 정보는 가린 참조값으로 다루고, 대기열과 감사 기록을 쉽게 확인하며, 백업 검사와 서비스 상태 알림을 자동화했습니다.

## v0.9.29

- 지원하는 모든 민팅 플랫폼에서 지갑·체인·가격·수량·수령주소와 발사 내용이 작업 시작부터 완료까지 정확히 유지되어 민팅 신뢰도가 향상됐습니다.
- 많은 지갑과 RPC에서도 더 빠르게 발사합니다: 네트워크·가스 준비를 미리 끝내고 불필요한 대기열을 줄였으며, 첫 트랜잭션 전에 새 온라인 대기를 추가하지 않았습니다.
- 정지·재시작·부스트가 이제 해당 작업의 트랜잭션만 이어가거나 교체해, 중복 민팅이나 다른 대기 트랜잭션의 잘못된 변경을 방지합니다.
- NFT 전송·리스팅·오퍼·자금 분배·회수가 타임아웃 후에도 정확히 복구되고, 실제 온체인 결과를 더 정확하게 표시합니다.
- 예약 실행·지갑 관리·라이선스·결제·업데이트·백업·상태 화면 전반과 텔레그램 봇의 안정성을 개선했습니다.

- 오픈씨 링크를 붙여넣을 때 간헐적으로 빨간 오류가 뜨던 문제 수정 — 첫 시도에서 실패하지 않고 등록된 RPC로 자동 재시도합니다.
- 커스텀 가스 안전화: 최대 수수료를 설정하면 팁이 그 안에 유지되어 네트워크가 민트를 거부하지 않습니다.
