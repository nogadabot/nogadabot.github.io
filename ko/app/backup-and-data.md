# 백업과 데이터

이 쪽의 기능은 모두 **설정 → 일반**에 있습니다. 하려는 일에 따라 나눠 적었습니다.

## 새 PC로 옮기기

1. 쓰던 PC의 **백업 및 복원**에서 **백업 비밀번호**에 8자 이상을 넣고 **백업 내보내기**를 눌러, 새 PC에서 꺼낼 수 있는 곳에 파일을 저장합니다. 비밀번호는 어디에도 남지 않으니, 잊으면 그 파일은 열 수 없습니다.
2. [내 라이선스](https://nogada.app/dashboard)에서 **기기 초기화**를 눌러 키를 옮길 수 있게 합니다(24시간에 한 번).
3. 새 PC에서 앱을 받고 키를 활성화합니다. → [내려받기와 첫 실행](../getting-started/install.md)
4. 그곳의 **백업 및 복원**에서 그 백업의 비밀번호를 넣고 **백업 복원**을 눌러 파일을 고릅니다. 보여 주는 개수(지갑, 작업 등)를 확인하고 **복원 후 다시 시작**을 누릅니다.
5. 백업에 안 들어가는 것을 아래 표를 보고 다시 합니다.

데이터 폴더를 그냥 복사하는 방법은 통하지 않습니다. 지갑, 계정, RPC, 프록시, OpenSea API 키는 Windows 계정으로 암호화되어 있어서 다른 PC에서는 열리지 않습니다.

### 백업에 들어가는 것

| 항목 | 백업에 들어가나 |
|---|---|
| 작업 | 들어갑니다 |
| 지갑 | 들어갑니다 |
| 계정 | 들어갑니다. 계정별 브라우저 프로필은 빠지니 필요한 곳은 Google 연결을 다시 합니다. |
| 마켓 관심 컬렉션 | 들어갑니다 |
| 손익 카드 배경 | 들어갑니다 |
| RPC, 프록시 | 들어갑니다 |
| OS API 메뉴의 OpenSea API 키 | 빠집니다. 다시 넣습니다. |
| 앱 설정 | 들어갑니다 |
| 라이선스 활성화 | 빠집니다. 새 PC에서 키를 활성화합니다. |

### 복원하면 일어나는 일

복원은 이 PC의 옮길 수 있는 데이터를 백업에 든 것으로 갈아 끼웁니다. 원래 있던 데이터는 먼저 암호화된 되돌림 사본으로 남겨 두므로 말없이 사라지지 않습니다. 그다음 앱이 닫히고, 다시 켜면 복원된 데이터로 시작합니다. 이 PC의 라이선스 활성화와 브라우저 프로필은 그대로 둡니다.

## PC나 VPS를 남에게 넘길 때

**위험 구역: 모든 데이터 지우기**는 이 앱이 이 PC에 저장한 모든 것을 되돌릴 수 없게 지웁니다. 지갑(개인키), 계정(토큰, 쿠키), RPC, 프록시, API 키, 라이선스 활성화, 작업, 브라우저 프로필이 모두 사라집니다. 확인 칸에 `WIPE`를 입력해야 실행되고, 끝나면 앱이 닫힙니다.

앱만 지워서는 이렇게 되지 않습니다. 데이터가 디스크에 남습니다. 지우기 전에 지갑 키를 다른 곳에 보관했는지 꼭 확인하세요.

## 목록을 다른 프로그램으로 가져갈 때

**데이터 내보내기**는 한 종류의 데이터를 CSV 파일로 씁니다. **지갑**(키와 주소), **계정**(계정 정보와 자격 증명), **RPC**(URL과 API 토큰), **프록시**(호스트와 자격 증명) 가운데 고릅니다. 목록을 스프레드시트나 다른 도구로 가져갈 때 씁니다.

이 파일은 그냥 글자 파일이라, 여는 사람은 누구나 안의 개인키와 비밀번호를 읽을 수 있습니다. 다 쓰면 지우세요.

## 로그아웃

**로그아웃**은 실행 중인 작업을 멈추고 라이선스 화면으로 돌아갑니다. 다음에 켜면 키를 다시 넣어야 합니다. 서버의 PC 묶임은 풀리지 않으니, 다른 PC에서 키를 쓰려면 [라이선스](../getting-started/license.md)의 기기 초기화를 하세요.

## 로그

- **로그 보기**: 실행 파일 옆의 로그 폴더를 엽니다.
- **로그 보내기**: 민감한 값을 가린 압축 묶음을 Nogada 지원팀에 올립니다. 지갑 키, RPC API 키, 프록시 자격 증명은 들어가지 않습니다. 함께 보낼 것은 [막혔을 때](../help/when-stuck.md)에 있습니다.

## 파일이 있는 곳

| 무엇 | 위치 |
|---|---|
| 앱 기록(로그) | 실행 파일 옆 `logs` 폴더 |
| 지갑, 계정, RPC, 프록시, OpenSea API 키, 작업, 설정 | `%LOCALAPPDATA%\nogada\data` |
| 계정별 브라우저 프로필(Google 연결 등) | `%LOCALAPPDATA%\nogada\browser-profiles` |

## 안전하게 쓰기

- 개인키와 거래 서명은 이 PC를 떠나지 않습니다.
- 개인키를 복사하는 기능(지갑의 **개인키 복사**, 편집 창의 복사 버튼, CSV)은 클립보드나 파일에 키를 남깁니다. 쓰고 나면 클립보드를 지우고 파일을 지우세요.
- 민팅에는 큰돈이 없는 전용 지갑을 쓰고, 번 돈은 따로 둔 지갑으로 옮기세요. 스마트 민트의 **민팅 후 안전 지갑으로 스윕**이나 작업의 **NFT 보내기** 동작이 도움이 됩니다.
