# OpenSea 드롭

OpenSea 컬렉션 링크로 민팅 작업을 만드는 법입니다. 앱이 컬렉션과 판매 정보를 채우므로 페이즈, 지갑, 수량, 가격 상한, RPC, 가스, 시간만 고르면 됩니다.

## 시작 전 준비

- 공식 OpenSea 컬렉션 링크. 보통 `https://opensea.io/collection/slug` 꼴입니다.
- 앱에 넣고 그 체인에 자금을 넣은 지갑. 무료 민팅도 가스가 듭니다.
- 그 체인의 RPC 하나 이상. 경쟁이 있으면 유료 RPC를 권합니다.
- 지갑이 많다면 프록시 그룹.
- OpenSea API 방식을 쓸 때는 [OpenSea API 키](../setup/opensea-api.md).

작업 칸에 시드 문구나 개인키를 넣지 마세요. 키는 [지갑](../setup/wallets.md) 가져오기로만 넣습니다.

## 만드는 순서

1. **작업 → EVM → 새 작업**이나 [스마트 민트](smart-mint.md)를 엽니다.
2. 공식 링크를 붙여넣습니다.
3. **민팅 페이즈** 칸이 나올 때까지 기다립니다. 불러오는 중에는 만들지 마세요.
4. 체인과 컨트랙트가 맞는지 확인합니다.
5. 페이즈를 고릅니다.
6. **모드**를 고릅니다.
7. 필요하면 **프록시 그룹**을 고릅니다.
8. **NFT 수량**을 넣습니다. 지갑마다의 수량입니다.
9. **NFT당 가격**을 확인합니다. 한 개의 최대 가격이며 전체 합계가 아닙니다.
10. 지갑과 RPC를 고르고, 가스와 시간, 방식을 정합니다.
11. 만든 뒤 시작합니다.

지갑을 20개 고르고 NFT 수량을 2로 하면 지갑 20개가 각자 2개까지 시도합니다.

## 확인할 것

| 항목 | 확인 |
| --- | --- |
| 링크 | 공식 OpenSea 페이지인지, 비슷한 가짜 주소가 아닌지 |
| 체인 | 민팅이 열리는 체인인지 |
| 컨트랙트 | 프로젝트가 공개한 주소와 맞는지 |
| 페이즈 | 공개나 화이트리스트 단계가 있는지, 시각이 맞는지 |
| 가격 | 공지와 같은지 |

하나라도 이상하면 멈추고 공식 링크와 공지를 다시 확인하세요.

## 페이즈 고르기

한 컬렉션에 여러 페이즈가 있을 수 있습니다. 공개 여부, 시각, 가격, 지갑당 한도가 다릅니다. 내 지갑이 자격이 있는 페이즈를 고르세요. 페이즈를 바꾸면 가격이 바뀔 수 있으니 다시 확인하세요. 작업에 넣는다고 자격 없는 지갑이 자격을 얻지는 않습니다.

## 모드

| 모드 | 언제 쓰나 |
| --- | --- |
| 익명 모드 | 로그인 없이 프록시로 민팅 데이터를 받습니다. 스마트 민트의 기본입니다. 답을 못 받은 지갑에만 저장한 키를 씁니다. 드롭이 로그인을 요구하면 그때 로그인합니다 |
| 일반 모드 | 지갑으로 OpenSea에 로그인해 받습니다 |
| OpenSea API | 저장한 API 키로 받습니다. 키가 없으면 고를 수 없습니다 |
| 듀얼 모드 | 일반 경로와 API 경로로 함께 받아 먼저 온 답을 씁니다. 키가 없으면 고를 수 없습니다 |

공개 단계는 대개 OpenSea 요청 없이 온체인으로 바로 보냅니다. 준비가 필요한 단계는 작업이 준비 상태를 지나 **준비**가 된 뒤 발사합니다.

## 프록시

- 지갑별로 OpenSea 준비가 필요한 단계에서 중요합니다.
- 지갑 수에 맞게 프록시를 넉넉히 넣으세요.
- 많은 지갑이 한꺼번에 준비에 실패하면 작업을 다시 만들기 전에 프록시 그룹부터 테스트하세요.
- 오픈 직전에는 잘 되는 프록시를 바꾸지 마세요.

## 수량과 가격

- **NFT 수량**은 1 이상의 정수입니다. 지갑당 한도를 넘기지 마세요. 이미 민팅한 만큼 남은 한도가 줄어듭니다.
- **NFT당 가격**은 페이즈가 채워 줍니다. 실제로 무료일 때만 0을 쓰세요.
- 지갑에 필요한 잔액은 `NFT당 가격 × NFT 수량 + 가스 여유`입니다.

## 민팅 뒤 동작

연사가 아닌 작업에 NFT 보내기, NFT 올리기, 오퍼 수락을 붙일 수 있습니다. 처음 쓰는 설정은 작은 지갑으로 먼저 시험하세요.

## 시작 전 점검

- [ ] 공식 OpenSea 링크
- [ ] 체인과 컨트랙트
- [ ] 페이즈
- [ ] 자격 있는 지갑
- [ ] 지갑당 한도 안의 수량
- [ ] NFT당 가격
- [ ] 지갑마다 민팅 금액과 가스
- [ ] 그 체인의 정상 RPC
- [ ] 방식에 맞는 가스
- [ ] 타임스탬프와 시간대
- [ ] 연사라면 최대 거래 수와 끝 시각

## 복제와 편집

저장된 OpenSea 작업은 링크, 체인, 페이즈가 잠길 수 있습니다. 지갑, RPC, 가스, 시간, 수량, 가격 상한, 프록시 그룹은 바꿀 수 있습니다. 복제한 작업은 페이즈와 가격을 다시 확인하세요.

## 문제 해결

**링크를 읽지 못합니다.** `opensea.io/collection/`이 들어 있는지, 앞뒤에 공백이 없는지 보고 추적 파라미터를 지운 깨끗한 링크를 넣으세요.

**계속 불러오는 중입니다.** 잠시 뒤 다시 붙여넣으세요. 인터넷을 확인하고, 키나 프록시를 쓴다면 테스트하세요. 창을 닫았다 열어도 됩니다.

**페이즈가 안 나옵니다.** 민팅 단계가 없거나 작성자가 바꿨을 수 있습니다. 아이템 페이지가 아니라 컬렉션 페이지를 넣었는지 확인하세요.

**OpenSea API를 고를 수 없습니다.** 키가 없습니다. 다른 모드를 쓰세요.

**키가 거절되거나 한도에 걸립니다.** [OS API](../setup/opensea-api.md)에서 테스트하고 만료된 키를 지우세요. 한도 메시지 뒤에는 잠시 기다리세요.

**지갑 준비가 멈추거나 실패합니다.** 지갑 자격, 프록시 그룹, PC 시계를 확인하세요. 모든 작업을 다시 만들지 말고 실패한 지갑만 재시도하세요.

**잔액이 부족합니다.** 지갑마다 민팅 금액과 가스 여유가 따로 필요합니다. 민팅 뒤 동작의 가스도 남겨 두세요.

**화이트리스트인데 자격이 없다고 나옵니다.** 정확한 페이즈를 골랐는지, 주소가 같은지, 이미 몫을 썼는지, 프로젝트가 목록을 바꿨는지 확인하세요.

**페이즈가 안 열렸습니다.** 공식 시각과 타임스탬프, 시간대를 비교하세요. 정확한 시각을 모르면 시뮬레이션을 쓰세요.

**RPC 시간 초과나 한도 오류입니다.** 정상 유료 RPC로 바꾸고, 다른 체인의 RPC를 지우세요.

**거래가 되돌려집니다(리버트).** 페이즈 시작 전이나 종료 뒤, 자격 없음, 한도 초과, 이미 민팅함, 가격 상승, 잔액 부족, 낮은 가스 한도, 맞지 않는 nonce가 흔한 원인입니다. 고치기 전에 같은 작업을 반복해도 나아지지 않습니다.

**nonce가 낮다거나 교체 오류가 납니다.** 지갑의 대기 거래를 확인하고 논스를 자동으로 되돌리세요. 같은 지갑으로 여러 작업을 동시에 돌리지 마세요.

**성공인데 NFT가 안 보입니다.** 거래 해시를 익스플로러에서 열어 전송을 확인하세요. OpenSea와 지갑의 색인은 늦을 수 있습니다.

**리스팅이나 오퍼 수락이 실패합니다.** 키, NFT 소유와 승인, 기간, 오퍼 유효 여부, 가스를 확인하세요.

## 문의할 때 보낼 것

앱 버전, OpenSea 링크, 체인과 페이즈 이름, 작업 이름과 대략의 시각, 실패한 공개 주소, 화면의 오류 글, 거래 해시, 민감 정보를 가린 스크린샷을 보내 주세요. 시드 문구, 개인키, 지갑 내보내기, 라이선스 키, API 키는 절대 보내지 마세요.
