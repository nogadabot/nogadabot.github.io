# 작업 방식

방식은 거래를 언제, 어떻게 보낼지 정합니다. 스마트 민트의 **즉시 1회**는 시뮬레이션을 끈 작업이고, **안전 (시뮬레이션 후)**은 시뮬레이션 작업이며, **연사 (반복)**은 연사 작업입니다.

## 즉시 (시뮬레이션 꺼짐)

한 번 서명해 바로 보냅니다. 이미 열린 민팅, 평범한 컨트랙트 호출, 시각을 정확히 아는 작업에 씁니다. 닫힌 민팅에 쓰면 실패합니다.

## 시뮬레이션

같은 호출 데이터와 금액으로 `eth_call`을 반복하다가 실패하지 않게 되면 실제 거래를 보냅니다.

- 호출이 실패하면 계속 다시 해 봅니다.
- 성공하면 바로 서명해 보냅니다.

즉시보다 한 단계 늦지만, 정확한 오픈 시각을 모르는 드롭에 안전합니다. 재시도 간격은 **지연** 칸입니다. 드라이런만 하는 모드가 아니라 결국 거래를 보내는 대기 방식입니다.

## 연사

블록이 아주 빠른 체인에 좋습니다. 오픈 몇 초 전부터 몇 초 뒤까지 거래를 많이 보내 하나가 들어가기를 노립니다.

연사를 켜면 이렇게 바뀝니다.

- 가스 한도, 최대 수수료, 우선 수수료를 채워야 합니다.
- **최대 거래 수** 칸이 나옵니다.
- **타임스탬프**에 `시작-끝`을 쓸 수 있습니다.

아래 가운데 하나가 일어날 때까지 계속 보냅니다.

| 멈추는 조건 | 뜻 |
| --- | --- |
| 성공 | 영수증 상태가 1입니다 |
| 최대 거래 수 | 정한 수에 닿았습니다 |
| 끝 시각 | `시작-끝`의 끝이 지났습니다 |
| 연사 안전 한도 | 설정의 한도에 닿았습니다 |
| 중지 | 직접 멈췄습니다 |

## 연사 + Flashbots

이더리움 메인넷에서 작업의 Flashbots를 켜면 공개 멤풀 대신 번들로 보냅니다. 놓친 시도는 가스를 내지 않고 nonce도 쓰지 않습니다.

## 고르는 법

| 상황 | 방식 |
| --- | --- |
| 이미 열렸다 | 즉시 |
| 시각을 정확히 안다 | 즉시 + 타임스탬프 |
| 언제 열릴지 모른다 | 시뮬레이션 |
| 블록이 빠르고 경쟁이 심하다 | 연사 |
| 이더리움 메인넷에서 실패 비용을 피하고 싶다 | 연사 + Flashbots |
