# 캡처 확장

Nogada 캡처는 Chrome과 Edge에 넣는 확장입니다. 익스플로러나 민팅 사이트의 호출을 잡아 `nogada-v1://` 프로토콜로 앱에 넘깁니다.

## 설치

1. **설정 → 연동 → Nogada 캡처 브라우저 확장**에서 **확장 내려받기**를 누릅니다.
2. 압축을 고정된 폴더에 풉니다.
3. `chrome://extensions`나 `edge://extensions`를 엽니다.
4. **개발자 모드**를 켭니다.
5. **압축 해제된 확장 프로그램 로드**로 그 폴더를 고릅니다.

쓰기 전에 Nogada를 한 번 켜세요. 켤 때 프로토콜을 등록합니다.

## 무엇을 잡나요

| 종류 | 앱으로 보내는 것 |
| --- | --- |
| Hex | 대상, 호출 데이터, 금액, 출처 URL |
| 함수 | 컨트랙트, 함수 이름과 시그니처, 보이는 인자, 금액 |

Hex는 작업 창을 Hex 모드로 엽니다. 함수는 그 함수의 ABI를 만들어 함수 모드로 엽니다. 빠진 인자를 채운 뒤 저장하세요.

수수료는 보내지 않습니다. 단위 실수를 막으려고 앱의 기본값이나 자동 값으로 시작합니다.

## 열리는 방식

Nogada가 켜져 있으면 열린 창에서 작업 창이 뜹니다. 꺼져 있으면 Windows가 앱을 켜고, 앱이 받은 값을 씁니다.

## 개인정보와 안전

- 확장은 거래에 서명하지 않습니다.
- 지갑 승인을 건너뛰지 않습니다.
- 마지막 캡처를 브라우저 저장소에만 둡니다.
- 앱과는 `nogada-v1://` 주소로만 이야기합니다.

## 문제 해결

- **눌러도 아무 일이 없습니다.** Nogada를 직접 한 번 켠 뒤 다시 해 보세요. 앱을 옮겼다면 **프로토콜 처리기 다시 등록**을 누르세요.
- **일부 인자가 비었습니다.** 확장은 페이지에 보이는 값만 읽습니다. 작업 창에서 채우세요.
- **가스 칸이 비었습니다.** 정상입니다. 가스는 앱의 작업 설정이 정합니다.
