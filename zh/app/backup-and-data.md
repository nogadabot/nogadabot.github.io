# 备份与数据

本页的功能都在 **设置 → 常规** 中，按你要做的事分开整理。

## 换到新电脑

1. 在旧电脑的 **备份与恢复** 中，在 **备份密码** 填写至少 8 个字符，点击 **导出备份**，把文件存到新电脑能拿到的地方。密码不会保存在任何地方，忘了密码这个文件就打不开。
2. 在 [我的许可证](https://nogada-lic.duckdns.org/dashboard) 点击 **重置设备**，让密钥可以转移（每 24 小时一次）。
3. 在新电脑上下载应用并激活密钥。→ [下载与首次启动](../getting-started/install.md)
4. 在新电脑的 **备份与恢复** 中填写该备份的密码，点击 **恢复备份** 并选择文件。确认显示的数量（钱包数、任务数等），点击 **恢复并重启**。
5. 对照下表，把备份不包含的内容重新设置一遍。

直接复制数据文件夹是行不通的：钱包、账户、RPC、代理和 OpenSea API 密钥用你的 Windows 账户加密，在其他电脑上打不开。

### 备份包含哪些内容

| 项目 | 是否在备份中 |
|---|---|
| 任务 | 包含 |
| 钱包 | 包含 |
| 账户 | 包含。各账户的浏览器配置文件不包含，需要时重新连接 Google。 |
| 市场关注的系列 | 包含 |
| 盈亏卡片背景 | 包含 |
| RPC、代理 | 包含 |
| OS API 页面中的 OpenSea API 密钥 | 不包含。需要重新添加。 |
| 白名单管理器条目 | 包含 |
| 应用设置 | 包含 |
| 许可证激活 | 不包含。在新电脑上激活密钥。 |

### 恢复会做什么

恢复会把这台电脑上可迁移的数据换成备份里的内容。原有数据会先保存为一份加密的回滚副本，不会悄悄丢失。随后应用关闭，再次打开即使用恢复后的数据。这台电脑上的许可证激活和浏览器配置文件保持原样。

## 把电脑或 VPS 交给别人时

**危险区域：清除所有数据** 会永久删除这个应用在这台电脑上保存的所有内容：钱包（私钥）、账户（令牌、Cookie）、RPC、代理、API 密钥、许可证激活、任务和浏览器配置文件。需要在确认栏输入 `WIPE` 才会执行，完成后应用会关闭。

只删除 exe 做不到这一点，数据仍会留在硬盘上。清除前务必确认钱包密钥已另外保存。

## 把列表带到其他程序

**导出数据** 把一类数据写成 CSV 文件，可以选择 **钱包**（密钥和地址）、**RPC**（URL 和 API 令牌）或 **代理**（主机和凭据）。用于把列表导入电子表格或其他工具。

这个文件是纯文本，任何打开它的人都能读到里面的私钥和密码。用完请删除。

## 退出登录

**退出登录** 会停止正在运行的任务并回到许可证页面，下次需要重新输入密钥。服务器上的电脑绑定不会解除，要在其他电脑上使用密钥，请按 [许可证](../getting-started/license.md) 中的说明重置设备。

## 日志

- **显示日志**：打开 exe 旁边的日志文件夹。
- **发送日志**：把已脱敏的压缩包上传给 Nogada 支持团队，绝不包含钱包密钥、RPC API 密钥和代理凭据。还需要一起发送什么，见 [遇到问题时](../help/when-stuck.md)。

## 文件位置

| 内容 | 位置 |
|---|---|
| 应用日志 | exe 旁边的 `logs` 文件夹 |
| 钱包、账户、RPC、代理、OpenSea API 密钥、任务、设置 | `%LOCALAPPDATA%\nogada\data` |
| 各账户的浏览器配置文件（连接 Google 等） | `%LOCALAPPDATA%\nogada\browser-profiles` |

## 安全使用

- 私钥和交易签名不会离开这台电脑。
- 复制私钥的功能（钱包的 **复制私钥**、编辑窗口的复制按钮、CSV）会把密钥留在剪贴板或文件中。用完后请清空剪贴板并删除文件。
- 铸造使用资金不多的专用钱包，赚到的钱转到另外的钱包。智能铸造的 **铸造后归集至安全钱包** 和任务的 **转移 NFT** 操作可以帮上忙。
