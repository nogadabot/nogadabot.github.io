# 密钥、数据与执行范围
## 应用与机器人的区别
应用私钥使用 Windows DPAPI 在本地加密；机器人私钥在服务器上加密保存。两者不共享钱包、任务或 nonce 状态。

加密不能消除所有风险。导出的密钥、剪贴板内容和截图需要单独保护，更换电脑前请确认恢复方式。

## 界面与分享
应用隐私模式会隐藏敏感显示，但不会取消交易或移动资产。充值二维码中是钱包地址，不是私钥。不要转发 Telegram 验证码或私钥导出消息。

## 执行前后
检查链、合约、数量、金额、接收钱包和所选选项。较高 Gas 或名称为 Safe 的模式不保证成功。删除、停止和重新执行任务，对已经发出的交易有不同影响。

## 备份与重置
仅将受 DPAPI 保护的数据库复制到另一台电脑，并不能保证恢复。解除设备绑定或重置前，请确认备份和私钥恢复方式。不要仅因查询失败就删除数据库或密钥文件。

时区、通知和登录偏好在各产品中独立管理，修改一个产品的个人设置不会自动改变另一个产品或其他用户的设置。
