# 常见问题
## 关闭应用后，机器人还能运行吗？
可以。机器人任务在服务器上独立运行；应用任务则需要保持电脑和应用运行。

## 我的机器人时区会影响其他用户吗？
不会。时区按私人聊天 ID 保存，应用使用电脑的 Windows 时区。参见[时区](../telegram/timezone.md)。

## 创建 Smart Mint 任务后会立即提交吗？
不会。创建任务后还需点击 Start，预约任务应提前点击 Start。

## 必须手动粘贴签名凭证吗？
支持的常规 OpenSea 签名路径会自动获取。未支持的自定义路径仍需要准确的执行数据。参见[签名铸造](../minting/whitelist.md)。

## 免费铸造完全不花费资金吗？
铸造价格为 0 时仍可能需要 Gas。ERC-20 付款与原生币 Gas 请分别核对。

## 未验证就是失败吗？
不是，它表示结果尚未得到验证。不要擅自当成零、失败或成功，应检查原交易和已有证据。

## 所有 EVM 链都能用吗？
请确认实际链列表和功能支持范围。链出现在列表中，不代表所有市场和 NFT 数据路径都已支持。

## 为什么看不到指南中的新按钮？
请检查[适用版本](../README.md)。标注为下次更新的功能尚未公开发布。购买、许可证和设备条件参见[激活说明](../getting-started/license.md)。
