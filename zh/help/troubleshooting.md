# 故障排查
## 列表为空或一直加载
请区分查询失败、上次数据和真正的空列表。先重试查询，不要因此重置钱包或任务数据。刷新列表与开始铸造是不同操作。

## 任务没有开始
检查预约时间、所选钱包、链/RPC、实际阶段和界面错误。Gas 上限、最高费用和 tip 错误对应不同设置，应修正相关字段，而不是在准备期间反复点击 Start。

## 交易一直待确认
先检查原交易哈希和回执。RPC 接收不代表已上链，再次 Start 可能创建新交易。使用应用中的 [Boost](../minting/boost.md) 前，请确认准确的待确认交易与费用。

## 回执成功，但铸造仍未验证
交易状态成功，也可能无法验证预期的 NFT 合约、接收钱包或数量。请查看区块浏览器和[结果汇总](../app-guide/results.md)。未验证结果不会自动重新铸造。

## 安装或验证失败
核对官方下载来源和 Windows 警告。许可证问题应检查购买邮箱、验证码有效期和设备限制。关闭杀毒软件或删除数据不是默认解决办法。

## 联系支持
请提供应用版本、链、任务编号、发生时间、界面错误和相关截图。遮挡私钥、验证码、许可证密钥以及完整 RPC 凭据。
