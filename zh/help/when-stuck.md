# 遇到问题时

按阶段整理了常见情况。这里解决不了的话，请看最后的“联系支持”。

## 启动与许可证

**应用打不开**

| 看到的情况 | 怎么做 |
|---|---|
| 双击后什么都没发生 | 可能已经在运行，第二次启动不会显示任何东西。找到已打开的窗口，或在任务管理器中结束 `nogada.exe` 后重新启动。 |
| 文件不见了，或 Windows 提示含有威胁 | 被杀毒软件拿走了。从杀毒软件的记录中恢复，并把应用文件夹加入排除项。 |
| 安装在同步文件夹（如 OneDrive）或网络驱动器上 | 卸载应用，再安装到默认文件夹这样的本地文件夹。钱包和任务在安装文件夹之外，会保留下来。 |

**显示“许可证检查暂不可用”**
表示多次尝试都没能连上许可证服务器，通常是短暂的网络问题。检查网络后点击 **立即重试**。已保存的密钥、电脑绑定和剩余时间都不会改变。

**输入密钥也无法激活**
- 确认密钥原样粘贴，前后没有空格。
- 在 [我的许可证](https://nogada.app/dashboard) 确认密钥是否已到期或被停用。
- 密钥绑定在其他电脑上时，在我的许可证中 **重置设备**（每 24 小时一次）。
- 显示“此电脑的时钟偏差超过一小时”时，请看下面。

**显示“此电脑的时钟偏差超过一小时”**
许可证服务器的应答里带有服务器时间，这台电脑的时钟与它相差超过一小时时，应用不接受该应答。在 Windows 中开启自动设置时间，然后重试。已保存的密钥会保留。启动应用时，同样的原因可能显示在“许可证检查暂不可用”页面的 **技术详情** 中。

**显示“如需在此电脑上使用，请重新输入密钥”**
表示这台电脑上保存了密钥，但没有这台电脑能打开的使用记录。把其他电脑或其他 Windows 账户的应用数据复制到这里时会出现。重新输入密钥即可。之前使用的电脑会在下一次许可证检查时停止。

**显示“此密钥已在另一台电脑上启用，本电脑的使用已结束”**
表示在设备 ID 相同的另一个地方启用了同一个密钥：复制或克隆的 Windows，或这台电脑上的其他 Windows 用户。一个密钥同一时间只在一个地方运行，所以这里已停止，正在运行的任务也一起停止。要在这里继续使用，请重新输入密钥，另一边就会停止。

**使用中回到了许可证页面**
应用每 15 分钟检查一次许可证，服务器拒绝密钥时（已到期、已停用、绑定在其他电脑上，或在设备 ID 相同的另一个地方启用）会回到许可证页面。只是短暂断网不会回到这个页面。

## 购买许可证

| 销售页面的提示 | 怎么做 |
|---|---|
| 金额不同或没有自动确认？ | 在订单页面下方填入转账交易的哈希，点击 **确认**。由运营者确认。 |
| 订单时间已过 | 已经转账的话稍等，或用交易哈希确认。还没转账就创建新订单。 |
| 未完成的订单太多 | 最多 3 个未完成订单。在我的许可证中取消一个。 |
| 今天创建的订单太多 | 超过了每天可创建的订单数。明天再试。 |
| 无法读取汇率 | 稍后重试，或用 USDC、USDT 付款。 |

## 智能铸造查询

| 代码 | 含义与处理 |
|---|---|
| R-NO-CODE | 该链的该地址上没有合约。检查链，或粘贴铸造合约地址。 |
| R-CHAIN-MISMATCH | 链接所属的链与所选链不同。切换链后重新查询。 |
| R-FN-NONE、R-FN-UNNAMED | 没有找到铸造函数。粘贴铸造合约或项目的铸造页面链接，或使用 ABI / Hex。 |
| R-FN-AMBIGUOUS | 有多个铸造函数。从列表中选择。 |
| R-VALUE-UNKNOWN | 无法读取价格。填写铸造价格。 |
| R-TOKEN-ID | ERC-1155 系列需要代币 ID。 |
| R-PROOF-UNVERIFIED | 需要白名单证明，但没有找到所选钱包的证明。试试添加白名单文件。 |
| R-AUTH-REQUIRED | 这次铸造需要项目网站为每个钱包签发的签名。 |
| R-LINK-BLOCKED、R-LINK-FETCH | 无法读取项目页面。直接粘贴铸造合约地址。 |
| R-RATE-LIMITED | 区块浏览器、项目服务器或 RPC 触发了请求限制。稍后重试或更换 RPC。 |
| R-TX-NOTFOUND | 在该链上找不到这笔交易。检查链。 |
| R-RPC | 无法连接链或项目服务器。检查 RPC 状态。 |
| R-BUDGET | 查询时间用完了。重试或减少钱包数量。 |
| R-HUMAN-CHECK | 网站要求验证码。需要在项目网站上自己铸造。 |
| R-POW-REQUIRED | 这次铸造需要为每个钱包进行计算（挖矿），应用不做这一步。 |
| R-RESOLVE | 因其他原因找不到路径。重试或使用 ABI / Hex。 |

## 任务

**显示“无 RPC，使用公共 RPC”**
该链没有保存 RPC。用公共 RPC 也能发送，但有竞争的铸造请添加 [RPC](../prepare/rpc-and-chains.md)。

**连发任务保存不了**
连发时最高费用、优先费和 Gas 上限不能设为自动。三栏都填上数字。

**因余额不足失败**
给钱包补足铸造价格和 Gas 所需的币，然后重新启动任务。需要多少请看 [Gas 计算器](../app/calculator.md) 的 **所需余额**。

**因 execution reverted 失败**
表示合约拒绝了这笔交易。常见原因是销售尚未开放、钱包没有资格，或价格、数量不对。想在开放前提前启动，可以开启模拟，让它在尝试通过时再发送。

**提示 RPC 余额或额度不足而停止**
任务的所有 RPC 都报告额度用完了。到 RPC 服务商充值，或添加其他 RPC。

**提示 OpenSea 价格高于我的最高价而停止**
发射时 OpenSea 给出的价格高于任务的 **每 NFT 价格**。如果那个价格没问题，就调高每 NFT 价格。

**提示 OpenSea 拒绝了这个钱包**
可能是没有资格、余额不足或临时错误。应用会重试几次后停止。

**无法编辑任务**
运行中的任务不能编辑。请先停止。

**开放时发得晚**
- 发射按电脑时钟计算。状态栏时钟旁显示差值时，请同步 Windows 时间。
- 提前启动任务，不要在开放前一刻才启动。
- 多添加几个 RPC，并试试开启 **多 RPC 广播**。

**已发送的交易一直不进块**
可能是 Gas 太低。用任务页面底部栏的 [加速](../tasks/running.md#加速) 提高。

## NFT 与市场

**上架、接受报价、取消挂单按钮处于关闭状态**
需要 OpenSea API 密钥。在 [OS API](../prepare/opensea-keys.md) 中添加。

**持仓上方显示“N 个错误”**
部分钱包没有读取成功。过一会儿刷新。持续出现时请检查该链的 RPC。

**盈亏无法计算**
可能是不支持的链。在 Alchemy 支持的链上，请在 RPC 菜单或 **设置 → 集成 → PnL Alchemy URL** 中添加 Alchemy 地址。

**市场什么都不显示**
检查 **设置 → 集成 → 市场中心** 的状态并刷新。

## 常见问题

**能在 Mac 上用吗？** 不能。这是 Windows 应用。使用 Mac 时可以用 Windows VPS。→ [下载与首次启动](../getting-started/install.md#在-vps-上运行)

**能在哪些链上铸造？** 以太坊和 EVM 链。列表见 [RPC 与链](../prepare/rpc-and-chains.md#支持的链)，没有的 EVM 链可以自己添加。

**关闭应用后任务还会运行吗？** 不会。任务在应用内运行。

**一个密钥能在两台电脑上用吗？** 不能。一个密钥同一时间只在一台电脑上运行。用相同的设备 ID 再次启用会结束之前的一方，设备 ID 不同的电脑需要先 **重置设备**。→ [许可证](../getting-started/license.md#一个密钥对应一台电脑)

**显示钱包没有资格，为什么不阻止我？** 应用显示的资格和余额是帮助你判断的信息。发不发由你决定，最终结果由链决定。在智能铸造中选择 **安全（先模拟）**，模拟会失败的钱包会被跳过。

**保证铸造成功吗？** 不保证。取决于 Gas、RPC、竞争和项目情况。

**可以退款吗？** 数字商品，不支持退款。→ [使用条款与隐私](terms-and-privacy.md)
