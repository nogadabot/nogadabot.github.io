# 使用条款与隐私

这里简要说明购买和使用 Nogada 的规则，以及应用发送到我们服务器的内容。有疑问请看 [联系支持](when-stuck.md#联系支持)。

## 购买许可证

- 在 [销售页面](https://nogada.app/buy) 用加密货币付款：Ethereum 或 Base 网络上的 ETH、USDC、USDT。不会自动续费。
- 数字商品，不支持退款。多付的部分也不予退还。
- 铸造成功与否取决于 Gas、竞争和项目情况，应用不作保证。
- 销售服务器会保存你的 Telegram ID、用户名和名字、订单，以及每笔转账的交易哈希和转出地址。

## 一个密钥对应一台电脑

- 一个密钥同一时间只在一台电脑上运行。电脑用设备 ID 区分，设备 ID 是 Windows 机器 ID 的哈希。
- 用相同的设备 ID 再次启用密钥时（复制或克隆的 Windows、同一台电脑上的其他 Windows 用户），之前使用的一方会在下一次许可证检查时停止。
- 设备 ID 不同的电脑，需要先在 [我的许可证](https://nogada.app/dashboard) **重置设备**（每 24 小时一次）才能使用密钥。见 [许可证](../getting-started/license.md#一个密钥对应一台电脑)。

## 只留在你电脑上的内容

- **私钥** 只保存在这台电脑上，用你的 Windows 账户加密，交易也在这台电脑上签名。应用不会把私钥发送到我们的服务器：铸造记录、许可证检查和日志包里都没有私钥。
- 应用不会询问或使用助记词（恢复短语）。钱包通过私钥导入。
- 备份和数据导出都是你保存在这台电脑上的文件。备份用你设置的密码加密。**导出数据** 会以明文写出私钥，请妥善保管该文件。

## 应用发送到我们服务器的内容

| 何时 | 发送的内容 |
|---|---|
| 许可证检查（启动时，之后每 15 分钟） | 许可证密钥、设备 ID（Windows 机器 ID 的 SHA-256 哈希，不是 ID 本身）和应用版本。 |
| 其他服务器功能（更新、市场、内置 RPC、Telegram 提醒） | 同样的密钥和设备 ID，以及该请求所需的内容。 |
| 铸造记录（任务开始、成功、失败时，以及加速时） | 链、合约地址、铸造函数名、Gas 设置、任务的钱包地址、交易哈希、NFT 合约、错误信息（最多 200 个字符）、任务带有的 OpenSea 发售信息、时间、应用版本、在这台电脑上生成的随机安装 ID，以及许可证密钥的哈希。不包含许可证密钥本身，也不包含设备 ID。 |
| 日志包（点击 **发送日志** 时，或运营者要求时） | `logs` 文件夹中的应用日志文件和崩溃日志、你在 **原因** 中写的内容、应用版本、安装 ID、许可证密钥哈希、已关联的 Discord ID（如有）和系统类型。上传前，每一行中网址的问号后部分、网址里的用户名和密码、网址里像密钥的长段，以及代理的用户名和密码都会替换为 `<redacted>`。 |
| 崩溃 | 应用把发生的情况写入 `logs` 文件夹的 `crash.log`。只会随日志包一起发送。 |

运营者要求日志包时，应用会在下一次许可证检查时自动发送，不会询问你。
