# 如何选择代理

代理不是必须购买的。直接发送到合约的铸造不需要代理。在钱包很多的网站请求，或社交任务里，再考虑它。

## 挑选时要看什么

- 是否是固定 IP。每次连接都会换 IP 的轮换代理，不适合网站会话
- 是 HTTP 还是 HTTPS。应用不支持 SOCKS
- 是否真的能连上需要的网站。请在 **代理** 菜单的 **测试 URL** 里填入那个网站试一试
- 延迟和失败率是否稳定
- 地区、并发连接数、流量上限

社交任务最好每个账户使用一个代理。使用同一个真实 IP 的代理，在网站看来就是同一个。

提供商和价格经常变化。请先小量试用。填入方法见[代理](../setup/proxies.md)。
