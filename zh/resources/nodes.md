# RPC 资料
选择服务商时，请使用实际需要的链和请求进行测试，不要只看名称或套餐价格。付费服务也可能限制请求量、并发数和流量。

## 官方文档
- [Alchemy](https://www.alchemy.com/docs)
- [Infura](https://docs.metamask.io/services/)
- [QuickNode](https://www.quicknode.com/docs)
- [dRPC](https://drpc.org/docs)
- [Chainlist](https://chainlist.org)：查询链和 RPC 信息的目录

本列表不是速度或价格排名，也不是购买推荐。请检查支持的链、每秒请求数、每日或每月限额、超时设置和交易提交能力。目录中的地址也应与项目官方资料及 chain ID 核对。

应用配置与测试方法参见 [RPC 连接](../app-guide/rpc.md)。
