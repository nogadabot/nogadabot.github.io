# RPC 提供商

如果铸造有竞争，请使用提供商的 RPC。通常有免费套餐，付费的也不贵，而且不容易触达上限。

| 提供商 | 方式 |
| --- | --- |
| [Alchemy](https://www.alchemy.com) | 免费套餐，按用量计费 |
| [DRPC](https://drpc.org) | 免费套餐，充值积分 |
| [Ankr](https://www.ankr.com) | 免费套餐，充值积分 |
| [QuickNode](https://www.quicknode.com) | 免费套餐，月度订阅 |

公共 RPC 地址可以在 [Chainlist](https://chainlist.org) 找到。

- 每条链上表现好的提供商不同。请准备几家，并用 **RPC** 菜单里的测试来比较。
- 盈亏计算需要 Alchemy 地址。见[盈亏](../tools/pnl.md)
- 价格和条件经常变化。请到提供商的网站上确认。

填入方法见 [RPC](../setup/rpc.md)。
