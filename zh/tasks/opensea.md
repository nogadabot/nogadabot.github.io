# OpenSea Drop

这是用 OpenSea 系列链接创建铸造任务的方法。应用会自动填入系列和销售信息，所以你只需要选择阶段、钱包、数量、价格上限、RPC、Gas 和时间。

## 开始前的准备

- 官方 OpenSea 系列链接。通常形如 `https://opensea.io/collection/slug`。
- 已经导入应用、并在该链上存入资金的钱包。免费铸造也需要 Gas。
- 该链至少一个 RPC。有竞争时推荐付费 RPC。
- 钱包很多时，准备代理分组。
- 使用 OpenSea API 模式时，需要 [OpenSea API 密钥](../setup/opensea-api.md)。

不要在任务栏里填入助记词或私钥。密钥只能通过[钱包](../setup/wallets.md)的导入功能填入。

## 创建步骤

1. 打开 **任务 → EVM → 新建任务** 或[智能铸造](smart-mint.md)。
2. 粘贴官方链接。
3. 等到出现 **铸造阶段** 栏。加载过程中不要创建。
4. 确认链和合约正确。
5. 选择阶段。
6. 选择 **模式**。
7. 需要的话，选择 **代理分组**。
8. 填入 **NFT 数量**。这是每个钱包的数量。
9. 确认 **每 NFT 价格**。这是单个的最高价格，不是总价。
10. 选择钱包和 RPC，设置 Gas、时间和方式。
11. 创建之后启动。

如果选了 20 个钱包，NFT 数量填 2，这 20 个钱包每个最多尝试铸造 2 个。

## 需要确认的事

| 项目 | 确认内容 |
| --- | --- |
| 链接 | 是否是官方 OpenSea 页面，而不是相似的假地址 |
| 链 | 是否是铸造开放所在的链 |
| 合约 | 是否与项目公布的地址一致 |
| 阶段 | 是否有公开或白名单阶段，时间是否正确 |
| 价格 | 是否与公告一致 |

只要有一项不对劲，就先停下，重新核对官方链接和公告。

## 选择阶段

一个系列可能有多个阶段。是否公开、时间、价格和每个钱包的上限各不相同。请选择你的钱包有资格参与的阶段。更换阶段后价格可能会变，请重新确认。把没有资格的钱包加入任务，并不会让它获得资格。

## 模式

| 模式 | 适用情形 |
| --- | --- |
| 匿名模式 | 不登录，通过代理获取铸造数据。这是智能铸造的默认模式。只对没有得到回应的钱包使用已保存的密钥。如果 Drop 要求登录，则那时再登录 |
| 普通模式 | 用钱包登录 OpenSea 来获取 |
| OpenSea API | 用已保存的 API 密钥获取。没有密钥时无法选择 |
| 双模式 | 同时通过普通路径和 API 路径获取，采用先返回的结果。没有密钥时无法选择 |

公开阶段通常不需要请求 OpenSea，直接在链上发送。需要准备的阶段，任务会经过准备状态，在变为 **就绪** 之后发射。

## 代理

- 对需要为每个钱包做 OpenSea 准备的阶段，这很重要。
- 按钱包数量多放入一些代理。
- 许多钱包同时准备失败时，重新创建任务之前，先测试代理分组。
- 临近开放时，不要更换正常工作的代理。

## 数量与价格

- **NFT 数量** 是 1 以上的整数。不要超过每个钱包的上限。已经铸造过的数量，会减少剩余上限。
- **每 NFT 价格** 由阶段自动填入。只有确实免费时才填 0。
- 钱包需要的余额是 `每 NFT 价格 × NFT 数量 + Gas 余量`。

## 铸造后的操作

对非连发的任务，可以附加发送 NFT、上架 NFT 和接受报价。第一次使用的设置，请先用小额钱包试一试。

## 开始前检查

- [ ] 官方 OpenSea 链接
- [ ] 链和合约
- [ ] 阶段
- [ ] 有资格的钱包
- [ ] 数量在每个钱包的上限之内
- [ ] 每 NFT 价格
- [ ] 每个钱包的铸造金额和 Gas
- [ ] 该链的可用 RPC
- [ ] 与模式匹配的 Gas
- [ ] 时间戳和时区
- [ ] 如果是连发，则要有最大交易数和结束时间

## 复制与编辑

已保存的 OpenSea 任务，其链接、链和阶段可能被锁定。钱包、RPC、Gas、时间、数量、价格上限和代理分组可以修改。复制出来的任务，请重新确认阶段和价格。

## 故障排查

**无法读取链接。** 请检查是否含有 `opensea.io/collection/`，前后有没有空格，并填入去掉跟踪参数的干净链接。

**一直在加载。** 请稍后重新粘贴。检查网络；如果使用了密钥或代理，请测试它们。关闭窗口再打开也可以。

**没有显示阶段。** 可能没有铸造阶段，或创建者做了修改。请确认填入的是系列页面，而不是物品页面。

**无法选择 OpenSea API。** 没有密钥。请使用其他模式。

**密钥被拒绝，或触达上限。** 请在 [OS API](../setup/opensea-api.md) 里测试，并删除已过期的密钥。看到上限提示后，请稍等一会儿。

**钱包准备卡住或失败。** 请检查钱包资格、代理分组和电脑时钟。不要重新创建所有任务，只重试失败的钱包。

**余额不足。** 每个钱包都需要单独的铸造金额和 Gas 余量。也请为铸造后的操作留出 Gas。

**明明在白名单里，却提示没有资格。** 请确认是否选对了阶段、地址是否一致、是否已经用完名额，以及项目是否修改了名单。

**阶段还没有开放。** 请对照官方时间、时间戳和时区。如果不知道确切时间，请使用模拟。

**RPC 超时或上限错误。** 请换成可用的付费 RPC，并删除其他链的 RPC。

**交易被回滚（revert）。** 常见原因有：阶段开始之前或结束之后、没有资格、超出上限、已经铸造过、价格上涨、余额不足、Gas 上限过低、nonce 不匹配。在修复之前，重复执行同样的任务不会有改善。

**提示 nonce 过低或替换错误。** 请检查钱包的待处理交易，并把 Nonce 恢复为自动。不要用同一个钱包同时运行多个任务。

**显示成功，但看不到 NFT。** 请在区块浏览器里打开交易哈希，确认转移记录。OpenSea 和钱包的索引可能有延迟。

**挂单或接受报价失败。** 请检查密钥、NFT 的所有权和授权、期限、报价是否有效，以及 Gas。

## 咨询时要发送的内容

请发送：应用版本、OpenSea 链接、链和阶段名称、任务名称和大致时间、失败的公开地址、屏幕上的错误文字、交易哈希，以及遮挡了敏感信息的截图。绝对不要发送助记词、私钥、钱包导出文件、许可证密钥、API 密钥。
