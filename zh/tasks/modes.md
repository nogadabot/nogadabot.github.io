# 任务模式

模式决定交易在何时、以怎样的方式发送。智能铸造里的 **即时 ×1** 是关闭模拟的任务，**安全（先模拟）** 是模拟任务，**连发（重复）** 是连发任务。

## 即时（模拟关闭）

签名一次，立即发送。用于已经开放的铸造、普通的合约调用，以及确切知道时间的任务。用在尚未开放的铸造上会失败。

## 模拟

用相同的调用数据和金额反复执行 `eth_call`，一旦不再失败，就发送真实交易。

- 调用失败时，会继续重试。
- 成功后，立即签名并发送。

比即时慢一步，但对不知道确切开放时间的 Drop 更稳妥。重试间隔就是 **延迟** 栏。它不是只做试运行的模式，而是最终会发送交易的等待方式。

## 连发

适合出块非常快的链。从开放前几秒到开放后几秒，大量发送交易，争取其中一笔被打包。

开启连发后会有这些变化。

- 必须填写 Gas 上限、最高费用和优先费。
- 会出现 **最大交易数** 栏。
- **时间戳** 里可以写 `开始-结束`。

会一直发送，直到下面任意一种情况发生。

| 停止条件 | 含义 |
| --- | --- |
| 成功 | 回执状态为 1 |
| 最大交易数 | 达到设定的数量 |
| 结束时间 | `开始-结束` 的结束时间已过 |
| 连发安全上限 | 达到设置里的上限 |
| 停止 | 你手动停止了 |

## 连发 + Flashbots

在以太坊主网上开启任务的 Flashbots 后，会以捆绑包代替公共内存池来发送。未打包的尝试不会支付 Gas，也不会占用 nonce。

## 如何选择

| 情况 | 模式 |
| --- | --- |
| 已经开放 | 即时 |
| 确切知道时间 | 即时 + 时间戳 |
| 不知道何时开放 | 模拟 |
| 出块快、竞争激烈 | 连发 |
| 在以太坊主网上想避免失败成本 | 连发 + Flashbots |
