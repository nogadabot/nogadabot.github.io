# 智能铸造：从链接到任务

智能铸造会把用户输入的铸造目标解析为任务草稿。**查询或选择阶段不会广播**；创建后的任务只能从任务界面的 Start 发射。

## 支持的输入

* NFT 或 minter 合约地址
* Etherscan 类区块浏览器链接
* OpenSea collection、item 或 assets 链接
* 市场或 Launchpad 链接
* 项目官方铸造站点链接

## 使用流程

1. 粘贴链接或合约并点击**查询铸造路径**。
2. 若项目登记了多个阶段，会按准确名称显示，请选择一个。
3. 确认链、交易目标、NFT 目标、钱包、每钱包数量、总目标数量、发送金额、Gas 和预约时间。
4. 点击**创建任务**。
5. 进入**任务**，选择该任务并点击 **Start**。

不存在“自动（最佳阶段）”。Nogada 不会替用户选择阶段。

## Telegram 快速流程

在 Telegram 机器人中，点击 **Smart Mint** 或发送 `/mint`。只有一个机器人钱包时会自动选择；有多个钱包时先选择执行范围。然后只需发送项目铸造、市场/OpenSea、区块浏览器、Launchpad 链接或 `0x` 地址。无法确认链时使用按钮选择，再选择项目登记的准确阶段。

默认流程会按每钱包 1 个立即创建任务。未来阶段采用项目公布的开始时间、仅在项目公布时采用结束时间，并使用连射与自动 Gas。只有需要修改数量、发射方式、预约或 Gas 时，才在发送链接前开启**高级设置**。旧的一行参数仍作为熟练用户的可选路径保留。

## 阶段信息原则

* 保留 API、链上或项目数据中的准确阶段名称。
* 缺少 index 或名称的阶段绝不会被改写为 Public 0。
* 只有完整、可靠的时间支持时，才显示当前、即将开始或已结束。
* 时间缺失或冲突时保持未知，不进行猜测。
* 不显示资格/WL 标记，也不会用猜测的资格阻止选择或 Start。

## 链接无法解析时

正常链接也可能因客户端渲染、地区限制、反机器人保护或缺少公开元数据而无法自动解析。请依次尝试：

1. 同一项目的 OpenSea collection 或区块浏览器链接
2. 实际 minter/NFT 合约和准确链
3. 任务编辑器中的导入 ABI
4. 项目公布的准确函数参数或 raw calldata

Nogada 不会仅因查询失败就虚构 Public 阶段或合约。

## 数量与结果

数量按每钱包请求，总目标会乘以已选钱包数。已知单笔上限会通过准确 nonce 分片处理，绝不会暗中减少。只有收据证明预期 NFT 合约、接收者和数量时，才显示**铸造完成**。
