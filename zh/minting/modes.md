# 立即、模拟后执行与连发
执行模式与预约时间是分开设置的。即使选择了**立即执行一次**，设置了未来时间后，任务仍会等到该时间。

| 模式 | 行为 |
|---|---|
| 立即执行一次 | 不先模拟，直接提交所选调用 |
| 模拟后执行一次 | 按用户主动选择的模拟路径检查同一调用，再执行 |
| 连发 | 根据用户上限、停止条件和交易结果重复尝试 |

模拟模式不是项目方的资格判定，也不保证成功。为满足准确数量，一轮执行仍可能需要多笔交易。

## 预约准备
创建任务后提前点击 Start，准备连接、Gas、nonce 和可确定的 calldata。对于稍后才开放的签名数据，支持的路径会自动重新查询。请核对实际预约值及[时区规则](../telegram/timezone.md)。

## 连发上限
应用的连发时间限制留空或填 0 时，使用默认 120 秒。选择无限制只取消时间限制，交易次数和结束时间限制仍可能生效。机器人高级输入请遵循对应提示的单位与范围。

除了铸造完成、用户 Stop 和明确上限，确认交易在链上执行失败（revert）后，若按原铸造设置再次检查并确认已售罄，也会停止后续发送。这与仅凭供应量显示就阻止 Start 不同。

待确认交易会继续按原交易跟踪，不会把未知结果当作成功，也不会自动加价或自动执行 RBF。
