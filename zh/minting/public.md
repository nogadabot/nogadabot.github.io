# 公开铸造
选择项目实际公布的 Public 阶段。信息不完整的阶段不会自动视为 Public。

1. 在 Smart Mint 中输入链接或合约。
2. 检查链以及 Public 阶段的价格、时间和数量条件。
3. 保存钱包、数量、Gas 和预约设置，再创建任务。
4. 在任务中点击 Start。

自动查询不可用时，可使用[手动 ABI/Hex 任务](../app-guide/tasks.md)。请检查参数或 calldata 中的实际数量，以及每笔交易金额。只更改回执核验数量，不会改变实际调用。

免费铸造也可能需要 Gas。RPC 接收或回执状态成功，本身不能证明已经获得 NFT，请查看[结果](../app-guide/results.md)。
