# 公开铸造

公开铸造是项目向所有人开放的调用路径。Nogada 不会把没有名称或缺少 index 的阶段擅自当作 Public。

## 使用智能铸造创建

1. 在 **智能铸造**中粘贴合约、区块浏览器、OpenSea collection/item/assets、市场、Launchpad 或项目铸造链接。
2. 查看项目实际登记的阶段名称，以及可验证的时间和价格。
3. 选择阶段、钱包、每钱包数量、Gas 和开始时间。
4. 点击**创建任务**。
5. 进入**任务**，选择已创建的任务并点击 **Start**。

只有完整、可靠的时间信息支持时，才会显示当前、即将开始或已结束。时间不完整时保持未知，不会猜成 Public 或“已结束”。

## 直接通过合约创建

自动解析不可用时，进入**任务 → + 新建任务**。

1. 确认实际链和交易目标合约。
2. 使用**导入 ABI**选择铸造函数，或输入准确函数签名/参数或 raw calldata。
3. 输入**每钱包请求数量**和**单笔交易发送的原生代币总额**。
4. 若路由器/共享 minter 从其他合约铸造 NFT，请输入**预期 NFT 合约**。
5. 选择钱包和 RPC，创建任务后从**任务中的 Start**发射。

ABI/Hex 的预期数量不会改变 calldata 或发送金额。Nogada 也不会猜测任意 calldata 的含义来阻止发射。

## 成功依据

交易提交后会核对同一笔交易的收据。只有成功收据证明准确的预期 NFT 合约、接收者和 Transfer 数量时，才显示**铸造完成**。若收据 status 成功但无法证明 NFT 结果，则显示**铸造未验证**。
