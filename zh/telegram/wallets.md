# 机器人钱包与充值

在**钱包**中创建或导入机器人钱包。选择链后，可查看该链上的原生币余额。查询失败不代表余额为零，请留意上次查询结果或无法查询的提示。

机器人私钥在服务器上加密保存，与应用钱包分开管理。即使使用相同地址，应用中的钱包名称、任务和 RPC 设置也不会同步过来。

## 下次更新：充值二维码

1. 在钱包页面确认要使用的**链**。
2. 点击**充值二维码**，选择目标钱包。
3. 核对卡片中的网络、币种符号和完整地址。
4. 扫描二维码，或复制消息中的地址。

二维码中包含钱包地址，但扫码并不能保证转出钱包自动选择正确网络。请在转账页面再次确认网络。

二维码生成或上传失败时可以重试。打开二维码不会发送交易，也不会导出私钥。

## 归集与删除

原生币归集使用输入的 `0x地址 [链]`。省略链时默认为 Ethereum，不会自动沿用钱包查询页面所选的链。此操作会归集该链上**所有机器人钱包**的原生币余额，请确认范围。它与 NFT 转移不同。删除钱包前，请检查其他链的资产和私钥备份。删除不会取消已发送的交易。
