# 通知设置

应用通知和 Telegram 通知是**相互独立的个人设置**。在机器人中打开**设置 → 通知设置**。修改 Telegram 设置不会改变应用的 Windows 通知设置。

## 公开版本 v0.9.43

可以分别开启或关闭**任务结果**和 **Supply Watch** 通知。关闭通知只影响消息接收，不会停止任务，也不会删除执行记录。

## 下次更新：按结果和阶段选择

- 铸造成功、失败、部分完成、铸造未验证、待确认或已停止
- 首次提交尝试、RPC/构建者接收、链上回执观测
- Supply Watch

**任务结果**是任务通知的总开关。关闭总开关后，即使单独项目处于开启状态，也不会发送任务通知。Supply Watch 使用独立开关。

新增的提交、接收和回执通知默认关闭，可按需要开启。RPC 接收或观察到回执，本身不代表 NFT 铸造成功。

已经发送的消息不会因后来收到记录而重写。请通过[任务结果汇总](telegram-bot.md)查看最新结果。
