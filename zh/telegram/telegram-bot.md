# Telegram 机器人入门
官方 [@NOGADA_Mint_Bot](https://t.me/NOGADA_Mint_Bot) 在服务器上独立运行，无需开启应用，也不会查看或控制应用的钱包、任务、RPC 或代理。

## 1. 登录并准备钱包
完成[购买邮箱验证](../getting-started/license.md)后，在**钱包**中准备机器人钱包。机器人私钥在服务器上加密保存，与应用中受 DPAPI 保护的钱包分开管理。参见[钱包与充值](wallets.md)。

## 2. 创建 Smart Mint 任务
1. 打开 **Smart Mint** 或发送 `/mint`。
2. 选择机器人钱包，发送链接或合约。
3. 手动选择链，再选择项目准确的铸造阶段。
4. 检查每个钱包的数量、目标总数、模式、Gas 和预约。
5. 创建任务后，在任务列表点击 Start。

普通签名铸造用户不需要手动准备 voucher。支持的路径会自动取得钱包专属数据，详见[签名铸造](../minting/whitelist.md)。

## 3. 任务与结果
任务列表可切换简洁和详细视图。请核对任务编号，以及 Start/Stop、详情和删除按钮对应的任务。重新执行会发送新交易，可能重复铸造。

**下次更新：**列表中的**结果汇总**每页最多显示自己的 25 个任务，并使用每个任务最近一轮的结果。任务钱包结果数与去重钱包数分别统计；没有记录的任务保持未知。任务详情还会显示以 ms 和 s 为单位的广播耗时。

## 4. 个人设置
- [时区](timezone.md)：按私人聊天保存在服务器上，同时显示 UTC、当地时间和秒数。
- [通知](notifications.md)：与应用通知单独设置。
- [供应量监测](supply-watch.md)：提供观测通知，不会自动铸造。
- RPC、代理和 OpenSea 密钥：在机器人的**设置**中另行配置。

## 高级 ABI/Hex
普通任务请使用按钮流程，仅在需要直接提供 calldata 时打开任务菜单中的**高级 ABI/Hex**帮助。

| 输入 | 含义 |
|---|---|
| `sig=`、`args=` | 实际函数签名和参数 |
| `fire=spam`、`fire=safe` | 用户选择的执行模式 |
| `gas=`、`fee=`、`tip=` | Gas 上限、最高费用和优先费 |
| `max=`、`delay=` | 每个钱包的交易次数上限及尝试间隔（ms） |
| `at=`、`until=` | 按提示的 UTC 规则设置开始和结束时间 |
| `nft=` | 用于回执核验的 NFT 合约 |
| `sweep=` | 铸造后的转移地址 |

不要原样执行示例地址或时间，请遵守当前帮助中的格式和范围。回执核验数量不会改写 ABI/Hex calldata，普通铸造由签名钱包接收。

应用与机器人同时使用同一钱包时可能发生 nonce 冲突，因为两个产品不共享执行状态。
