# 备份、恢复与迁移

应用不会把数据上传到任何地方，也没有自动备份。删除钱包、更换电脑或做有风险的更改之前，请使用 **设置 → 常规 → 备份与恢复**。

## 创建备份

1. 填入 8 位以上的 **备份密码**。
2. 点击 **导出备份**。
3. 把 `.nogada-backup` 文件放在这台电脑以外的地方。

备份会用密码加密。密码不会被保存，忘记了就无法找回。

## 备份里包含什么

包含钱包、账户和认证状态、RPC、代理、OpenSea 开发者密钥、任务、白名单、盈亏设置和背景、界面设置和收藏。

不包含许可证、日志和缓存、浏览器配置文件和会话。请在新电脑上重新激活，并重新连接会话。

## 恢复与更换电脑

1. 在新电脑上安装并激活 Nogada。见[许可证](../getting-started/license.md)。
2. 在 **备份与恢复** 里填入密码，点击 **恢复备份**。
3. 确认备份时间、应用版本和内容数量。
4. 点击 **恢复并重启**。

恢复会更改这台电脑上的数据。更改之前，会用同一个密码把当前状态加密，保存为回滚文件，然后关闭应用。重新启动并确认钱包数量、任务分组、设置和 RPC 之前，不要删除原始备份和回滚文件。

不要把 `.dat` 文件复制到另一台电脑。它们绑定了 Windows DPAPI，在别的电脑上打不开。请使用备份。

> **注意**：没有备份、也没有导出密钥就删除的钱包无法恢复。服务器上没有副本。
