# 故障排查

先原样查看任务行、提醒或窗口里显示的错误文字。先确认这件事所需的东西：钱包资金、RPC 状态、代理状态、账户认证、API 密钥、验证码余额、网络。然后只重试失败的部分。

## 安装与运行

- **文件消失了。** 多半是杀毒软件或浏览器删除的。请把文件夹加入排除列表，然后重新下载。
- **SmartScreen 拦截。** 点击 **更多信息 → 仍要运行**。
- **什么都打不开。** 请看[安装与首次运行](../getting-started/install.md)。

## 许可证

- **无法激活。** 请检查密钥里有没有空格，网络是否正常。
- **提示在其他设备上使用。** 请联系运营者重置设备。见[许可证](../getting-started/license.md)。
- **没收到密钥。** 请检查垃圾邮件箱，写明购买时用的邮箱，联系运营者。

## 交易发不出去

- **余额**：检查每个钱包是否都有铸造金额和 Gas。
- **RPC**：在 RPC 菜单里测试。检查任务中选的 RPC 是否属于该链。
- **Gas**：检查是不是太低。Gas 上限请留空。见 [Gas](../tasks/gas.md)。
- **阶段**：检查是否已经开放，钱包是否有资格。

## 交易一直待处理

请用[加速](../tasks/boost.md)，以更高的费用替换。

## 找不到 ABI

应用会依次查看所选链的验证来源。填入 **设置 → 集成 → Etherscan API 密钥** 可以提高查询上限。如果合约存在但没有已验证的 ABI，请手动填入函数签名或 Hex。链选错的话，会提示没有代码。

## 智能铸造找不到路径

请看[智能铸造](../tasks/smart-mint.md)里的“查询失败时”。

## OpenSea 任务

请看 [OpenSea Drop](../tasks/opensea.md) 里的故障排查。

## 收集日志

在 **设置 → 常规 → 应用日志** 里打开日志文件夹。如果安全的话，请重现一次问题，并记下大致时间。`nogada.log`、`tasks.log`、`funds-sessions.log` 会有帮助。不要只复制最后几行，请保留完整的文件。原因往往在更前面。

## 咨询时要发送的内容

- 你想做什么
- 屏幕上的错误文字和大致时间
- 应用版本和 Windows 版本
- 页面、任务或模块名称、链、公开的交易哈希或钱包地址
- 重现步骤

不要发送助记词、私钥、钱包导出文件、许可证密钥、API 密钥、账户令牌、代理密码、备份密码。也请检查截图里的敏感栏位。

使用 **发送日志**，会上传遮挡了敏感值的日志包，并给出一个 ID。请把这个 ID 附在咨询里。
