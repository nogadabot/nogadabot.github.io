# 安全与隐私

重要数据加密后保存在这台电脑上，更新文件在安装前先验证，许可证由服务器绑定到电脑。

## 本地加密

`wallets.dat`、`rpc.dat`、`proxies.dat`、`accounts.dat`、`opensea_developer_keys.dat` 用 Windows DPAPI 加密。它们绑定到这台电脑和这个 Windows 用户。平时不会询问应用密码。

## 不加密的文件

`tasks.json`、许可证状态、`flashbots.key`、NFT 缓存、盈亏设置和背景、账户认证状态、浏览器配置文件、日志不加密。不含钱包私钥。浏览器配置文件里有网站 Cookie，请把整个 Windows 用户配置文件都当作敏感数据对待。

## 服务器会接收和不会接收的内容

- **不接收**：钱包私钥。签名始终在这台电脑上完成。
- **接收**：验证许可证所需的密钥和设备标识值。
- **问题报告**：应用界面上的错误，会遮挡敏感值后发送，用于诊断。**发送日志** 只有在你亲手点击时才会发送。

## 更新

应用会验证发布信息的签名、下载文件的签名和版本顺序。即使是签过名的旧版本，也不会接受。验证失败时不会应用，并记录原因。

## 许可证与设备

激活后，服务器会把密钥绑定到这台电脑的设备标识值。即使删除本地状态文件，服务器上的绑定也依然存在。见[许可证](../getting-started/license.md)。

## 无法阻止的事

- 以你的 Windows 用户权限运行的恶意软件
- 能操作你桌面的人
- 被攻破的浏览器配置文件或账户会话
- 诱使你把私钥或许可证密钥填到错误地方的钓鱼

## 习惯

- 铸造用小额钱包，大额资产放在没有接入应用的钱包里。
- 不要把助记词和私钥发给任何人。运营者也不会问。
- 只使用官方链接。第一次见到的合约，先用小钱包试一试。
- 导出的文件和剪贴板里的密钥，要立刻清除。
