# 本地数据与导出

钱包、账户、任务、设置、缓存、浏览器配置文件都在运行应用的这台电脑上。没有 Nogada 云账户。

## 保存位置

| 数据 | 位置 |
| --- | --- |
| 应用数据 | `%LOCALAPPDATA%\nogada\data` |
| 浏览器配置文件 | `%LOCALAPPDATA%\nogada\browser-profiles` |
| 日志 | `nogada.exe` 旁边的 `logs` 文件夹 |

`wallets.dat`、`rpc.dat`、`proxies.dat`、`accounts.dat`、`opensea_developer_keys.dat` 用 Windows DPAPI 加密，并绑定到这台电脑和当前用户。

任务和白名单 JSON、缓存、日志、盈亏显示文件、账户认证状态、浏览器配置文件不是保密存储。所以不仅要保护 `.dat` 文件，还要保护好整个 Windows 用户账户和磁盘。

## CSV 导出与备份的区别

**设置 → 常规 → 导出数据** 会把钱包、账户、RPC、代理中的一项导出为未加密的 CSV。里面的私钥和凭据可以直接读取。CSV 不是完整的迁移手段。

想加密迁移多项数据，请使用[备份、恢复与迁移](backup-restore.md)。无论哪种方式，都不要放在共享文件夹里，临时副本用完请删除。

## 删除

删除钱包、分组、任务、白名单、浏览器配置文件后，它们就从这台电脑上消失了。没有回收站。大规模删除之前，请先备份，并确认备份文件在应用数据文件夹之外。

## 日志

日志里可能含有 URL、地址和任务错误。分享之前请先检查，咨询时只发送需要的时间段。**设置 → 常规 → 发送日志** 发送的日志包不含钱包密钥、RPC API 密钥和代理凭据。
