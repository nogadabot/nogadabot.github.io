# 添加自定义链

添加不在内置列表里的 EVM 链。使用 **设置 → 发射引擎 → 添加自定义链**。

## 添加

1. 粘贴一个可用的 RPC URL，点击 **检测**。
2. 应用会调用 `eth_chainId`，并查找已知信息自动填入。
3. 确认链 ID、名称、原生代币符号、区块浏览器（可选）。
4. 添加。

RPC URL、链 ID、名称、符号是必填的。不能添加相同的链 ID。RPC、名称、符号、区块浏览器之后可以修改。链 ID 不能修改，请删除后重新添加。

> **注意**：应用把原生代币按 18 位小数处理。检测时如果发现不是这个值，会发出警告。仍然可以保存，但余额和金额可能显示错误。

## 自定义链上能用什么

它会出现在选择处，并使用你填入的 RPC 和区块浏览器。分发合约、Multicall3、NFT 批量辅助合约、市场和索引器、链专用模块不会自动出现。

基础调用能用，部分工具也可能用不了。大任务之前，请先试一试读取余额和小额交易。竞争性铸造请在 RPC 菜单里填入专用 RPC。

删除链只会删除这台电脑上的条目。对已经发送的交易没有影响。
