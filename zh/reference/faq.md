# 常见问题

## 支持哪些链

支持以太坊和主要的 EVM 链。见[支持的链](chains.md)。不在列表里的 EVM 链，可以[自行添加](custom-chains.md)。不支持 Solana 和比特币。

## Mac 上能用吗

不能。这是 Windows 应用。如果用 Mac，可以使用 [Windows VPS](../getting-started/vps.md)。

## 钱包安全吗

私钥用 Windows DPAPI 加密后保存在这台电脑上，不会发送到服务器。即便如此，铸造也请使用小额钱包。见[安全与隐私](security.md)。

## 必须准备 RPC 吗

不用。不填也会用内置的公共 RPC 运行。但公共 RPC 很容易被限流，所以竞争性铸造推荐使用付费 RPC。见 [RPC 提供商](../resources/nodes.md)。

## 代理、API 密钥、验证码密钥一定需要吗

铸造本身不需要。代理用于钱包很多的网站请求，OpenSea 密钥用于查看器购买、铸造日历和 API 模式铸造，验证码密钥用于带验证码的社交模块。

## 许可证怎么买

在运营者的销售页面付款，密钥会发到你的邮箱。见[许可证](../getting-started/license.md)。

## 可以在多台电脑上用吗

一个密钥只绑定一台电脑。迁移时，请联系运营者重置设备。

## 关掉应用，任务还会运行吗

不会。应用必须保持运行。想让它一直运行，请使用 [Windows VPS](../getting-started/vps.md)。

## 保证铸造成功吗

不保证。这取决于 Gas、RPC 速度、竞争和项目状态。准备得越充分，成功率越高。

## 没有资格或余额不足，为什么不拦住发射

资格和余额信息只是参考，因为存在应用不知道的变数（最后时刻追加白名单、突然开放等）。最终由网络来判断。

## 能退款吗

仅在完全无法安装的情况下，我们才会协助处理。铸造结果不在退款范围内。
