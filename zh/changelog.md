# 更新日志

最新版本显示在最上方。每次打开应用都会自动更新到最新版本 — 安装请参阅 [下载](getting-started/download.md)。

## v0.9.43

- 任务页面保持简洁的 STATUS，并使用独立的 RESULT 区域显示已确认的铸造证据、交易链接和清晰的失败原因；分组结果摘要可查看每个钱包的结果，同时避免与行操作按钮重叠。
- 任务详情新增 Broadcast Flight Recorder：首次广播与 RPC 接收以毫秒显示，链上确认则根据实际运行记录以秒显示。
- 钱包可打开清晰的充值二维码卡片，集中显示网络、地址、二维码和复制地址操作。应用通知设置可独立控制铸造结果与 Supply Watch 的 Windows 通知。
- Supply Watch v2 会如实提示供应量增加、百分比里程碑和铸造速度突然加快，并且不会自动启动铸造。Telegram 拥有独立于应用的任务结果与 Supply Watch 通知设置，并支持保存本地时区及精确到秒的预约倒计时。
- 连发铸造在已回滚交易被确认属于售罄后会停止继续发送。Telegram 也会保留更具体的 gas、fee 与 tip 错误说明，不再统一显示成泛化的 Gas 设置错误。

## v0.9.42

- Telegram 主菜单更加简洁，供应量监控也会明确说明它监控的是 totalSupply 增长，而不是铸造开放提醒。
- 机器人导出的私钥消息在可追踪消息 ID 时会于约 60 秒后自动从 Telegram 删除；无法自动删除时会明确提示手动删除。
- 设置、快速任务、代理、NFT 与 Smart Mint 页面现在会区分加载失败、真正为空和已关闭状态，并提供直接重试操作。
- 仪表盘监控刷新不再重叠；隐藏后重新显示链时会保留已保存的 RPC 设置，同时改进了可选择设置的键盘操作。

## v0.9.41

- Telegram Smart Mint 会在 GTD 或 FCFS 阶段开放时自动获取每个钱包的 SeaDrop 签名铸造数据。默认使用 OpenSea 匿名流程，也可使用你已配置的 OpenSea Drops API 密钥；数据一旦可用就立即广播，并准确保留签名阶段、时间窗口、价格和钱包限额。
- 资格检查模块在 API 缺少资格字段或字段格式发生变化时会安全地按不具备资格处理，Admin 页面也可准确管理每个模块使用的阶段资格字段。

## v0.9.40

- 钱包、RPC 和任务加载现可区分数据不可用、加载中、上次可用数据及确实为空。重试只重新读取数据，不会重复执行 Start。
- 手动 Boost 会按顺序应用到每个运行中的钱包，并在私有替换交易及下一个 nonce 中保留用户选择的费用。不会自动提高 Gas。
- Telegram 任务结果会持久保存，在发送失败或服务器重启后继续发送，不会重复铸造。收件人验证与分段进度保护延迟报告；确认中断时，个别分段仍可能重复。
- 明确区分 Smart Mint 与手动 ABI/Hex 入口。创建首个任务组后继续打开编辑器，PnL 计算置于可选卡片样式之前，并改善文字对比度及桌面菜单行为。
- Telegram 任务列表更紧凑，同时保留详情和全部操作。机器人钱包可查询所选链的原生余额，RPC 设置提供安全详情、连接检查及删除确认。延迟回复会重新验证当前登录绑定。
- 应用和机器人的标签明确标注数字单位、每钱包适用范围，以及留空或填 0 的默认含义。原生币归集会拒绝无效地址或链名，登录绑定变更后无法复用旧输入会话。

## v0.9.39

- 桌面仪表盘集中显示本地准备状态、下一项任务、待处理问题和已验证结果。高级工具集中到菜单中，原有设置和操作仍可访问。
- 任务数量、按网络时间校正的秒级倒计时、代币费用及未确认结果显示更清晰。仪表盘加载失败时会区分数据不可用与上次可用数据。
- Telegram Smart Mint、任务列表和结果报告采用统一分区及清晰按钮。保留全部铸造选项，并可逐步设置数量、预约和 Gas。
- 删除任务时验证所有权，并安全处理执行记录清理失败。优化页面加载并更新依赖，减小构建体积并修复加载错误。

## v0.9.38

- 预约连发铸造会并行处理不支持批量请求的 Gas 查询，并让单个 RPC 使用完整且受限的开放前准备窗口，无需更早查询即可降低错过发射的风险。
- 当铸造钱包余额不足时，Telegram 机器人现在会准确提示余额不足，不再错误地要求用户修改 Gas 选项。

## v0.9.37

- Telegram Smart Mint 现在只需发送铸造链接或合约地址即可开始。创建任务前，可在简洁的设置界面中通过按钮确认或修改钱包、链、阶段、数量、发射方式、预约和 Gas。
- 应用不再要求用户填写预期 NFT 合约或预期铸造数量。已确认交易会依据实际链上证据区分铸造已验证、与请求不符和证据不足，并显示链上发现的实际铸造数量。
- Telegram 任务详情和重试提示现更简短，只保留发射设置、实际交易状态和重复铸造风险。修改设置时，Smart Mint 凭证和已选钱包范围都会保留。
- 如果项目在创建 Smart Mint 任务后调整了所选阶段的时间，应用和机器人中未被用户修改的自动预约会跟随同一准确阶段的新时间；用户手动编辑的时间绝不会被覆盖。
- 任务结果改用易懂表述；RPC 组会明确提示何时仅使用该组；Smart Mint 或 ABI 查询失败时显示简短恢复建议，不再暴露内部错误原文。
- 即使公共浏览器拒绝普通客户端请求，合约函数查询也能加载已验证 ABI。应用和 Telegram Smart Mint 会使用任务所选的完整 RPC 池；某个节点不可用或限制批量请求时，会切换到下一个节点。排队中的机器人任务也能容忍较慢的 RPC 准备，并会在发射前迅速重试未完成的预热。

## v0.9.36

- 若捕获的历史铸造交易已确认 NFT 发给了签名钱包以外的地址，现在将无法创建或重启任务。普通铸造路径固定由签名钱包接收；高级 ABI 与 Hex 仅按原始 calldata 执行，不再提供独立的铸造接收地址设置。

## v0.9.35

- Smart Mint 现在支持使用已验证 Blockscout ABI 与链上分组铸造的项目官网和直接合约，并包含 Robinhood Chain。分组价格、开始状态、供应量和整套售罄状态均来自合约事实，但不会阻止用户选择阶段或启动任务。
- 合约 ABI 查询现在以用户选择的链为准，并使用受支持的 EVM 浏览器及已验证源码回退路径。Smart Mint 要求手动选择链；任务编辑器在输入有效合约后会自动加载已验证的可调用函数。
- 普通解析型铸造路径现在由签署交易的钱包接收 NFT。应用和机器人已移除独立接收地址设置；旧任务若保存了其他接收地址，会在广播前停止。
- 任务编辑器的 RPC 选择器不再让分组标题覆盖节点名称与 URL。所有链上的长 RPC 名称、地址、连接状态和选择控件都能清晰显示。
- Telegram Smart Mint 现在只需发送链接或合约地址即可开始，并会在查询前始终要求用户通过按钮确认链。准确阶段、数量、发射方式、预约和 Gas 都在普通设置流程中通过按钮配置；原有单行命令仍供熟练用户使用。
- 未来的 SeaDrop GTD 与 FCFS 任务会从设置阶段到凭证到达始终保留准确的签名或 allowlist 铸造函数，因此 T0 的有效凭证不会再被误判为铸造方式变化，而会立即广播。
- Telegram 的阶段卡、任务创建卡与最终结果卡现仅保留价格、限额、时间、钱包、成功、失败、待确认、铸造数量和短交易链接等必要信息，并移除了重复的 nonce 与保管说明。

## v0.9.34

- Smart Mint 现在会从受支持的链接和合约中解析项目实际登记的铸造阶段，不再虚构自动、Public 或已结束阶段。资格推测也不会再阻止阶段选择或启动。
- 应用与 Telegram 机器人完全独立运行。两边可以使用同一钱包，但不会共享任务、状态、nonce 协调、凭据或执行；界面仅会明确提示同时运行可能造成链上 nonce 冲突。
- 预定的 GTD、FCFS 与 Public 任务会在开放前完成准备，并在真实阶段或凭证可用时立即通过所选 RPC 路由广播，启动瞬间不会增加新的同步等待。
- 铸造执行会准确保留所选钱包、接收地址、阶段、数量、价格、calldata 与 Gas。受支持的多次铸造路径会把准确数量拆分为可追踪交易，不会静默减少请求数量。
- 任务状态与铸造结果现在以持久化运行记录和真实 receipt 为依据，避免空闲任务自行变更状态，也不再猜测成功、失败或已结束。
- OpenSea Drop 链接和合约输入的解析更可靠；Smart Mint 创建任务后的返回路径更清晰；应用与机器人中的阶段、钱包、RPC、接收地址和启动反馈也更加明确。

## v0.9.33

- 铸造启动更快且更可预测：应用与 Telegram 机器人各自独立准备自己的钱包、Gas、nonce、网络路由和定时交易，并在发射时不再增加新的在线等待。
- Stable Smart Mint 现已支持 Fefer Genesis、GMCards 与 OmniHub public 铸造，并包含最新价格与授权处理、精确定时执行以及更安全的重启恢复。
- Stable 现支持通过已验证的所有权检查查看 NFT 持仓、转账和拆分发送。OpenSea 市场、SeaDrop 与 PnL 会在数据链路独立验证前继续保持关闭。
- 重启、Safe、Boost、Flashbots、代理与多 RPC 现在会保留原始钱包、交易、路由和隐私选择，避免重复发送或意外切换到公开广播。
- Telegram 机器人会在后台加载余额以保持界面响应，在铸造门槛关闭期间刷新自动 Gas，并立即从内存中清除已撤销的 OpenSea 密钥。
- 服务器升级现在会保留由旧版本创建且仍在等待处理的 Telegram 铸造与授权记录。

## v0.9.32

- 已修正各链的 Gas 说明。Stable 仍将优先费设为 0 后发送；Robinhood 会保留你选择的 Gas 设置，而 Public、GTD 和 FCFS 仍是项目的铸造阶段。
- 从 Base、Optimism、Ink 和 Shape 的机器人钱包提取全部余额时，现在会预留少量 L1 费用，避免因网络费用不足而导致发送失败。

## v0.9.31

- 新增 Robinhood Chain 与 Stable。Robinhood 可使用 Nogada 的 NFT、PnL 和 OpenSea 功能；Stable 支持使用 USDT0 支付 Gas 的铸造与转账，其 OpenSea NFT 与 PnL 功能会在相关数据链路验证完成前保持隐藏。
- Gas 处理现在会遵循各链特性：Stable 将优先费设为 0 后发送。Robinhood 会保留用户选择的 Gas 设置；链上的交易到达顺序与项目的 Public、GTD 或 FCFS 铸造阶段彼此独立。

## v0.9.30

- PnL 结果现在更值得信赖：明确区分精确、估算与部分结果，说明缺失的依据，并且不会把无法取得的历史错误显示为零。
- 发生问题时可更快恢复：按照易懂的修复提示，只重试受影响的钱包，在发射前检查任务准备状态，并可在需要时恢复到较早的任务版本。
- 通过更清晰的活动时间线、任务前后钱包余额对比，以及可搜索的任务与变更记录，可以快速看懂发生了什么。
- 保存的接收地址、导入预览、更快的搜索，以及屏幕共享时隐藏敏感信息的隐私控制，让大量地址操作更快也更安全。
- 管理员与运维工具更加安全实用：使用隐私保护的客户引用，清楚查看队列与审计记录，并自动执行备份检查和服务健康告警。

## v0.9.29

- 所有受支持的铸造平台现在都能从发射到确认始终绑定你选择的钱包、链、价格、数量、接收地址与交易内容，铸造更加可靠。
- 高负载下发射更快：提前完成网络与 Gas 准备，减少大批钱包的不必要排队，并且首笔交易前不增加新的在线等待。
- 停止、重启与 Boost 现在只会继续或替换属于该任务的交易，避免重复铸造或误改其他待处理交易。
- NFT 转账、挂单、报价、资金分发与归集在超时后可正确恢复，并更准确地显示实际链上结果。
- 提升了定时执行、钱包管理、许可证、支付、更新、备份、状态界面以及 Telegram 机器人的整体稳定性。

## v0.9.28

- 铸造更快：移除首笔交易前的延迟（自动 Gas 准备），开售瞬间发射更迅速，力争抢到第一个区块。
- 按你设置的 Gas 一次性发射：应用不再每隔几秒自动提高 Gas，而是按你设置的 Gas（自动/自定义）发射一次；想提高请用 Boost 按钮。
- 铸造成功现在会在状态栏正确显示（绿色）——已上链的铸造不再被误标为失败。

## v0.9.27

- ERC-20 计价 Drop 支付更准确：Manifold 与 TLStacks 铸造现在会发送准确的原生平台费，ERC-20 计价的 Drop 不再回退。
- Manifold 白名单 Drop 现可正常铸造（使用白名单领取的链上费用）。
- 修复粘贴 OpenSea 链接时偶发的红色错误：应用现在会自动在你的 RPC 间重试，而不是首次就失败。
- 更安全的自定义 Gas：设置最高费用后，小费会保持在其范围内，避免网络拒绝铸造。

## v0.9.26

- 更可靠的铸造：在每条铸造路径上，价格、金额、Gas 与 ERC-20 处理都更准确。
- 更快的发射：预热 RPC 连接并精简了发射路径。
- 更稳健：改进重试、状态显示更清晰，Drop 数据变动时可自愈。
- 新增：白名单检查可使用运营者发布的外部检查器，根据粘贴的 slug 或链接自动路由。
- 全应用范围内的大量稳定性与准确性修复。

## v0.9.25

- 新增：Drop 页面 — 扫描热门链上正在开放或刚部署的 SeaDrop 铸造，点击即可直接载入 Smart Mint。
- 多钱包白名单与签名 Drop 铸造更快了：现在按 Drop 并行获取每个钱包的凭证并合并处理，钱包再多也无需逐个等待即可发射。
- 新增：同一 Drop 的各钱包任务在任务页折叠为一张卡片 — 查看 Drop、阶段、钱包数量与实时进度，并一键全部启动 / 停止。
- 新增：按任务调节 Gas — 为单个任务设置小费倍数与最低优先费，并为连发模式提供 15/30/60% 快捷加成预设。
- 修正了韩文与中文界面中若干仍显示为英文的标签。

## v0.9.24

- 新增：签名 Drop 可使用你自己的 OpenSea API 密钥。应用与 Telegram 机器人的凭据彼此独立，请在需要使用的产品中分别注册。该产品随后通过 OpenSea 官方 Drops API（每账户每分钟 120 次）获取凭证。公开铸造仍无需密钥。
- 新增：可自定义代理测试 URL，用你喜欢的任意地址检查代理（默认 api.ipify.org）。
- 新增：在钱包页面一键将 WETH 解包换回 ETH。
- 新增：应用、用户指南与 Telegram 机器人现已全面支持简体中文 — 在设置中切换语言。
- 优化了英文、韩文与中文的措辞，使其更清晰自然。

## v0.9.23

- 新增：在钱包页面一键检查钱包是否存在 EIP-7702 委托（部分铸造会拒绝的智能账户升级）并撤销。
- 新增：在设置中登出。它会停止所有运行中的任务并用你的密钥锁定应用，但保留全部钱包、RPC 和设置。
- 新增：分发资金时可为每个钱包设置随机金额，避免给所有钱包发送完全相同的数额。
- 新增：可直接归集到外部地址（交易所充值地址或冷钱包），并新增 Gas 预估的 ETH / USD 一键切换。
- 白名单铸造在大规模下对频率限制更友好：现在会将凭证请求分散到你的多个代理，连发监控也更紧密地跟踪铸造开放时间。
- 优化了应用和应用内指南的措辞，使其更清晰自然。
