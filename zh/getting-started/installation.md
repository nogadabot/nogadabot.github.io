# 安装与首次运行
1. 从[下载页面](download.md)获取官方安装程序。
2. 打开安装程序，按照提示完成安装。
3. 从开始菜单或桌面快捷方式启动 Nogada。
4. 阅读应用中的提示并激活许可证。

Nogada 是 Windows 桌面应用，窗口最小宽度为 1024px。如果布局显得拥挤，请检查应用缩放和 Windows 显示缩放；这不是移动应用的安装流程。

Windows 出现警告时，请先核对文件来源和具体警告。应用自身的更新验证与 Windows 文件信誉检查是两回事。如果仍无法安装，请向运营方提供警告截图和 Windows 版本，并遮挡密钥及验证码。

电脑休眠可能影响应用中的预约任务。若希望不依赖应用、直接在服务器上运行，请单独设置 [Telegram 机器人](../telegram/telegram-bot.md)。
