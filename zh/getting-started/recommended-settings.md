# 按需添加设置
不必一开始就开启全部选项，按自己的使用方式选择即可。

| 目的 | 应检查的设置 |
|---|---|
| 使用常用默认值创建任务 | 设置 → 快速任务设置 |
| 查询 NFT 和计算盈亏 | 所选链支持的数据集成 |
| 获取 OpenSea 签名铸造数据或使用市场功能 | 各产品独立的 OpenSea 密钥与支持路径 |
| 指定网络连接路径 | 任务中的 RPC 和代理选择 |
| 选择结果通知 | 分别设置应用和机器人通知 |
| 减少预约错误 | 电脑时间、机器人时区和 UTC 开始时间 |

快速任务默认值用于创建新任务，不会直接复用旧 calldata，也不会自动点击 Start。

选择 [RPC](../app-guide/rpc.md) 时，应同时考虑请求是否成功、链是否正确和近期测试结果，而不只看延迟。[代理](../app-guide/proxies.md)会增加一段网络路径，并不一定更快。本指南不保证服务商的价格或性能。

Gas 和 Flashbots 请参见 [Gas 设置](../minting/gas.md)。已经发出的交易不会自动加价。
