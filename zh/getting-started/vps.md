# Windows VPS 与远程连接

VPS 是放在数据中心、一直开机的远程电脑。没有也可以。不过在竞争激烈的铸造里，延迟就等于顺序，所以很多用户会使用 VPS。

## 为什么会更快

RPC 提供商和发射台服务器大多在美国。如果你的电脑在亚洲，请求到美国可能要花几百 ms。把 Nogada 装在美国的 VPS 上，请求直接从 VPS 发出，距离会大大缩短。

先从美国东部试起，例如弗吉尼亚北部或纽约。它并不总是最快的。各家提供商的数据中心和线路不同，请实际测一测再选。

从你家连到 VPS 的远程画面再慢，也和铸造无关。重要的是从 VPS 到发射台、从 VPS 到 RPC 的延迟。

## 用远程桌面连接

1. 租用一台所在地区合适、支持 RDP 的 Windows VPS。
2. 在你的电脑上打开 **远程桌面连接**。
3. 填入提供商给你的 IP、用户名和密码。
4. 在 VPS 里，原样按照[安装与首次运行](install.md)操作。
5. 填入 RPC 并测试，然后再配置其余数据。

VPS 是另一台独立的电脑。文件、应用数据、浏览器配置文件和许可证激活，都不会自动和你家的电脑同步。一个密钥只绑定一台电脑，所以每次在 VPS 和你家的电脑之间切换，都要请运营者重置设备。见[许可证](license.md)。

## 不关闭应用，只断开连接

只要关闭远程窗口，VPS 和 Nogada 就会继续运行。即使关掉你家的电脑，预约的任务也照常运行。

注销、重启、关机会把 Nogada 一起关掉。提供商维护时的重启也一样。

## 检查清单

- Windows 更新可以开着，但重启时间要避开重要的铸造。
- 关闭睡眠和休眠。
- 确认 Windows 时间同步正常。预约发射使用这台电脑的时钟。
- 给 CPU、内存、磁盘留出余量。
- 使用强且唯一的 Windows 密码，可能的话只对你的 IP 开放 RDP。
- 不要通过共享剪贴板转移钱包导出文件和 API 密钥。能进入桌面的人就能操作应用。
- 删除 VPS 之前，先备份 Nogada。

## RPC 依然重要

VPS 所在地区再好，也不能修复缓慢或被限流的 RPC。请准备多个好的 RPC 节点，并用 RPC 菜单里的测试来确认。下一步是[钱包](../setup/wallets.md)。
