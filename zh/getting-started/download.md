# 下载
请下载适用于 Windows 10/11 64 位系统的[官方安装程序](https://nogada-lic.duckdns.org/updates/nogada-app-setup.exe)，文件名为 `nogada-app-setup.exe`。

首次使用请先[安装](installation.md)，再[激活许可证](license.md)。如果只使用 Telegram，可直接[使用机器人](../telegram/telegram-bot.md)，无需安装应用。

已安装的用户可以通过更新提示或**设置 → 常规**检查新版本。发现更新不等于安装完成；应用更新前，请先确认正在执行的任务，并按照界面提示操作。

如果安全软件拦截了文件，请核对警告内容和下载来源，再联系运营方。不要直接认定警告无害，也无需关闭杀毒软件。
