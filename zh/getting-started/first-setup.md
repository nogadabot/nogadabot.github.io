# 前 5 分钟设置

这是完成一次铸造所需的最少步骤。代理、API 密钥、验证码密钥都可以先不配。

## 1. 选择语言

在 **设置 → 常规 → 语言** 中，从 English、한국어、简体中文 里选一个。选择后立即生效，并保存在这台电脑上。

## 2. 添加钱包

1. 在 **钱包** 菜单里点击 **+ 新建分组**，创建一个分组。
2. 用 **导入密钥** 填入私钥，或用 **生成密钥** 创建新钱包。
3. 选择链，确认能看到余额。

详情见[钱包](../setup/wallets.md)。

## 3. 添加 RPC（推荐）

不添加 RPC，应用也会使用内置的公共 RPC 运行。但公共 RPC 很容易被限流。如果铸造竞争激烈，请在 **RPC** 菜单里填入你自己的 RPC 节点。见 [RPC](../setup/rpc.md)。

## 4. 创建铸造任务

1. 打开 **智能铸造**。
2. 选择链，然后粘贴铸造链接、合约地址、交易哈希三者之一。
3. 点击 **解析铸造路径**。
4. 选择阶段、钱包和数量，然后创建任务。

详情见[智能铸造](../tasks/smart-mint.md)。

## 5. 启动

创建任务后，任务不会自动发射。需要在 **任务** 菜单里，点击该任务的启动按钮。

## 建议提前配置

- **设置 → 常规 → 备份与恢复**：添加钱包之后，先备份一份。
- **设置 → 集成 → Discord Webhook**：每次任务结束，都通过 Discord 收到结果。
- **设置 → 快速任务设置**：先设好常用的钱包，创建任务会更快。
- **代理**：在钱包很多的 Drop 里分散网站请求。见[代理](../setup/proxies.md)。
