# 应用初始设置
创建铸造任务前，请完成以下检查。

1. **钱包：**创建分组，生成或导入要使用的钱包，确认地址和选定的链。
2. **RPC：**添加该链的节点，或检查可用的默认连接。除了延迟，也要检查链是否正确、请求能否成功。
3. **Gas 与付款：**确认支付 Gas 的原生币、铸造付款资产、数量以及每笔交易金额。
4. **Smart Mint：**输入项目链接或合约，选择实际链和铸造阶段，再创建任务。
5. **任务：**检查保存的设置，点击 Start。预约铸造时请提前点击 Start。

专用 RPC 不是所有场景的必需品；付费服务也有配额和限额。低延迟本身不能证明节点一定能可靠接收交易。

API 密钥和代理是否需要，取决于所选功能和服务商。OpenSea 密钥也可用于获取签名铸造数据，并非只用于市场功能。参见[集成设置](../app-guide/settings.md)。

钱包、RPC 或任务列表无法加载，不代表数据已删除。请使用重试按钮并确认最新状态。
