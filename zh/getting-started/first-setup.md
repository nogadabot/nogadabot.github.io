# 跟着做完第一次铸造

激活完成后，按下面五步就能运行第一个任务。每一步的详细说明见链接页面。

## 1. 添加钱包

在 **钱包** 中用 **+ 新建分组** 创建分组，然后在 **导入密钥** 里每行粘贴一个私钥。需要新钱包的话，用 **生成密钥** 生成需要的数量。→ [钱包](../prepare/wallet-groups.md)

先从没有大额资金的铸造专用钱包开始。

## 2. 准备 Gas

每个钱包需要有足够支付铸造价格和 Gas 的币。用 **钱包 → 管理资金** 的 **分发**，可以从一个钱包一次性转给分组里的多个钱包。→ [分发与归集资金](../prepare/funding.md)

不确定需要多少时，可以在 [计算器](../app/calculator.md) 中填入 Gas 上限和 NFT 价格看看。

## 3. 添加 RPC

不添加 RPC 时，应用会通过每条链内置的公共 RPC 发送。但公共 RPC 很容易被限制，最好在 **RPC → 添加 RPC** 中加入要铸造的链的 RPC，并用 **全部测试** 检查。→ [RPC 与链](../prepare/rpc-and-chains.md)

## 4. 用智能铸造创建任务

在 **智能铸造** 中粘贴铸造链接、合约地址或该 Drop 的铸造交易哈希，选择链，点击 **解析铸造路径**。

1. 在 **阶段选择** 中选择要铸造的阶段。
2. 在 **执行设置** 中设置钱包分组、每钱包数量和发射方式。
3. 查看 **最终确认**，点击 **创建铸造任务**。

→ [智能铸造](../tasks/smart-mint.md)

像 OpenSea 白名单这样每个钱包都需要签名铸造数据的 Drop，会通过代理 IP 获取这些数据，IP 被封时改用已登记的 OpenSea API 密钥。钱包较多时，两者都准备好。→ [代理](../prepare/proxy-groups.md)、[OpenSea API 密钥](../prepare/opensea-keys.md)

## 5. 在任务页面启动

智能铸造只负责创建任务。进入 **任务**，点击该行的 ▶ 按钮或底部栏的 **启动**。

- 阶段已经开放时，会立即发送。
- 阶段稍后才开放时，任务会等到那时再发送。请保持应用打开。

结果显示在该行的 **状态** 列。失败时这里会简短显示原因，该行的 **⋯ → 显示日志** 中有完整记录。→ [运行任务与加速](../tasks/running.md)
