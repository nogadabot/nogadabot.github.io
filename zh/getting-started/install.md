# 安装与首次运行

Nogada 是 Windows 应用。不需要安装程序，只用一个 `nogada.exe` 文件就能运行。它也没有后台服务，所以关闭应用后，什么都不会运行。另外，关闭应用后，已预约的任务也不会运行。

## 安装步骤

1. **下载。** 从购买说明里的链接下载 `nogada.exe`。
2. **创建文件夹。** 创建一个固定的文件夹，例如 `C:\Nogada\`，把文件放进去。日志会保存在这个文件旁边的 `logs` 文件夹里，所以最好不要先放在桌面或下载文件夹，之后再挪动。
3. **允许 Windows 运行。** 如果弹出蓝色的 SmartScreen 窗口，点击 **更多信息 → 仍要运行**。如果杀毒软件删除了文件，请把这个文件夹加入 **Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项**。
4. **运行并激活。** 双击 `nogada.exe` 启动，输入许可证密钥。见[许可证](license.md)。

激活需要联网。应用会定期重新验证许可证。短暂断网没有问题，但如果长时间无法验证，应用会回到许可证界面。

社交任务，或需要浏览器的网站，需要安装 Chrome、Brave、Edge 其中之一。

## 什么都打不开时

通常是下面三种情况之一。

- **杀毒软件隔离了文件。** 请查看 Windows 安全中心里的保护历史记录。
- **文件放在 OneDrive 或网络驱动器上。** 请把它移到 `C:\Nogada\` 这样的本地文件夹。
- **应用已经在运行。** Nogada 同一时间只能运行一个。第二次启动时，它会悄悄关闭。请检查任务栏。

还是不行，请看[故障排查](../reference/troubleshooting.md)。
