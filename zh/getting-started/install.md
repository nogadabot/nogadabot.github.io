# 下载与首次启动

Nogada 通过安装程序安装。无需管理员权限，只安装到当前 Windows 账户。安装后的应用名称是 **Nogada App**。

## 从下载到主界面

1. 在付款完成页面或 [我的许可证](https://nogada-lic.duckdns.org/dashboard) 的密钥卡片上点击 **下载应用**，下载安装程序 `nogada-setup-<版本>.exe`。这个按钮只在许可证有效期内显示。购买密钥的方法见 [许可证](license.md)。
2. 双击安装程序。Windows 对没见过的程序可能弹出蓝色警告，先点 **更多信息**，再点 **仍要运行**。
3. 安装界面对所有人都是英语。按界面提示安装。安装文件夹默认是 `%LOCALAPPDATA%\Programs\Nogada App`，安装时可以更改。
4. 用桌面或开始菜单里的 **Nogada App** 启动应用。
5. 出现许可证页面后，粘贴密钥并点击 **激活**（英语界面为 **Activate**）。首次激活需要联网。

左侧出现菜单就完成了。应用首次启动时为英语。要切换成中文，在 **Settings → General → Language** 中选择 **简体中文 (Chinese)**。

## 文件放在哪里

| 内容 | 位置 | 说明 |
|---|---|---|
| 程序 | 安装文件夹（默认 `%LOCALAPPDATA%\Programs\Nogada App`） | 普通的本地文件夹最合适。OneDrive 这类同步文件夹和网络驱动器容易出问题。 |
| 日志 | 安装文件夹里的 `logs` 文件夹 | 生成在程序旁边。 |
| 钱包、任务、设置 | `%LOCALAPPDATA%\nogada` | 在安装文件夹之外，所以换成新版本或卸载应用后一切都还在。 |

## 重新安装或卸载

- 应用正在运行时，安装和卸载会停下并提示关闭应用。关闭应用后再试。
- 重新安装会装到第一次选的安装文件夹。
- 在 Windows 设置的应用列表中卸载 **Nogada App**，只会删除安装的程序文件。`logs` 文件夹和 `%LOCALAPPDATA%\nogada`（钱包、密钥、任务）会保留。要把数据也从这台电脑上删除，卸载前先在应用里执行 **设置 → 常规 → 清除所有数据**。→ [备份与数据](../app/backup-and-data.md)

## 应用自己会做的事

- **检查许可证**：启动 90 秒后检查一次，之后每 15 分钟一次。短暂断网不会有任何影响。只有服务器拒绝密钥时（已到期、已停用或绑定在其他电脑上）才会回到许可证页面。
- **更新**：**设置 → 常规 → 更新** 中开启 **启动时强制更新** 时，启动并检查完许可证后会马上安装新版本并重启。关闭时只提示有新版本。
- **只允许一个**：Nogada 已在运行时再次打开，不会出现新的东西。请找已经打开的窗口，它可能被最小化或在其他窗口后面。
- **关闭即全部停止**：右上角的 X 会结束整个应用，而不只是关窗口。运行中和定时的任务也一起结束。

窗口不能缩小到 1100 × 720 以下。

## 在 VPS 上运行

如果自己的电脑关机时任务也要继续运行，可以租一台一直开着的 Windows 电脑（VPS），在上面运行 Nogada。

1. 用远程桌面（RDP）连接。
2. 在远程画面里按上面的“从下载到主界面”操作。
3. 一个密钥只能在一台电脑上使用。如果家里的电脑用过这个密钥，先在 [我的许可证](https://nogada-lic.duckdns.org/dashboard) 点击 **重置设备**（每 24 小时一次）。

需要注意：

- 远程桌面窗口的 X 只是断开连接，Nogada 会在 VPS 里继续运行。在 VPS 里选择注销或重启会结束那个 Windows 会话，Nogada 也会随之关闭。
- 定时任务按 VPS 自己的时钟发射，请在那里开启 Windows 时间同步。应用底部状态栏的时钟旁显示差值，说明那台电脑的时钟不准。
- 归还 VPS 前，先做好 [备份](../app/backup-and-data.md)，再执行 **设置 → 常规 → 清除所有数据**。只删除应用，钱包仍会留在那块硬盘上。
