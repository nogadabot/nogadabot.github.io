# 下载与首次启动

Nogada 只有一个程序文件 `nogada.exe`，没有安装向导，下载后直接运行即可。

## 从下载到主界面

1. 在付款完成页面或 [我的许可证](https://nogada-lic.duckdns.org/dashboard) 点击 **下载应用**，下载 `nogada.exe`。购买密钥的方法见 [许可证](license.md)。
2. 双击文件。Windows 对没见过的程序可能弹出蓝色警告，先点 **更多信息**，再点 **仍要运行**。
3. 出现许可证页面后，粘贴密钥并点击 **激活**。首次激活需要联网。

左侧出现菜单就完成了。

## 文件放在哪里

| 内容 | 位置 | 说明 |
|---|---|---|
| `nogada.exe` | 你自己选的文件夹，例如 `C:\Nogada` | 普通的本地文件夹最合适。OneDrive 这类同步文件夹和网络驱动器容易出问题。 |
| 日志 | exe 旁边生成的 `logs` 文件夹 | exe 移到哪里，哪里就会新建一个 `logs` 文件夹。 |
| 钱包、任务、设置 | `%LOCALAPPDATA%\nogada` | 不在 exe 旁边，所以换成新版本的 exe 后一切都还在。 |

## 应用自己会做的事

- **检查许可证**：启动 90 秒后检查一次，之后每 15 分钟一次。短暂断网不会有任何影响。只有服务器拒绝密钥时（已到期、已停用或绑定在其他电脑上）才会回到许可证页面。
- **更新**：**设置 → 常规 → 更新** 中开启 **启动时强制更新** 时，启动并检查完许可证后会马上安装新版本并重启。关闭时只提示有新版本。
- **只允许一个**：Nogada 已在运行时再次打开，不会出现新的东西。请找已经打开的窗口，它可能被最小化或在其他窗口后面。
- **关闭即全部停止**：右上角的 X 会结束整个应用，而不只是关窗口。运行中和定时的任务也一起结束。

窗口不能缩小到 1100 × 720 以下。

## 在 VPS 上运行

如果自己的电脑关机时任务也要继续运行，可以租一台一直开着的 Windows 电脑（VPS），在上面运行 Nogada。

1. 用远程桌面（RDP）连接。
2. 在远程画面里按上面的“从下载到主界面”操作。
3. 一个密钥只能在一台电脑上使用。如果家里的电脑用过这个密钥，先在 [我的许可证](https://nogada-lic.duckdns.org/dashboard) 点击 **重置设备**（每 24 小时一次）。

需要注意：

- 远程桌面窗口的 X 只是断开连接，Nogada 会在 VPS 里继续运行。在 VPS 里选择注销或重启会结束那个 Windows 会话，Nogada 也会随之关闭。
- 定时任务按 VPS 自己的时钟发射，请在那里开启 Windows 时间同步。应用底部状态栏的时钟旁显示差值，说明那台电脑的时钟不准。
- 归还 VPS 前，先做好 [备份](../app/backup-and-data.md)，再执行 **设置 → 常规 → 清除所有数据**。只删除 exe，钱包仍会留在那块硬盘上。
