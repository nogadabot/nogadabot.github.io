# 捕获扩展

Nogada 捕获是安装在 Chrome 和 Edge 里的扩展。它捕获区块浏览器或铸造网站上的调用，通过 `nogada-v1://` 协议交给应用。

## 安装

1. 在 **设置 → 集成 → Nogada 捕获浏览器扩展** 里点击 **下载扩展**。
2. 把压缩包解压到一个固定的文件夹。
3. 打开 `chrome://extensions` 或 `edge://extensions`。
4. 打开 **开发者模式**。
5. 用 **加载已解压的扩展程序** 选择那个文件夹。

使用之前，请先启动一次 Nogada。启动时会注册协议。

## 捕获什么

| 类型 | 发送给应用的内容 |
| --- | --- |
| Hex | 目标、调用数据、金额、来源 URL |
| 函数 | 合约、函数名称和签名、可见的参数、金额 |

Hex 会以 Hex 模式打开任务窗口。函数会生成该函数的 ABI，并以函数模式打开。补全缺少的参数后保存。

不会发送费用。为了避免单位出错，会以应用的默认值或自动值开始。

## 打开方式

Nogada 正在运行时，任务窗口会在已打开的窗口中弹出。没有运行时，Windows 会启动应用，应用会使用收到的值。

## 隐私与安全

- 扩展不会为交易签名。
- 不会跳过钱包审批。
- 只把最近一次捕获保存在浏览器存储里。
- 只通过 `nogada-v1://` 地址与应用通信。

## 故障排查

- **点击后没有任何反应。** 请先手动启动一次 Nogada，再试一次。如果移动过应用，请点击 **重新注册协议处理程序**。
- **部分参数是空的。** 扩展只读取页面上可见的值。请在任务窗口里补全。
- **Gas 栏是空的。** 这是正常的。Gas 由应用的任务设置决定。
