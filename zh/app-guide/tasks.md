# 任务与 Start
任务会保存链、合约、铸造阶段、钱包、数量、Gas 和预约时间。**创建任务与执行任务是两步操作。**

## 创建并执行
1. 使用 [Smart Mint](../minting/smart-mint.md) 或手动 ABI/Hex 编辑器创建任务。
2. 在任务组中检查保存的设置。
3. 立即执行时点击 Start；预约执行时提前点击 Start，开始准备。
4. 查看状态与结果，需要时打开日志或结果汇总。

分组启动/停止、批量编辑、复制和删除只针对界面显示的目标。删除任务不会取消已发送的交易。编辑运行中的任务时，请确认界面说明的新设置生效时间。

## 数量与金额
**每个钱包的数量**、**选中钱包数**和**目标总数量**是不同概念。存在已知单笔上限时，请求数量可能拆成多笔交易，每笔交易都可能产生 Gas 费用。

手动 ABI/Hex 任务的实际铸造数量由函数参数或 calldata 决定。交易金额是**单笔交易附带的原生币总额**，不是每个 NFT 的单价。高级回执设置中的 NFT 合约与预期数量用于核验结果，不会改写 calldata。铸造所得由签名钱包接收。

## 状态与结果
状态栏保持简短，结果栏显示失败原因、交易链接和链上证据。请参阅[结果说明](results.md)，区分成功、失败、待确认和未验证。

余额或资格估计属于准备信息，不是成功保证。已提交的交易仍待确认时，请先检查原交易，再决定是否重启任务。再次点击 Start 可能让相同钱包发出新交易，造成重复铸造。

另见[铸造模式](../minting/modes.md)与 [Boost](../minting/boost.md)。

## 编辑与重试工具
| 功能 | 注意事项 |
|---|---|
| 仅重试失败钱包 | 为失败钱包创建新的空闲任务。检查设置后，需要另行点击 Start。 |
| 任务模板 | 保存或加载常用任务设置。应用模板后，请确认当前链、目标、价格和数量。 |
| 比较与恢复保存版本 | 比较修改历史并恢复以前的设置。任务正在运行时，请按提示确认恢复设置的生效时间。 |

Stop 用于停止后续尚未发送的执行，不会取消已经提交到链上的交易。
