# 代理 (Proxies)

代理用于让铸造查询、voucher 请求和交易传播走用户选择的网络路径。**大多数直接合约铸造不需要代理。**

## 什么时候需要？

* 多个钱包在同一时刻请求签名/voucher 数据，需要分散 API 路径时使用。
* 为任务选择代理组后，该任务会固定使用该路径。所选代理失败时，Nogada 会报告错误，不会暗中改为直连。
* 直接合约铸造通常不使用代理，路径更短。

## 格式

代理通常使用以下格式：

```
host:port:username:password
```

可以逐行粘贴多个代理。

## 界面组成 / 按钮

* **分组栏（左侧）**：管理代理分组。`+ 新建分组`。
* **导入代理**：按上述格式粘贴后添加。
* **全部测试**：检查代理是否可用及响应速度。
* **全部删除**：清空当前分组。
* **按主机筛选**：代理较多时可快速搜索。

## 代理类型（简介）

* **住宅代理（Residential）**：需要多样 IP 时可用，但延迟可能更高。
* **ISP 代理**：通常延迟与连接更稳定，但不同服务商之间差异很大。
