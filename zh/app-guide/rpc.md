# RPC 连接
RPC 用于查询区块链和提交已签名交易。在**高级菜单 → RPC**中创建分组，每行导入一个 URL。

测试时，除了延迟，还应检查**链是否正确、区块是否更新、请求是否成功**。检测失败不等于列表为空，请保留上次保存的数据并按需重试。

## 在任务中选择
确认所选节点属于目标链。任务明确选择了节点时，会遵循该选择。未选择节点时，默认连接池取决于应用设置和该链已注册的节点，不要假定一定只使用某个服务商。

同一笔签名交易可以通过多个 RPC 广播。这不等于重复发起多次铸造，也不会自动提高 Gas。RPC 接收与交易上链是不同事件。

应用和机器人的 RPC 设置相互独立，机器人需在其**设置**中单独配置。查看详情、测试或删除时，请确认对应的项目编号。

RPC URL 可能含有 API 凭据，请勿在公开日志或截图中暴露完整地址。参见 [RPC 资料](../resources/nodes.md)。
