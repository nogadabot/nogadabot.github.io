# 应用设置
当前设置包括**常规、语言、集成、执行引擎、链与 RPC、许可证、快速任务设置**。除非界面另有说明，设置保存在这台电脑的应用中。

## 常规与语言
可以调整缩放、开机启动、隐私模式和 Windows 通知。英语、韩语和简体中文的选择会在本地保留。应用按 Windows 时区显示当地时间，不使用机器人的时区设置。

**下次更新：**首次提交、RPC 接收和链上回执通知将成为独立选项，默认关闭。它们与最终铸造结果通知分开管理。

## 集成
OpenSea 密钥既可用于签名铸造数据，也可用于支持的市场操作。Alchemy 数据接口按链配置，用于相应 NFT 和盈亏查询。Etherscan V2 密钥不仅用于扩展 ABI 查询，也是现有 Stable NFT 查询路径的必需配置；这不代表全部 Stable 市场功能均已支持。Webhook 用于对应的通知功能。

不能笼统地说所有功能都需要或都不需要 API 密钥，应以实际功能和错误提示为准。应用密钥不会复制到机器人。

## 执行引擎与链/RPC
检查 Gas 默认值、广播设置、支持的私有提交方式、显示的链和公共 RPC 覆盖设置。不要把所有留空或 0 都理解成无限制，请阅读对应字段说明。自动 Gas 不会持续提高已提交交易的费用。

## 许可证与快速设置
许可证页面用于激活与设备绑定。快速任务设置用于创建新任务，不会自动启动；点击 Start 前仍应检查任务内容。

更新、刷新和数据重置是不同操作。查询失败时，不应把删除本地数据当作常规解决办法。
