# 市场与 NFT
查看所选链和钱包组中的 NFT，并管理支持的 OpenSea/Seaport 订单。列表无法加载时，请先检查数据服务设置和查询错误；查询失败不代表没有 NFT。

## 持有的 NFT
选择链和钱包后刷新。相关链的 NFT 数据接口在**设置 → 集成**中配置。转移 NFT 时，请区分代币、数量、来源钱包、目标地址和链。

## 订单与购买
支持的路径可以创建/取消挂单、查看/接受报价，以及执行扫地板价和狙击。预览不等于订单已执行，请在操作界面核对币种、价格、数量、费用、Gas 和目标 NFT。

**取消所选挂单**与**取消钱包/分组的全部挂单**范围不同。全部取消还会影响该钱包未选中或未显示的订单。请检查各钱包的取消交易以及失败、待确认结果，再决定重试范围。

链出现在列表中，不代表该链的全部市场或 NFT 数据功能均已支持。路径不可用或不受支持时，请按提示处理。

市场交易与[铸造任务的 Start](tasks.md)是不同操作。
