# App updates

In **Settings → General → Updates**, you see the installed version and check for a new one. The app changes itself only after it checks the signature of the release info and the signature and hash of the downloaded file.

## Actions

- **Check for Update**: Checks now.
- **Update Now**: Downloads, verifies, applies, and restarts.
- **Force update on startup**: If on, the app applies a new build right after the license check. If off, it shows an **Update Now** notice.

## If it fails

Put the app in a fixed, writable folder, check that you can reach the update server, then restart the app and try again. If the signature check fails, do not bypass it. Find the update error in **Application Logs** and contact support. Do not use files from unofficial sites.
