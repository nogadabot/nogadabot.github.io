# Optional settings
You do not need to enable every option at the start. Choose settings that serve your workflow.

| Goal | Setting to check |
|---|---|
| Create tasks with familiar defaults | Settings → Quick task setup |
| View NFTs and calculate PnL | Supported data integration for the selected chain |
| Obtain OpenSea signed mint data or use market features | Each product's OpenSea key and supported route |
| Use a specific network route | The task's RPC and proxy selection |
| Choose result notifications | App and bot notification settings separately |
| Avoid scheduling mistakes | PC time, bot time zone and UTC start time |

Quick-task defaults help create a new task. They do not blindly reuse old calldata or automatically press Start.

Choose [RPCs](../app-guide/rpc.md) using successful responses, chain identity and recent measurements, not latency alone. A [proxy](../app-guide/proxies.md) adds a network hop and is not necessarily faster. This guide does not guarantee any provider's pricing or performance.

See [Gas settings](../minting/gas.md) for gas and Flashbots. Fees on transactions already sent do not increase automatically.
