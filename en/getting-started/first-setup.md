# Initial app setup
Complete these checks before creating a minting task.

1. **Wallets:** create a group, then generate or import the wallets you intend to use. Check their addresses and the selected chain.
2. **RPC:** add endpoints for that chain or review the available default route. Test chain identity and successful responses as well as latency.
3. **Gas and payment:** check the native coin used for gas, the mint payment asset, quantity and amount per transaction.
4. **Smart Mint:** enter the project link or contract, select the actual chain and phase, then create a task.
5. **Tasks:** review the saved settings and press Start. For a future mint, press Start in advance.

Adding a private RPC is a choice, not a universal requirement. Paid services also have quotas and limits. A low ping alone does not prove that a provider will accept transactions reliably.

API keys and proxies depend on the selected feature and provider. An OpenSea key can also be used for signed mint data; it is not limited to market features. See [Integrations](../app-guide/settings.md).

An unavailable wallet, RPC or task list is not proof that data was deleted. Use the retry control and check the latest status.
